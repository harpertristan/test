Facebook и LinkedIn через Apify API

Для чужих публичных публикаций используются сохранённые задачи Apify. Собственное приложение Meta / LinkedIn не требуется. Выбирайте сборщики без логина и cookies. Проверка доступа не запускает задачу. Пробный сбор: один запрос / URL, до 20 результатов, время 120 секунд; денежный предел дополнительно настройте в Apify — расходы зависят от сборщика.

Настроить локально: npm run configure:social-api

Рынок и исключаемые юрисдикции

Локация определяется по домену, опубликованному адресу и сведениям о юридическом лице. Язык текста и страна магазина не считаются юрисдикцией. Румыния (RO), Словакия (SK), Словения (SI) остаются в поиске. Чистые криптокошельки без фиатного счёта не добавляются в списки; провайдеры крипто + бизнес-IBAN проходят обычную проверку.

Публикации, реклама, партнёры и реестры

Публичный индекс Brave: источники могут отдавать неполную выдачу. Поиск YouTube и библиотек рекламы не означает доступ ко всем объявлениям или закрытым публикациям. Для публичного индекса аккаунты LinkedIn / Facebook не нужны.

Наблюдение за известными страницами и каналами

Для YouTube: https://www.youtube.com/feeds/videos.xml?channel_id=ID_КАНАЛА. Первое чтение страницы создаёт исходный снимок; затем сохраняются изменения. Закрытые страницы и содержимое за входом не читаются.

Память ваших решений

Новые отметки «Подходит» и причины отказа помогают расставлять приоритеты запросов и дают моделям короткие примеры ваших решений. «Уже в работе» исключает повторы и не считается отрицательным примером. Источники нового провайдера проверяются отдельно. Новые запросы или платные подключения автоматически не добавляются.

ИИ и русский язык

Профиль не устанавливает модель. Инструкция запуска GPU-обработчиков: Windows, Mac M5 и ферма. На каждой карте работает один обработчик. Несколько GPU увеличивают пропускную способность очереди; качество зависит от модели и источников.

Параллельность — число одновременных разборов, а не лимит количества проектов. Повышайте её постепенно с учётом квот API.

Ключи вводятся через 4-Keys.cmd или npm run configure:gemini / configure:ai. Бесплатные квоты Gemini и доступ к модели зависят от аккаунта. Облачные API могут быть платными. В режиме GPT + Ollama разные карточки распределяются между моделями; одна карточка не отправляется обеим. Параллельность облака задаётся выше, Ollama получает одну карточку одновременно. Локальный ИИ зависит от видеокарты; автоматически на платный API не переключаемся.

Официальные реестры EMI и MiCA

Каждый реестр запускается в разделе «Источники поиска». Отметка «ИИ после сбора» включает последующий разбор сохранённой общей базы. Найденная лицензия — сигнал; выдача бизнес-счёта и EU IBAN проверяется отдельно на сайте продукта.
