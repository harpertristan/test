Нейронный поиск

Подробная инструкция с нуля ↗

Все выбранные источники → единый список → анализ, фильтрация и комментарий ИИ. Неизвестные сведения остаются на проверку.

Для платного режима нужен отдельный ключ OpenAI. Бесплатный локальный режим Ollama выбирается в настройках единой CRM. Подписка ChatGPT не оплачивает API. Откройте 3-Настроить-ИИ.command или выполните npm run configure:ai, затем перезапустите программу.

В экономном режиме ИИ получает до 6 000 символов ключевых фрагментов; в подробном — до 24 000 символов общедоступных описаний, сайта и индекса. До 3 страниц сайта на находку и проверки Brave без квоты на число запросов. API оплачивается отдельно; уже проверенные неизменные находки временно сохраняются в кэше.

Источники для общего поиска и анализа

Вся очередь ИИ разбирается без квот за запуск и за месяц. Ваш API оплачивается отдельно.

По умолчанию приоритет у неизвестных находок. Указанный вами список не считается новыми открытиями. Счётчик учитывает попытки, включая ошибки и отмену; программных квот нет.

Проверяются все выбранные источники. Публикации собираются в широком режиме сигналов; Сбор и анализ выполняются параллельно по мере поступления записей. Каждый источник может вернуть пустой ответ или ошибку — это показывается отдельно.

Выводы по найденным сервисам

Сформировать и выгрузить список

Отмечайте нужные сервисы галочкой «В итоговый список». Ручные исключения учитываются во всех выгрузках. Выгружается весь выбранный список с текущим фильтром, включая записи за пределами первых 30 на экране.

Скачать Word (.docx) Отчёт / сохранить PDF Скачать CSV для таблиц

Word и отчёт содержат ссылки, комментарии ИИ, оценки критериев и цитаты. В отчёте нажмите Command + P → «Сохранить как PDF». Выгрузка не запускает новый анализ.

ИИ предлагает оценку. Записи и история не удаляются автоматически. Кнопка «Исключить» сохраняет ваше решение во всех вкладках.
