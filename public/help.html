Полная ручная очередь и GPT + Ollama

«Все карточки на проверке → сайты + ИИ» запускает всю вкладку, независимо от фильтра и первых 50 строк. Читает публичные сайты и актуальные карточки Google Play, сохраняет цитаты и дату. Недоступные источники помечаются. Ручные исключения и записи в работе пропускаются; «Подтверждено мной» ставите вы.

После остановки используйте «Продолжить полную проверку». Основная кнопка начинает новый проход и может повторно расходовать API. В настройках выберите «GPT + Ollama»: модели берут разные карточки из общей очереди, одна запись не отправляется обеим. Облако платное; локальный разбор зависит от оборудования. Ограничения поисковых источников ИИ не ускоряет.

Сохранённую очередь Google Play можно продолжить отдельной кнопкой без повторения всех поисковых запросов. При обновлении с 4.4 ваши решения не сбрасываются.

Play Scout 4.2.1 — Mac и Windows

Обновление Mac M5 / 16 ГБ · Обновление Windows · llama.cpp, CUDA / Metal и 6 GPU

Mac: обновить в прежней папке

Готовый блок команд и полная инструкция Mac. Обновление сохраняет историю и ключи на месте и создаёт резервную копию. После первого обновления: npm run update:mac -- "$PWD" --start или 4-Обновить.command. Запуск — 2-Запустить.command, остановка — 5-Остановить.command. Для Apple Silicon начните с Ollama qwen2.5:3b и экономного режима.

Windows: установка и перенос

  1. Установите Node.js LTS 22 или новее. Скачайте ZIP проекта, извлеките в папку PlayScout внутри вашей папки пользователя Windows.
  2. Остановите прежнюю программу. Перенесите в новую папку всю старую data и скрытый файл .env. В Finder скрытые файлы показываются через Command + Shift + точка. Так сохраняются история, исключения, кэш, заметки и ключи.
  3. Запустите 1-Install.cmd. Затем 2-Start.cmd: он откроет CRM в браузере. Оставьте окно открытым.
  4. Остановка с сохранением — 3-Stop.cmd. Ключи и пароли — 4-Keys.cmd.

Полная инструкция Windows: по папкам, кнопкам и командам. Инструкция для Mac.

Локальный ИИ на NVIDIA

  1. Установите и откройте Ollama.
  2. Для видеокарты с 8 ГБ видеопамяти запустите 5-Local-AI.cmd: скачается модель qwen3.5:4b.
  3. В настройках CRM выберите Ollama, экономный режим и qwen3.5:4b. Сохраните настройки и проверьте подключение. Сначала разберите одну карточку.
  4. 6-Diagnostics.cmd показывает установленные модели и GPU. Во время генерации ollama ps должен показывать использование GPU. Скорость зависит от видеокарты.

Ollama не требует ключа и оплаты за API-запросы. Облачные OpenAI и Gemini подключаются отдельно через 4-Keys.cmd и выбираются вами в CRM. Бесплатные квоты Gemini зависят от аккаунта и региона. Автоматического платного переключения нет. Подробности: ИИ и критерии проверки.

Перепроверка результатов 4.1

«Перепроверить сохранённое · без API» обновляет статусы по уже прочитанным текстам. Это также выполняется один раз после обновления. Исключения и комментарии сохраняются. «Повторить проблемные» вызывает выбранную модель только для проблемных записей; облачный API может расходовать баланс. Общие материалы регуляторов доступны отдельно во вкладке «Материалы источников».

Чистый запуск Windows без истории

Перенесите только файл .env с Mac и запустите 9-Import-keys-only.cmd, затем 1-Install.cmd и 2-Start.cmd. Старые data и JSON CRM не копируйте. Модель Ollama установите отдельно и выберите её в CRM. Подробная инструкция.

Необязательно: полный перенос профиля

Остановите программу на Mac и выполните npm run transfer:export. Передайте зашифрованный .psbackup на Windows, запустите 7-Import-from-Mac.cmd и введите пароль переноса. Затем 1-Install.cmd и 2-Start.cmd. История, исключения и ключи из .env переносятся без повторного ввода. Модель Ollama скачивается отдельно. Пошаговая инструкция.

Что искать

Подходят банки и небанковские провайдеры бизнес-счетов / IBAN: EMI, платёжные организации, агенты, BaaS и white-label, а также криптосервисы с фиатными EUR-реквизитами через партнёра. Собственная банковская лицензия не обязательна. EUR, SEPA или европейский адрес сами по себе не доказывают EU IBAN.

«Выбрать источник поиска» открывает отдельные запуски и расписания каждого источника. Результаты объединяются в CRM, а ИИ разбирает общую базу отдельно или после выбранного источника. Издания и реестры разделены по доменам. Фильтр источника действует также в Word / CSV / JSON. Прежние общие расписания можно отключить кнопкой в разделе источников. App Store отключён.

Быстро очистить список

  1. Выберите причину исключения один раз в панели списка.
  2. Нажимайте «Исключить» прямо в строках либо отметьте несколько / все подходящие строки и исключите одним действием.
  3. Во вкладке «Исключены вручную» выберите причину: «Уже в работе / был в работе», «Не банк и не провайдер», «Не подходит локация». Здесь можно менять причины и восстанавливать записи.

Исключения сопоставляются по бренду и вариантам его названия, домену и ID приложения. Сортировка доступна по релизу, публикации, решению о лицензии и обнаружению. Неизвестные даты идут в конце. Ночной режим запоминается.

Выгрузить и передать в этот чат

Выберите вкладку, фильтры и сортировку, затем Word, CSV или JSON для ChatGPT. Рабочий экспорт исключает отсеянные проекты; исключения можно выгрузить из их вкладки. Прикрепите JSON к вашему сообщению для независимого разбора здесь. Чат не видит файлы на вашем компьютере автоматически.

Поделиться ссылкой

В 4-Keys.cmd задайте пароли владельца admin и чтения viewer, затем перезапустите. В одной сети откройте IP компьютера и порт 3000. Для HTTPS-ссылки из другой сети инструкция описывает Tailscale Funnel. Компьютер и программа должны работать. Права viewer проверяются сервером: чтение и выгрузки без запуска поиска и изменений.

Полная повторная проверка

Версия 4.4 возвращает сохранённую базу в «Проверить вручную», сохраняя «Уже в работе / был в работе». Перед изменением существующей базы создаётся резервная копия. Сброс при обновлении выполняется один раз и не вызывает ИИ. «Подтверждено мной» ставится только по вашему решению; восстановленные записи не считаются впервые найденными. В карточках доступны прежние замечания и разборы. Критерии стран и кошельков продолжают действовать для новых находок.

Юрисдикции и криптокошельки

Общий фильтр находится в CRM → Настройки → «Рынок и исключаемые юрисдикции». Румыния, Словакия и Словения остаются в поиске. Язык и страна магазина не определяют юрисдикцию провайдера. При новом поиске чистые криптокошельки без фиатного счёта / IBAN отсекаются до ИИ. Восстановленные записи доступны в ручной очереди; помощь ИИ для одной из них запускается отдельно. Криптосервисы с бизнес-счётом через партнёра проверяются по обычным критериям. При обновлении ошибочные выводы об утилитах перепроверяются локально; ручные исключения сохраняются.

Проверить автоисключения в ChatGPT

Откройте CRM → «Автоисключения» → «Выгрузить все автоисключения для проверки в ChatGPT · JSON». Прикрепите скачанный play-scout-auto-exclusions.json в чат. Файл содержит весь сохранённый список из всех источников, причины отсева, оригиналы и настройки поиска / ИИ. Выгрузка не вызывает ИИ и не меняет исключения. Старые несохранённые тексты в неё восстановить нельзя.

Социальные сети и реклама

Сейчас поиск использует публичный индекс Brave, включая YouTube, Meta / LinkedIn Ad Library и другие рекламные библиотеки. Это не полный поток объявлений или закрытых публикаций. Прямые API Facebook и LinkedIn требуют приложения разработчика, разрешений и иногда одобрения; универсального ключа для поиска всех публикаций нет. Как устроены подключения.

Ежедневный поиск и ошибки

Включите отдельные расписания нужных источников в CRM, время — Калининград. Программа и выбранный локальный GPU-сервер / Ollama должны работать, сон ПК — выключен. Пропущенный запуск выполняется после включения. Очередь и история сохраняются. Программных квот числа проектов нет; остаются ограничения внешних API, время ответа и размер контекста модели.

При ошибках используйте 6-Diagnostics.cmd. Не удаляйте data. Перед обновлением остановите программу и сохраните резервную копию data и .env. Ошибка сети или квоты не означает отсутствие подходящих проектов.
