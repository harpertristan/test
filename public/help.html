Запуск и настройка на Mac

Версия 2.1 ищет бизнес-счета и платёжные сервисы по вашим примерам. Собственная банковская лицензия не требуется. Неизвестный EU IBAN не выдаётся за подтверждённый.

1. Установка

  1. Установите Node.js LTS с nodejs.org — установщик macOS .pkg.
  2. Скачайте свежий ZIP проекта, распакуйте, назовите папку play-scout и перенесите на Рабочий стол.
  3. При обновлении остановите старую программу (Control+C) и скопируйте data и .env из старой папки в новую. Скрытые файлы Finder: Command+Shift+точка. Старую папку пока сохраните.

2. Ключ Brave

  1. У вас уже есть Search API key. Откройте 1-Настроить-ключ.command в папке проекта.
  2. Вставьте только ключ, нажмите Enter. Ввод скрыт. Ключ сохранится в локальном .env, в историю результатов не попадёт.
  3. Если macOS не открывает файл: запустите Терминал (Command+пробел → Терминал), выполните cd ~/Desktop/play-scout, затем npm run configure.

3. Запуск

  1. Откройте 2-Запустить.command. При первом запуске зависимости установятся автоматически.
  2. Если файл не открывается: в Терминале из папки проекта выполните bash ./2-Запустить.command.
  3. Откройте в браузере http://localhost:3000. Оставьте Терминал открытым.

4. Первый поиск

  1. На главной нажмите «Настроить под ваши примеры». Выбран профиль бизнес-сервисов, 12 месяцев, от 1 установки, страны ЕС.
  2. Нажмите «Проверить ключ Brave». Это один запрос API. Дождитесь сообщения об успешном подключении.
  3. Нажмите «Найти приложения» и дождитесь завершения. Поиск может занять несколько минут; прогресс виден в интерфейсе.
  4. Смотрите «Все находки» и «На проверку». Образцы отмечены отдельно. Откройте карточку: бизнес, IBAN, EU IBAN и лицензия — отдельные сведения.
  5. Если нужна более широкая проверка, включите «За всё время» или полный план. Они дают больше старых приложений и запросов.

5. Ежедневная работа

  1. Проверьте запросы и исключения. Нежелательные приложения убирайте кнопкой «Исключить это приложение».
  2. Включите «Автоматически каждый день», выберите время по Калининграду и нажмите «Сохранить расписание». Сохраняется выбранное число месяцев.
  3. Приложения не добавляются повторно по одному ID. Смена названия или страны не создаёт новую находку. В «На проверку» — сервисы, для которых бизнес-обслуживание или нужные условия неясны.

Mac должен быть включён, с интернетом и открытой программой. Файл запуска предотвращает автоматический сон по бездействию, пока работает. Закрытая крышка, выключение и остановка программы мешают расписанию. После перезагрузки запустите файл снова. Для 24/7 без Mac нужен облачный сервер: инструкция Render.

6. Сайты и публикации

  1. Откройте «Сайты и публикации», оставьте профиль бизнес-сервисов и выберите источники.
  2. Для своих сайтов включите «Мои сайты» и добавьте домены по одному на строку: lurrapay.com, rampy.money, stable.com, photonpay.com.
  3. Используйте запросы business account / corporate account с IBAN, SEPA или EUR. Точная фраза EU IBAN не обязательна.
  4. Проверьте ручной поиск, затем включите ежедневное расписание и сохраните его на этой странице. Это отдельное расписание.

Публикации ищутся через индекс Brave; прямое наблюдение за изменениями находится на странице «Изменения и компании».

7. Включить все источники и изменения

  1. Откройте «Изменения и компании» и нажмите «Включить весь ежедневный мониторинг». Будут включены три сохранённых расписания.
  2. У публикаций по умолчанию 8 Brave-запросов за запуск, полный круг стандартных источников — 5 дней. Для всего за один день увеличьте лимит на странице публикаций до числа пар.
  3. Форумы дают сообщения пользователей; реестры — зацепки для проверки. Они не подтверждают открытие счёта.
  4. Первый просмотр страниц и приложений сохраняет исходное состояние; последующие отмечают изменения. Для своих RSS/Atom укажите точный адрес ленты.
  5. Смотрите «Подробности проверки»: ошибка доступа отличается от отсутствия изменений. Не удаляйте историю.

Если что-то не работает

В Терминале из папки проекта выполните npm run doctor. Команда показывает версию, наличие ключа и истории, не раскрывая ключ. Ошибки источника смотрите в «Подробностях проверки». Не удаляйте data для исправления поиска.

Выдача веб-версии Google Play отличается от приложения на телефоне. Для конкретного приложения скопируйте на телефоне ссылку «Поделиться» и добавьте её в «Образцы». В таблице она будет помечена как прямая проверка, а не независимая находка по общим запросам.

Проверьте тариф Brave. В Google Play используется до 20 обращений Brave за запуск, включая поиск карточек по сайтам образцов. Мониторинг новостей использует отдельный лимит и ротацию: по умолчанию до 8 обращений за запуск. Сам Google Play ключа не требует. Дополнительные источники настраиваются на странице «Сайты и публикации».

Веб-версии и ручное исключение

Откройте «Веб-версии» → «Найти веб-сервисы». Используется ваш существующий ключ Brave. Для ежедневной работы включите «Каждый день» и сохраните расписание этой вкладки.

Кнопка «✕ Исключить» у каждой находки сохраняет исключение сразу во всех вкладках. Для возврата нажмите «Отменить» или раскройте «Исключённые вручную» → «Восстановить». История сохраняется.

Остановка поиска

Версия 2.3.1 прерывает ожидающий запрос и сохраняет очередь. Пока показано «Останавливаем поиск…», новый запуск выключен. После «Поиск остановлен» можно запустить поиск сразу. Для зависшей старой версии остановите программу через Control+C, обновите с переносом data и .env, затем запустите снова.
