Запуск Play Scout 3.1 на Mac

Обновить

  1. Остановите старую программу через Control + C в Терминале.
  2. Скачайте новый ZIP, распакуйте и назовите папку play-scout. Старую папку пока сохраните.
  3. Скопируйте из старой папки в новую data и .env. Показать скрытые файлы в Finder: Command + Shift + точка. Это сохранит находки, исключения и ключи.

Установить и запустить

Нужен Node.js LTS версии 22+ с nodejs.org. Если папка лежит на Рабочем столе, в Терминале выполните по одной команде:

cd ~/Desktop/play-scout
npm ci
npm start

Затем откройте http://localhost:3000/crm. Терминал должен оставаться открытым. Также можно запустить файл 2-Запустить.command двойным щелчком.

Бесплатный локальный ИИ

В CRM можно выбрать Ollama, которая работает на вашем Mac без оплаты за запросы. Подробная установка Ollama и экономный режим OpenAI. Для первого запуска используйте qwen2.5:3b; качество и скорость зависят от компьютера. Автоматического платного переключения нет.

Добавить ключи

Если перенесли старый .env, повторять ввод не нужно. Для Brave выполните npm run configure. Вставьте ключ поиска и Enter — ввод скрыт.

Для ИИ нужен отдельный ключ OpenAI: создать ключ API, проверить оплату API, выполнить npm run configure:ai, вставить ключ и Enter. Подписка ChatGPT не оплачивает API. Ключи в чат не присылайте. После изменения перезапустите программу.

Начать поиск

  1. Откройте CRM → «Настройки источников, перевода и исключений».
  2. Проверьте фразы, страны и категории Google Play / App Store. Перевод включён по умолчанию.
  3. Нажмите «Искать во всех источниках + ИИ» или «Разобрать уже найденное через ИИ».
  4. Откройте сервис слева: справа будут статус, комментарии, ссылки, цитаты, перевод и оригинал.
  5. Для удаления из рабочих списков нажмите «Исключить из всех списков». Вернуть можно во вкладке ручных исключений.

EMI и MiCA

Вкладка «Лицензии» → фильтр «EMI и MiCA / CASP», «Только EMI» или «Только MiCA / CASP». До анализа это материалы регуляторов; после разбора появятся компания, тип, статус, дата решения при наличии и официальная цитата. Заявки и VASP не считаются выданной CASP-авторизацией. Лицензия не доказывает выдачу бизнесу EU IBAN.

Как передать находки в этот чат

Выберите нужную вкладку CRM → «Скачать данные для разбора в ChatGPT» → прикрепите JSON к сообщению. Чат автоматически не видит ваш Mac. Встроенный ИИ работает отдельно через ваш OpenAI API.

Документы

Кнопки Word и CSV выгружают весь отфильтрованный список с комментариями и разборами. Вкладка «Все» включает исключения; «Рабочий список» их убирает.

Ежедневный режим

Нажмите «Включить ежедневный сбор + ИИ». Отдельные расписания выключатся, чтобы не дублировать обращения. Единый запуск использует время из настроек ИИ, по Калининграду (UTC+2). Компьютер или сервер должны быть включены, а программа запущена.

Ограничения и ошибки

Программных квот на запросы, карточки и ИИ больше нет. Платные API могут расходовать доступный баланс. 20 результатов Brave / 200 результатов Apple — размер ответа сервиса, а не число запросов. Паузы, тайм-ауты и ограничения внешних сайтов сохраняются.

«Остановить всё и сохранить» прерывает поиск и сохраняет проверенное. Очередь Google Play можно продолжить на его странице. 403, DNS и тайм-аут означают проблему доступа, а не отсутствие подходящих банков. Диагностика: npm run doctor; с реальными запросами Google Play: npm run doctor -- --play. Не удаляйте data для исправления ошибок.
