# Размещение и общий доступ

Для текущего сценария используется **ваш компьютер с Windows и NVIDIA**: [полная инструкция](WINDOWS.md). Запуск — `2-Start.cmd`; доступ в своей сети или HTTPS через Tailscale Funnel описан там же. Платный сервер для этой настройки не создан и не требуется.

Обычный VPS без GPU не ускоряет Ollama. Если позже понадобится постоянный сервер, сохраняйте `data/state.json` на постоянном диске, ключи — в секретах окружения, задайте `APP_PASSWORD` и отдельный `VIEW_PASSWORD`, используйте HTTPS и одну копию процесса на одну базу. Dockerfile и Render-конфигурация оставлены как необязательный вариант; локальная Ollama на таком сервере требует подходящего GPU и установки на той же машине.

Код не содержит ваших ключей и истории. Без переноса `data` новый экземпляр начинает с пустой базой. Word / CSV не заменяют полную историю. При использовании облачного ИИ ключ и баланс относятся к выбранному API; локальная и облачная модели не переключаются друг на друга автоматически.
