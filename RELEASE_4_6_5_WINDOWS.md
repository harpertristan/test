# Play Scout 4.6.5 — Windows / 32 ГБ RAM / NVIDIA 8 ГБ

Добавлен ручной запуск без ежедневных расписаний и отдельная кнопка проверки
Brave в CRM. [Поведение и ограничения](RELEASE_4_6_5.md).
Профили NVIDIA 8 ГБ и шести RTX 2060 Super, выбранная модель и данные сохраняются.

## Обновить и запустить вручную

Остановите прежний экземпляр через Ctrl + C. Откройте PowerShell:

```powershell
cd "$env:USERPROFILE\PlayScout"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-windows.ps1 -Target (Get-Location).Path
if ($LASTEXITCODE -ne 0) { throw 'Обновление не завершено.' }
npm.cmd run start:manual
```

Для другой рабочей папки замените первую строку её действительным путём.
Дождитесь «Готово: Play Scout 4.6.5» и сообщения о ручном запуске.
Приложение откроется на http://127.0.0.1:3000/crm, только на этом компьютере.
Вверху должна быть надпись «Ручной запуск».

Повторную очистку делать не нужно. Updater сохраняет backup кода / `data` /
`.env`. Ключи, комментарии, записи в работе, фильтры, исключения, выбранный ИИ,
аппаратный профиль и расход API не сбрасываются. Сохранённые расписания остаются
прежними, но в этом экземпляре не выполняются.

Нажмите **«Проверить Brave · 1 запрос»**. Это одно обращение к Brave Search API,
учитываемое вашим тарифом; без чтения сайтов, сохранения новых карточек и вызова
ИИ. Успех — «Brave отвечает». Ошибки ключа / доступа / квоты / таймаута
различаются, секреты не выводятся.

Для раздельного сбора и анализа снимите «ИИ после сбора» на выбранном источнике.
Этот флажок продолжает действовать после явного запуска источника.

Остановка — Ctrl + C или `3-Stop.cmd`. Повторный ручной запуск из папки программы:
`npm.cmd run start:manual`. Для просмотра без изменений есть
`npm.cmd run start:diagnostic`; обычный `2-Start.cmd` / `start:desktop`
использует сохранённые включённые расписания.
