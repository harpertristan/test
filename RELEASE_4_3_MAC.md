# Play Scout 4.3.0 — обновление Mac M5 / 16 ГБ

**Все 39 проектов из вашего последнего списка внесены в «Уже известные».** Поиск, публикации, CRM и ИИ пропускают их по доменам, известным ID, названиям и алиасам. Посвящённые им статьи тоже скрываются. Реестр находится в отдельной вкладке и выгружается в Word / CSV / JSON. Кнопка «Вернуть» снимает это исключение для выбранного проекта. Статья о новом провайдере сохраняется, если известный проект выступает только его партнёром и новый провайдер установлен как основной.

Образцы остаются поисковыми ориентирами: рекомендации Google Play вокруг них могут приводить другие проекты, сами известные сервисы повторно не добавляются и в ИИ не отправляются. Неподтверждённые ссылки и package ID для BORDERPAY Business, Omexpay Business, TantumPay и Moneybase не выдумываются. Личные пометки «тест» в библиотеку не перенесены.

Поиск разделён на отдельные источники; результаты остаются в общей CRM. У каждого сайта / реестра есть свой запуск, остановка и расписание. Для ИИ добавлен профиль **Mac M5 · 16 ГБ** и подключение llama.cpp / Metal. Установленная Ollama и выбранный ИИ не меняются автоматически.

## Что меняется в отборе

- Общая политика действует в Google Play, веб-поиске, публикациях, наблюдении, CRM и очереди ИИ. Китай / Гонконг / Макао, арабские юрисдикции, страны СНГ, Украина и Беларусь исключаются при наличии сведений о юрисдикции провайдера. Нигерия остаётся в исключениях. Наличие европейского продукта не отменяет эти исключения.
- Румыния, Словакия и Словения остаются среди стран поиска. Язык приложения, `gl` магазина, список стран получателей и клиентов не определяют юрисдикцию проекта. Неизвестная юрисдикция не подменяется догадкой.
- Чистые криптокошельки без собственного предложения фиатного счёта / IBAN не добавляются в находки или очередь ИИ. Старые такие записи скрываются из списков и выгрузок. Криптосервисы с бизнес-счетами через банк / EMI-партнёра остаются кандидатами; EU IBAN проверяется отдельно.
- Прежние стандартные широкие запросы заменяются фразами про бизнес-IBAN, EUR, SEPA, поставщиков IBAN и новые запуски. Пользовательские запросы сохраняются. Рекомендации Google Play и поиск приложений разработчиков сохраняются.
- Обычные банковские функции больше не считаются доказательством «это утилита». Сохранённые выводы и кэш проходят локальную перепроверку цитат при обновлении — без вызовов модели и API. Ручные исключения не восстанавливаются. Это не автоматическое подтверждение EU IBAN.
- Публикации СМИ ищутся как события запуска; реестры и форумы сохраняют режим ранних сигналов. Лицензия сама по себе не подтверждает бизнес-IBAN.

В CRM откройте **«Настройки источников, ИИ и ежедневного поиска» → «Рынок и исключаемые юрисдикции»**. Там видны действующие коды. Изменение применяется ко всем источникам. Переключение рынка на «Другие рынки» само по себе не убирает исключённые юрисдикции.

Прежние настройки перед первой перенастройкой сохраняются в локальном `data/state.json`, в разделе `searchTuningBackup`; полная резервная копия создаётся updater. Ключи, история, комментарии, выбранная модель и расписания сохраняются. Обновление не включает новые платные задачи и не меняет аппаратный профиль. Уже включённые расписания остаются включёнными.

## Обновить существующую папку

Откройте **новое окно Терминала** (Command + N). Ваша папка по скриншотам:

```bash
cd "$HOME/Desktop/play-scout-v31" &&
npm run update:mac -- "$PWD" --start
```

Путь `"$PWD"` обязателен в этой инструкции для совместимости со старым скриптом 4.0.2. Не вставляйте команды в окно с работающим Node. Updater скачает новый код, остановит экземпляр из этой папки, создаст резервную копию, установит зависимости и запустит CRM. История, исключения, `.env` и настройки ИИ остаются на месте.

Дождитесь **«Готово: Play Scout 4.3.0»**. Откройте **http://127.0.0.1:3000/crm** и один раз обновите старую вкладку браузера. При своём `PORT` используйте адрес программы. Окно запущенной программы оставьте открытым.

Если команда `update:mac` ещё не существует, используйте [блок загрузки нового updater](MAC.md#1-обновить-уже-установленный-play-scout-одной-командой).

## Пользоваться источниками

1. Нажмите **«Выбрать источник поиска»**. Найдите Google Play, Trustpilot, отдельное издание или домен реестра.
2. **«Искать только здесь»** запускает только этот источник. Общий список CRM не запускает другие источники.
3. Кнопка **«Находки в общей базе»** включает фильтр источника. Снимите его выбором «Все источники», чтобы снова увидеть общую базу. Word / CSV / JSON учитывают тот же фильтр.
4. У каждого источника отдельно включаются «Ежедневно», время и «ИИ после сбора». После изменения нажмите «Сохранить расписание». Без этой отметки сбор не вызывает ИИ.
5. Сохранённые общие расписания прежней версии не удаляются молча: интерфейс показывает предупреждение и кнопку **«Отключить прежние общие расписания»**. Используйте её перед переходом на новые отдельные расписания, чтобы не запускать оба режима.
6. Публикации и реестры используют Brave и ждут своей очереди; несколько источников можно поставить в очередь. Можно отменить конкретный источник. Google Play / веб / наблюдение используют свои очереди. Ни одна кнопка отдельного источника не расширяет его до всех площадок.

Для анализа всей базы используйте «Разобрать найденное». Для проверки после одного источника включите его «ИИ после сбора»: анализ использует общую сохранённую базу и не запускает остальные поиски. Если ИИ занят, новый анализ дождётся завершения его текущей очереди.

## ИИ для M5

Полная установка llama.cpp / Metal, GGUF, проверка скорости и запуск — **[GPU_AGENT.md](GPU_AGENT.md#mac-m5-16-гб)**. Новый профиль рассчитан на один экономный обработчик. При 16 ГБ не рекомендую начинать с нескольких моделей или большого контекста.

Обычный следующий запуск CRM:

```bash
cd "$HOME/Desktop/play-scout-v31" &&
bash ./2-Запустить.command
```

Остановка CRM в новом окне: `cd "$HOME/Desktop/play-scout-v31" && npm run stop`. Окно GPU-агента останавливается отдельно через Control + C. История и ключи не требуют повторного переноса.
