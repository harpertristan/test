# Play Scout 4.3.0 — обновление Windows / 32 ГБ RAM / NVIDIA 8 ГБ

**Все 39 проектов из вашего последнего списка внесены в «Уже известные».** Поиск, публикации, CRM и ИИ пропускают их по доменам, известным ID, названиям и алиасам. Посвящённые им статьи тоже скрываются. Реестр находится в отдельной вкладке и выгружается в Word / CSV / JSON. Кнопка «Вернуть» снимает это исключение для выбранного проекта. Статья о новом провайдере сохраняется, если известный проект выступает только его партнёром и новый провайдер установлен как основной.

Образцы остаются поисковыми ориентирами: рекомендации Google Play вокруг них могут приводить другие проекты, сами известные сервисы повторно не добавляются и в ИИ не отправляются. Неподтверждённые ссылки и package ID для BORDERPAY Business, Omexpay Business, TantumPay и Moneybase не выдумываются. Личные пометки «тест» в библиотеку не перенесены.

**[Установить Windows с нуля: папки, ключи, NVIDIA и команды](INSTALL_WINDOWS.md).**

Это те же функции и формат базы, что на Mac. Отдельная инструкция и аппаратный профиль учитывают Windows / CUDA. Общая CRM хранит результаты, исключения, статусы и разборы; поиск запускается отдельно по каждому источнику.

## Что меняется в отборе

- Общая политика действует в Google Play, веб-поиске, публикациях, наблюдении, CRM и очереди ИИ. Китай / Гонконг / Макао, арабские юрисдикции, страны СНГ, Украина и Беларусь исключаются при наличии сведений о юрисдикции провайдера. Нигерия остаётся в исключениях. Наличие европейского продукта не отменяет эти исключения.
- Румыния, Словакия и Словения остаются среди стран поиска. Язык приложения, `gl` магазина, список стран получателей и клиентов не определяют юрисдикцию проекта. Неизвестная юрисдикция не подменяется догадкой.
- Чистые криптокошельки без собственного предложения фиатного счёта / IBAN не добавляются в находки или очередь ИИ. Старые такие записи скрываются из списков и выгрузок. Криптосервисы с бизнес-счетами через банк / EMI-партнёра остаются кандидатами; EU IBAN проверяется отдельно.
- Прежние стандартные широкие запросы заменяются фразами про бизнес-IBAN, EUR, SEPA, поставщиков IBAN и новые запуски. Пользовательские запросы сохраняются. Рекомендации Google Play и поиск приложений разработчиков сохраняются.
- Обычные банковские функции больше не считаются доказательством «это утилита». Сохранённые выводы и кэш проходят локальную перепроверку цитат при обновлении — без вызовов модели и API. Ручные исключения не восстанавливаются. Это не автоматическое подтверждение EU IBAN.
- Публикации СМИ ищутся как события запуска; реестры и форумы сохраняют режим ранних сигналов. Лицензия сама по себе не подтверждает бизнес-IBAN.

В CRM откройте **«Настройки источников, ИИ и ежедневного поиска» → «Рынок и исключаемые юрисдикции»**. Там видны действующие коды. Изменение применяется ко всем источникам. Переключение рынка на «Другие рынки» само по себе не убирает исключённые юрисдикции.

Прежние настройки перед первой перенастройкой сохраняются в локальном `data/state.json`, в разделе `searchTuningBackup`; полная резервная копия создаётся updater. Ключи, история, комментарии, выбранная модель и расписания сохраняются. Обновление не включает новые платные задачи и не меняет аппаратный профиль. Уже включённые расписания остаются включёнными.

## Обновить установленную копию через код

Откройте новое окно **PowerShell**. По вашим скриншотам программа находится в **`C:\Users\ivano\PlayScout`**; `$env:USERPROFILE` подставит `C:\Users\ivano`. Если вы переместили папку, замените путь в первой строке.

Скопируйте весь блок:

```powershell
& {
  $ErrorActionPreference = 'Stop'
  Set-Location "$env:USERPROFILE\PlayScout"
  if (-not (Test-Path -LiteralPath '.\package.json')) { throw 'Open the PlayScout folder containing package.json.' }
  $PlayScoutUpdater = Join-Path $env:TEMP ('play-scout-bootstrap-' + [guid]::NewGuid().ToString('N') + '.ps1')
  try {
    [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
    Invoke-WebRequest -UseBasicParsing -Uri 'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-windows.ps1' -OutFile $PlayScoutUpdater -TimeoutSec 60
    & powershell.exe -NoProfile -ExecutionPolicy Bypass -File $PlayScoutUpdater -Target (Get-Location).Path -Start
    if ($LASTEXITCODE -ne 0) { throw 'Update failed. Read the error above; keep data and .env.' }
  } finally {
    if (Test-Path -LiteralPath $PlayScoutUpdater) { Remove-Item -LiteralPath $PlayScoutUpdater -Force }
  }
}
```

Скрипт скачает архив во временную папку, попросит старую программу остановиться и сохранить очередь, создаст резервную копию рядом с PlayScout, заменит код в **той же папке**, выполнит `npm ci`, диагностику и запуск. Он не переносит данные в новую папку программы. `.env`, `data`, исключения, комментарии и выбранный ИИ остаются на месте.

Дождитесь **«Готово: Play Scout 4.3.0»** и откройте **http://127.0.0.1:3000/crm**. Обновите старую вкладку один раз. При нестандартном порте используйте адрес из окна программы. Ключи заново импортировать не нужно. Окно программы оставьте открытым.

Если старая программа не отвечает на остановку, обновление не начинает замену кода. Остановите именно её старое окно через Ctrl + C, дождитесь приглашения PowerShell и повторите блок. Если установка зависимостей завершится ошибкой, updater восстановит прежний код и напечатает путь к резервной копии; перед повторным запуском может понадобиться `npm.cmd ci` в рабочей папке.

После этого для следующих обновлений доступен **`10-Update.cmd`**, либо из папки программы:

```powershell
cd "$env:USERPROFILE\PlayScout"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-windows.ps1 -Target (Get-Location).Path -Start
```

Файлы `.command` предназначены для Mac; Windows использует `.cmd` / `.ps1`. Архив скачивается с GitHub без ваших ключей; ключи берутся из существующей локальной `.env`.

## Обычный запуск

```powershell
cd "$env:USERPROFILE\PlayScout"
npm.cmd run start:desktop
```

Или **`2-Start.cmd`**. Для остановки — **`3-Stop.cmd`**, диагностики — **`6-Diagnostics.cmd`**. Не запускайте npm из `C:\Windows\System32`.

## Отдельные источники и общая база

В CRM нажмите **«Выбрать источник поиска»**. У каждого отдельного сайта, издания или реестра есть «Искать только здесь», остановка и собственное ежедневное расписание. Google Play остаётся отдельным основным источником. App Store не возвращается.

Кнопка «Находки в общей базе» включает фильтр; Word / CSV / JSON используют тот же фильтр и ручные исключения. Фильтр не создаёт другую базу. Один проект может иметь подтверждения из нескольких источников.

Если осталось прежнее общее расписание, интерфейс покажет его. Нажмите «Отключить прежние общие расписания» и включите только нужные отдельные. Время — Калининград UTC+2. Сбор и ИИ не запускаются автоматически лишь от применения аппаратного профиля.

Профиль фермы распределяет разные карточки; он не объединяет VRAM автоматически и не ускоряет ограничения Google / Brave. Цена облачного API не возникает при локальном разборе; Brave остаётся отдельным источником со своим биллингом.

Из среды разработки нельзя проверить ваш драйвер, физические GPU, PowerShell 5.1 и пропускную способность PCIe. Проверены логика обновления / отката и протокол локальных серверов; аппаратный результат измеряется на вашем компьютере по инструкции.
