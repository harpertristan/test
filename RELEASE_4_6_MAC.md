# Play Scout 4.6.0 — обновление Mac M5 / 16 ГБ

Теперь после проверки явно неподходящие записи уходят в «Автоисключения», сильные кандидаты — в «Совпадения ИИ», сомнительные остаются в «Проверить вручную». Уже завершённые разборы текущего прохода распределяются без повторной оплаты. Ваши ручные решения, очередь, ключи и выбранный ИИ сохраняются. [Подробности](RELEASE_4_6.md).

## Вставить в Терминал

Откройте **новое окно Терминала (Command + N)** и вставьте весь блок:

```bash
(
  set -e
  cd "$HOME/Desktop/play-scout-v31"

  PLAY_SCOUT_UPDATER=$(mktemp "${TMPDIR:-/tmp}/play-scout-update.XXXXXX")
  trap 'rm -f -- "$PLAY_SCOUT_UPDATER"' EXIT

  curl --fail --location --retry 2 \
    --connect-timeout 15 --max-time 60 \
    'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-mac.sh' \
    -o "$PLAY_SCOUT_UPDATER"

  bash "$PLAY_SCOUT_UPDATER" "$PWD" --start
)
```

Рабочая папка остаётся `~/Desktop/play-scout-v31`. Не вставляйте код в окно работающего Node. Updater остановит экземпляр из этой папки, сохранит резервную копию, обновит код и зависимости и запустит программу.

Дождитесь **«Готово: Play Scout 4.6.0»**, затем откройте **http://127.0.0.1:3000/crm** и обновите вкладку через **Command + R**. При переходе с 4.4 повторного сброса базы нет.

## После обновления

1. Откройте **«Совпадения ИИ»** — здесь сильные кандидаты по цитатам.
2. В **«Проверить вручную»** останутся сомнения и ещё не проверенные карточки.
3. Нажмите **«Продолжить полную проверку»** для оставшейся очереди; выбранный GPT + Ollama сохраняется. Данные источников обновляются и могут вызывать платный API выбранного облака / Brave.
4. Явный отсев доступен в **«Автоисключения»**. Кнопка «Вернуть на ручную проверку» возвращает ошибочно отсеянное. Одобрить подходящее можно кнопкой «Проверено: подходит».

Повторного сброса базы нет. Уже успешно разобранные записи не нужно отправлять всем списком заново ради смены категории.

Для меньшей локальной модели на M5 / 16 ГБ можно установить из нового окна Терминала:

```bash
ollama pull qwen2.5:3b
```

Затем укажите **`qwen2.5:3b`** в поле модели Ollama и сохраните настройки. Программа Ollama должна работать. Уменьшение модели обычно ускоряет обработку, но не гарантирует полноту вывода; точные цитаты проверяются теми же правилами. Локальная 7B остаётся доступной, если вы предпочитаете её качество. Для llama.cpp / Metal остаётся [отдельная инструкция](GPU_AGENT.md#mac-m5-16-гб).

Следующий обычный запуск:

```bash
cd "$HOME/Desktop/play-scout-v31" &&
bash ./2-Запустить.command
```

Остановка из нового окна:

```bash
cd "$HOME/Desktop/play-scout-v31" &&
npm run stop
```

Для вашего M5 / 16 ГБ остаётся [профиль llama.cpp / Metal](GPU_AGENT.md#mac-m5-16-гб). Это обновление не переключает выбранный движок, не переустанавливает модель и не включает платный API.
