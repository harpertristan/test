# LinkedIn, Facebook, YouTube и реклама

## Что подключено в Play Scout 4.0

Brave ищет **публичные индексируемые страницы** LinkedIn / Facebook, видео YouTube, публикации и библиотеки рекламы. Для такого поиска нужен ключ Brave; личные аккаунты LinkedIn и Facebook к программе не подключаются.

Добавлены цели поиска:

- YouTube: публичные видео, объявления о запуске и рекламные публикации.
- Meta Ads Library: https://www.facebook.com/ads/library/ .
- LinkedIn Ad Library: https://www.linkedin.com/ad-library/home .
- Google Ads Transparency Center: https://adstransparency.google.com/ .
- TikTok Creative Center и публичные видео: https://ads.tiktok.com/business/creativecenter/ .
- Публикации банков / EMI / BaaS-партнёров, пресс-релизы, новости, Trustpilot и сообщества.

Это **публичный поисковый индекс**, не прямое API всех рекламных кампаний. Динамические библиотеки могут почти не индексироваться, объявления могут быть недоступны по стране или аккаунту. Ссылки для ручной проверки библиотек находятся в CRM. Найденное видео / упоминание не автоматически считается подтверждённой оплаченной рекламой или релизом.

Для известных сайтов и RSS/Atom добавьте ссылки в настройках наблюдения. YouTube-канал можно наблюдать через `https://www.youtube.com/feeds/videos.xml?channel_id=ID_КАНАЛА` без отдельного ключа YouTube API. Это полезно для ранних публикаций известных каналов; все существующие каналы таким способом автоматически не перечисляются.

## Нужны ли API и аккаунты

**Для текущего поиска по публичному индексу — нет**, достаточно Brave. Полнота ограничена индексом и доступностью страниц.

**LinkedIn:** официальное чтение контента управляемых страниц требует приложения разработчика, OAuth и разрешений соответствующего продукта / уровня доступа. Обычный личный аккаунт и его API-ключ не дают глобальный поиск всех публикаций LinkedIn. Доступ к Community Management API и чтению страниц зависит от одобрения LinkedIn и роли пользователя в организации.

Документация: https://learn.microsoft.com/en-us/linkedin/marketing/community-management/community-management-overview .

**Facebook:** Graph API для страниц требует приложения Meta, токенов и разрешений. Доступ к публичному контенту страниц, которыми вы не управляете, и к рекламе ограничивается конкретными разрешениями / продуктами Meta. Личный пароль или обычный токен не открывает полный поиск всех постов Facebook. Для Ads Library API есть отдельные условия доступа и области покрытия.

Документация: https://developers.facebook.com/docs/pages-api/ , https://www.facebook.com/ads/library/api/ .

**В этой версии нет OAuth-подключения ваших управляемых страниц.** Пароли соцсетей не собираются. Добавлены публичный поиск, прямые ссылки библиотек и наблюдение за доступными страницами / RSS. Для официальных персональных интеграций сначала понадобится получить одобренный доступ в вашем приложении соответствующей платформы; это отдельный источник, а не включение универсального поиска одним ключом.

Объём конкретных API-разрешений в вашем аккаунте в среде разработки не проверен. Условия и доступность подтверждайте по официальной документации и кабинету платформы.
