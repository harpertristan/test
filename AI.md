# Нейронный поиск и раннее обнаружение — с нуля

## Что изменилось в 2.4

Ваши **37 примеров** сохранены в библиотеке: Unlimit, OFX Business, Ebury, Paynovate, Breinrock, Luminary, iSX Financial, payabl, XlentPay, Limited, Wirex, Mistertango, Xoala, ether.fi, Jetonbank, Payswix, Keytom, Satchel, Andaria business, amnis treasury, PaySaxas, Bankera, Sokin, Genome, PayDo, Kunga, Monetoria, mytu, eMoney, Axilpay, fgconboarding.com, Igson Capital, LurraPay, Rampy, Stable.com, Kleos business и PhotonPay. Название сервиса за fgconboarding.com пока не установлено. Для примеров только с названием URL и ID приложения не угадываются.

Это список подходящих **вам типов сервисов**, а не подтверждение EU IBAN или лицензии. В нём есть банки, EMI и платёжные сервисы; не следует требовать собственной банковской лицензии от всех.

Основной источник остаётся Google Play. На отдельной вкладке «Нейронный поиск» одна кнопка собирает выбранные каналы: Google Play и рекомендации, веб-сервисы, публикации / соцсети / форумы / реестры и наблюдаемые страницы / RSS / приложения. ИИ получает единый список, разбирает сведения, предлагает фильтр и комментарий с цитатами. Есть также отдельная кнопка для анализа уже собранного без нового обхода источников.

В список ИИ поступают и предварительные находки, которые обычный фильтр отправил на проверку или отверг: это помогает не потерять новый сервис из-за краткого описания. Явные пользовательские исключения сохраняют силу. Отзывы не обязательны: у нового сервиса их может не быть. Приоритет у собственных описаний продукта, FAQ и условий. Сборщик не может получить публикации, которых нет в публичной выдаче, закрытых группах или доступных лентах.

## 1. Обновить программу

1. Остановите старую программу. Если Control+C не срабатывает, закройте **её** окно Терминала и подтвердите завершение процессов.
2. [Скачайте свежий ZIP](https://github.com/harpertristan/test/archive/refs/heads/main.zip), распакуйте в новую папку. Старую папку сохраните.
3. Скопируйте **data** и **.env** из старой папки в новую. Скрытые файлы Finder: **Command + Shift + точка**. Не переносите `node_modules`.
4. Откройте **2-Запустить.command**. Обновите страницу браузера и проверьте версию **2.4.0** внизу главной страницы.

Если программа сообщает, что порт занят, работает старый процесс: сначала завершите его. Изменения на GitHub не обновляют вашу скачанную папку автоматически.

## 2. Настроить поиск раньше других

1. На главной нажмите **«Раннее обнаружение · ваши примеры»**.
2. Будут включены поиск за всё время, отсутствие порога установок, похожие приложения, другие приложения разработчика и библиотека примеров. Даже диапазон `0+` допускается. Дата выпуска старого приложения не мешает заметить новый продукт.
3. Укажите **страну аккаунта Google Play на телефоне** в дополнительных настройках, если хотите добавить соответствующую выдачу.
4. Для первого исследования используйте этот режим. Поиск «Полный» во всех 27 странах даст больше запросов; «Сбалансированный» быстрее проверит все страны и больше запросов в основных шести.
5. Нажмите **«Найти приложения»**. После первого прохода проверьте также «На проверку».
6. Сохраните ежедневное расписание. Время — **Калининград, UTC+2**.

К общим запросам ежедневно добавляются **6 названий из библиотеки по кругу**, чтобы находить их карточки и рекомендации. Весь круг названий занимает до 6 дней; это не ежедневный полный обход всех 37 брендов. Поиск карточек через Brave обрабатывает до 4 сайтов образцов за запуск по кругу внутри прежнего лимита 20 обращений на поиск приложений. Веб-поиск имеет свой лимит и ротацию.

В живом Google Play дополнительно проверены карточки PaySaxas, Breinrock, Luminary и Unlimit; их ID включены в библиотеку. Краткое описание Breinrock сохраняется на проверку, даже если в нём нет слова IBAN. Само наличие карточки не подтверждает EU IBAN.

Известные по указанным доменам и проверенным ID примеры в раннем режиме сохраняются с пометкой образца и не увеличивают счётчик новых открытий. Название само по себе недостаточно для надёжной идентификации. Впервые найденное программой приложение может существовать давно — дата первого обнаружения не является датой запуска компании.

## 3. Получить отдельный ключ OpenAI

Ваш ключ **Brave не подходит для OpenAI**. Подписка ChatGPT Plus/Pro тоже не оплачивает API.

1. Откройте [platform.openai.com](https://platform.openai.com/) и войдите в свой аккаунт.
2. Выберите или создайте проект для этой программы.
3. Откройте [Billing](https://platform.openai.com/settings/organization/billing/overview) и подключите оплату / пополните баланс API, если требуется в вашем аккаунте.
4. В настройках проекта установите уведомления о расходах. Денежный бюджет в кабинете может быть порогом уведомления, а не жёстким ограничителем; проверяйте условия вашего аккаунта.
5. Откройте [API keys](https://platform.openai.com/api-keys), нажмите **Create new secret key**, создайте ключ с доступом к Responses API и выбранной модели.
6. Скопируйте ключ. Не присылайте его в чат, не публикуйте в GitHub и не вставляйте в поисковые поля программы.

Цена зависит от модели и количества токенов. Проверяйте [актуальные цены API](https://openai.com/api/pricing/). Приложение показывает число попыток, входные и выходные токены, но не обещает фиксированную стоимость.

## 4. Сохранить ключ на Mac

1. В **новой папке программы** откройте **3-Настроить-ИИ.command**.
2. Вставьте только ключ OpenAI в запрос Терминала и нажмите Enter. Символы скрыты — это нормально.
3. Дождитесь сообщения «Ключ сохранён».
4. Остановите программу и снова откройте **2-Запустить.command**. Работающий сервер сам новый ключ не перечитывает.

Если macOS не открывает `.command`:

1. Откройте Терминал через **Command + пробел → Терминал**.
2. Напишите `cd ` с пробелом, перетащите **новую папку программы** из Finder в окно Терминала, нажмите Enter.
3. Выполните:

   ```sh
   npm run configure:ai
   ```

Ключ сохраняется в локальный `.env` с правами только владельцу. Существующий ключ Brave и остальные настройки сохраняются.

Модель по умолчанию — `gpt-5-mini`. При необходимости добавьте в `.env` отдельную строку `OPENAI_MODEL=имя-модели`, которая поддерживает Responses API и Structured Outputs, затем перезапустите. Не меняйте адрес API: обращения идут только к официальному `api.openai.com`.

На хостинге задайте `OPENAI_API_KEY` через настройки секретов хостинга, сохраните постоянный диск для `DATA_DIR` и перезапустите сервис. Не добавляйте ключ в Dockerfile или репозиторий.

## 5. Выполнить первый нейронный поиск

1. В верхнем меню откройте **«Нейронный поиск»**.
2. Отметьте все четыре источника. Для веб-поиска и публикаций нужен ваш ключ Brave; Google Play и прямое наблюдение работают независимо.
3. Статус должен показывать «Ключ OpenAI задан». Это ещё не подтверждение доступа к API.
4. Для проверки подключения поставьте **1 проверку за запуск**, **30 попыток за месяц** и нажмите **«Сохранить настройки ИИ»**.
5. Нажмите **«Собрать все выбранные источники + ИИ»**. Сначала программа собирает источники, затем отправляет находку в OpenAI. Успешный ответ API подтверждает подключение. Если находки уже собраны, можно выбрать **«Разобрать уже собранные находки»**.
6. Наблюдайте за состоянием каждого источника. Сбор Google Play по нескольким странам может занять минуты; отдельные обращения ограничены по времени. Ошибка одного канала не отменяет остальные. Проверка ИИ включает чтение страниц и ответ модели; её можно остановить.
7. После успешной проверки увеличьте объём: **30 проверок за запуск, 1000 попыток OpenAI в месяц**. Это начальный ориентир для ежедневного мониторинга, а не измеренный оптимум. Если очередь «Ещё не разобраны ИИ» растёт, можно увеличить до 50 за запуск и до 3000 в месяц.

По умолчанию известные вам образцы пропускаются. Для проверки Unlimit / Bankera / Stable и других примеров включите **«Проверять также уже известные образцы»**. Если очередь пуста, сначала выполните сбор.

Для самостоятельного поиска без ИИ используйте прежние вкладки: их история и расписания сохраняются. Сбор всех каналов соблюдает ограничения каждого источника. В публикациях включаются все рекомендованные группы в режиме сигналов: **36 пар поиска, при лимите 8 — полный круг за 5 последовательных дней**. Среди источников добавлены Business Wire, GlobeNewswire и PR Newswire. В режиме конкретных анонсов — 24 пары, круг за 3 дня. Нельзя гарантировать результат от каждого сайта в каждом запуске. LinkedIn/Facebook собираются через публичный индекс, а RSS — по указанным вами адресам лент.

## 6. Понять результат

- **Есть цитаты по критериям:** найдены свидетельства бизнес-обслуживания, предложения счёта и EU IBAN. Это утверждения источников, а не проверка открытия счёта для вашей компании.
- **На проверку:** нет части сведений, сайт недоступен, предлагается только будущий продукт или вывод не подкреплён цитатой. Находка не пропадает.
- **Похоже на неподходящий продукт:** например, IBAN-чекер или генератор. Это предложение ИИ; исключение сохраняется только после вашего нажатия **«Исключить»**.

**«Новые»** — отдельная категория находок, впервые обнаруженных в последнем сборе. Повторный источник, повторный запуск и перепроверка ИИ не делают старую находку новой. Указанные вами образцы исключаются из новых по проверенному домену, ID или подтверждённому в цитате названию. До установления связи две записи могут выглядеть как разные сервисы. В Google Play также восстановлена отдельная вкладка «Новые».

**«Ранние сигналы»** — лист ожидания, планы запуска и сигналы из реестров. Даже при наличии IBAN в описании будущий продукт остаётся на проверку. Программа различает дату первого обнаружения, дату выпуска приложения и заявление о запуске продукта.

Приложение и сайт с одним доменом разработчика объединяются, ссылки на все источники сохраняются. Статьи разных компаний не объединяются по домену издателя. Совпадения названия после анализа могут группироваться на экране с предупреждением о возможных разных юридических лицах.

У каждого признака — цитата и ссылка. Программа проверяет, что цитата есть в переданном тексте. EUR, SEPA, офис в ЕС и IBAN Британии/Швейцарии сами по себе не дают положительный EU IBAN. Страна выдачи магазина также не подтверждает страну IBAN.

Читайте цитату полностью: важны тип клиента, собственный/партнёрский счёт, конкретная страна IBAN, ограничения регистрации. Отсутствие отзывов — не доказательство мошенничества или отсутствия продукта.

## 7. Включить постоянную работу

1. На вкладке «Нейронный поиск» выберите четыре источника и включите **«Автоматически каждый день после завершения поиска»**.
2. Для полного сбора перед анализом включите также **«Перед анализом собирать все выбранные источники · нейронный автопоиск»**. Без этой галочки ИИ только разбирает уже накопленное другими расписаниями.
3. Укажите время и нажмите **«Сохранить настройки ИИ»**. По умолчанию — не раньше **09:45 по Калининграду (UTC+2)**, после завершения активных поисков. Автосбор выполняется раз в день. Уже завершённые сегодня совместимые сборы повторно используются, чтобы не дублировать запросы. Ручной полный сбор запускается отдельно и может увеличить расход.
4. Веб-поиск использует сохранённые настройки вкладки «Веб-версии»; страницы, приложения и RSS — настройки вкладки «Изменения». Добавляйте официальные продуктовые страницы, тарифы и FAQ, а не закрытые кабинеты. Источники публикаций обходятся по кругу. Отдельные старые расписания можно оставить: пригодные завершённые сборы используются повторно.
5. Для начала используйте **30 проверок ИИ за запуск, 1000 попыток OpenAI и 2000 запросов Brave за месяц**. Это ориентир с запасом для первых сборов. По умолчанию в программе установлены более низкие значения: 10 / 300 / 1000. Ручные запуски расходуют тот же месячный остаток.
6. Компьютер должен быть включён, программа запущена и иметь доступ в интернет. Для работы без Mac нужен постоянно работающий сервер с постоянным диском; браузер можно закрыть. Пока программа выключена, непрерывного наблюдения нет.

### Как увеличить Brave

В файле **.env** в папке программы добавьте или измените строку, сохранив строки ключей:

```env
BRAVE_MONTHLY_REQUEST_LIMIT=2000
```

Скрытые файлы в Finder показывает **Command + Shift + точка**. Остановите и заново запустите программу после изменения `.env`. На хостинге задайте ту же переменную в Environment и перезапустите сервис.

Это общий программный лимит Brave для всех каналов, дополнительных проверок ИИ и проверки ключа. При его исчерпании новые обращения Brave блокируются, прямой Google Play продолжается. По умолчанию — 1000 запросов в календарный месяц; счётчик виден в нейронном поиске и сохраняется после перезапуска. Увеличение лимита не пополняет баланс Brave. По тарифу со скриншота пользователя ($5 / 1000 запросов, $5 кредита в месяц) 2000 запросов — $10 до кредитов, около $5 при полностью доступном кредите; актуальные условия проверяйте в кабинете.

Увеличение лимитов позволяет обработать больше записей, но не делает одну оценку ИИ точнее и не заставляет Google Play раскрыть весь каталог. OpenAI оплачивается отдельно по модели и токенам. Дополнительно к обычным поискам ИИ может выполнить **до 3 запросов Brave за запуск**; они входят в общий месячный счётчик. Ошибки и отмена консервативно учитываются как попытки.

Сырая очередь ИИ ограничена 2000 отдельными записями: при заполнении показывается предупреждение и неполный статус. Старые записи не удаляются автоматически, обычная история подходящих находок сохраняется отдельно.

Неизвестные сведения перепроверяются не чаще раза в сутки, совпадения — раз в 7 дней, либо при изменении сохранённой карточки/модели. Смена текста на сайте сама по себе не сбрасывает кэш до следующей проверки; изменения сайтов отслеживаются также отдельной вкладкой наблюдения. Ошибки и отменённые запросы учитываются в лимите попыток консервативно, поскольку запрос мог уже уйти в API. Токены отражаются только для полученных успешных ответов.

## Чего инструмент не гарантирует

Публичная выдача Google Play неполная, рекомендации могут отличаться от телефона, поисковый индекс обновляется с задержкой. Нельзя гарантировать, что вы узнаете о каждом сервисе самым первым. Рекомендации, ротация источников, наблюдение за изменениями и отсутствие жёсткого отсечения неизвестных находок повышают шанс заметить продукт раньше. ИИ улучшает разбор найденного, но сам по себе не расширяет каталог Google Play.

В этой среде без вашего ключа реальное подключение OpenAI не проверено. После установки его проверит первый запуск с вашим ключом. Если ошибка 401/403 — проверьте ключ, модель и доступ API; 429 — баланс и квоты. Ключ в чат не присылайте.
