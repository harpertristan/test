# Ежедневный мониторинг Play Scout 2.1

**Начните с [START_HERE.md](START_HERE.md): там одна актуальная инструкция установки и обновления на Mac, подключения ключа, первого поиска и расписания.** В программе она доступна по ссылке «Инструкция с нуля».

Основной режим теперь ищет сервисы по вашим примерам: бизнес-счета, мультивалютные счета, платёжные платформы и EMI. Требование собственной банковской лицензии из основного режима убрано. Отдельный строгий профиль сохранён для явных заявлений о бизнес-счёте, EU IBAN и лицензии.

## Что означает результат

«Совпадает с профилем сервиса» не равно «подтверждено открытие бизнес-счёта с EU IBAN». Бизнес-обслуживание, IBAN, EU IBAN, SEPA и лицензия показываются раздельно с выдержками. Неизвестные свойства не выдумываются. Требование конкретного EU IBAN включается отдельно и не требует собственной банковской лицензии: EMI тоже может предлагать такой продукт.

На проверку сохраняются сервисы с неполными сведениями о бизнесе и счёте. Их можно экспортировать отдельно. Очередь и общий список не дублируют записи по app ID; разные публикации об одной компании остаются отдельными сигналами.

## Откуда берутся приложения

1. Поиск Google Play по английским запросам и нескольким местным языкам во всех выбранных странах.
2. Прямые карточки по вашим ссылкам / ID. Они помечены как образцы, а не независимые находки.
3. При наличии Brave: дополнительные карточки Google Play из веб-индекса, в том числе по доменам образцов.
4. При наличии Brave: фрагменты с домена сайта разработчика для уточнения свойств сервиса. Прямой обход всего сайта не выполняется.

Сбалансированный план выполняет больше запросов в шести основных странах, первые два — в остальных; полный выполняет все запросы в каждой стране. Число запросов и лимит карточек показаны в форме. Страна аккаунта телефона добавляется отдельно. Выдача веб-версии и телефона может отличаться из-за страны, языка, аккаунта, устройства и персонализации.

Дополнительные ссылки из карточек Google Play — экспериментальная опция, выключенная по умолчанию. В проверенных карточках публичная веб-страница не раскрыла полезных ссылок на другие приложения, а метод similar сторонней библиотеки не смог разобрать данные. Приложение не выдаёт это за работающий источник: отсутствие ссылок отображается предупреждением, поиск по запросам продолжается.

## Дата и отсутствие повторов

По умолчанию период расширен до 12 месяцев, порог установок — 0, чтобы не терять очень ранние приложения. В форме можно вернуть 1 месяц, порог 100, включить все даты или расширить период до 24 месяцев. Ежедневное расписание сохраняет выбранное число месяцев и пересчитывает окно на день запуска. Дата первого выпуска, обновления и первого обнаружения — разные поля, ни одно не доказывает дату основания компании.

Кандидаты перепроверяются при следующем поиске. Уже подходящие приложения обновляются не реже повторного поиска после семи дней и при первом подключении проверки сайта, если EU IBAN неизвестен и сайт ещё не проверялся. Повторная проверка не создаёт новую запись и не меняет дату первого обнаружения. Лимиты источника и карточек по-прежнему ограничивают полноту проверки.

В `data/state.json` хранятся все записи, кандидаты, расписания и последние 20 заданий каждого источника. Обновления JSON атомарны. Ошибка сохранения останавливает затронутый поиск, не сбрасывая историю. С одним файлом должен работать один процесс. Архив кода не содержит `data` и `.env`; переносите их при обновлении отдельно.

## Ключ и стоимость

Brave optional для Google Play. `npm run configure` сохраняет ключ в `.env`; процесс читает его при запуске. Переменная окружения процесса имеет приоритет. Значения не отдаются UI и не пишутся в историю. Кнопка проверки делает один настоящий API-запрос. Просто заданный ключ не означает успешный доступ.

Основной поиск использует до 20 обращений Brave на запуск суммарно: 2 запроса по Play, запросы по доменам образцов и уточнение сайтов. Дополнительные новости / соцсети используют отдельный лимит: до 8 обращений за запуск по умолчанию, с ротацией выбранных источников. Полный круг стандартных пар — 5 дней. Ручные повторы и проверка ключа также расходуют квоту. Ежемесячного автоматического ограничителя затрат нет: проверьте тариф в кабинете Brave.

## Работа без включённого компьютера

Mac должен быть включён, с интернетом, программа — запущена. Браузер не обязателен. Пропущенное задание выполняется один раз после запуска. `2-Запустить.command` на Mac использует `caffeinate -i` только на время работы программы; закрытая крышка или выключение не обеспечивают работу.

Для 24/7 нужен постоянно работающий сервер с постоянным диском: [CLOUD.md](CLOUD.md). Публикация кода в GitHub не развёртывает платный сервис автоматически.

## Новые источники и изменения

Список СМИ, банковских партнёров, реестров и форумов, условия доверия и стоимость: [SOURCES.md](SOURCES.md). Прямое наблюдение `/watch` работает по отдельному расписанию 09:30, сохраняет исходные состояния и события в том же файле `state.json`. Без ключа Brave оно может читать доступные публичные страницы и Google Play; работоспособность сети и DNS проверяется отдельно. RSS/Atom добавляются по точным адресам. Первое исходное состояние не считается новым запуском банка.
