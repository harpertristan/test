# Play Scout 4.8.3 — объединение карточек рекламодателя Apify

Несколько Facebook-публикаций одного рекламодателя без сайта раньше получали отдельные карточки по URL поста. Теперь явно указанное имя рекламодателя группируется внутри одного источника, независимо от пробелов и регистра: Cruise Pay Finance / CruisePay Finance. При наличии единственного связанного продуктового домена публикации входят в карточку сайта. При нескольких разных доменах карточки этих сайтов остаются раздельными; публикации без сайта остаются отдельной группой рекламодателя. Произвольные заголовки без имени рекламодателя не объединяются по имени.

Исходные URL, материалы и дата первого обнаружения сохраняются. Уже сохранённые находки объединяются при открытии базы; новые — при импорте Apify. Существующие заметки, ручные решения и ссылки очереди переносятся через локальную консолидацию идентификаторов, прежние решения и анализы сохраняются в архиве идентичностей. Формат общей очереди ИИ используется и после объединения. Сбор или платный вызов ИИ для обновления карточек не требуется.

Проверено: 18 тестов из test/provider-identity-upgrade.test.js и test/apify-social.test.js, все прошли менее чем за секунду. Полный набор тестов не запускался. Денежный параметр Apify 1 USD и предел Facebook 500 результатов не меняются.

Дождитесь завершения заданий, остановите программу, обновите через npm run update:mac и запустите npm run start:manual. Обновите страницу CRM. Перед обновлением сохраните резервную копию папки data и .env.
