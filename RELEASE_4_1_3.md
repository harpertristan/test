# Play Scout 4.1.3 — ответы интерфейса при большом списке

По ответу `/api/health` программа 4.1.1 продолжала работать, несмотря на сообщение браузера о 40 секундах. В коде найдены повторные тяжёлые пересчёты: сводка ИИ дважды строила один список, фоновая проверка статуса повторяла расчёт счётчиков, запуск четырёх источников дополнительно собирал списки.

- Неизменившиеся тексты используют кэш предварительного отбора. Новые / изменённые тексты проверяются заново. Ручные исключения, выбранные источники и допуск к ИИ считаются по актуальному состоянию и не берутся из этого кэша.
- Счётчики сводки используют один снимок кандидатов. Фоновые проверки «подключён ли ИИ / занят ли он» обходятся без перебора находок. Приоритет кандидата вычисляется один раз перед сортировкой.
- При потере ответа на запуск или продолжение браузер запрашивает активное задание. Повторный запуск автоматически не отправляется. Полученный ID восстанавливает показ прогресса.
- Ошибка обновления списка отличается от неопределённого результата записи. Устаревшее сообщение об ошибке опроса убирается после успешного восстановления связи.
- Предел ожидания браузера остаётся 40 секунд. Ключи, история, исключения, очередь и выбранная модель сохраняются; автоматического повторного платного разбора нет.

На синтетическом списке из 1500 записей с длинными текстами повторный расчёт сводки на тестовой машине сократился примерно с 12 до 2 секунд. Это замер обработки списка, а не скорости локальной модели. Первое чтение новых текстов требует полного отбора. Временные ограничения Google Play остаются ограничениями источника; очередь продолжения сохраняется.

## Обновить Windows в существующей папке

В новом PowerShell выполните:

```powershell
cd "$env:USERPROFILE\PlayScout"
node .\scripts\stop-desktop.js
```

Дождитесь сообщения об остановке. Сохраните личную резервную копию папки `data` и файла `.env`. Затем:

1. [Скачайте ZIP](https://github.com/harpertristan/test/archive/refs/heads/main.zip) и извлеките его в отдельную временную папку.
2. Откройте распакованную папку, где сразу виден `package.json`.
3. Скопируйте **всё её содержимое** в прежнюю `%USERPROFILE%\PlayScout` с заменой файлов кода. **Прежнюю папку PlayScout не удаляйте.** Архив не содержит `data` и `.env`, поэтому при таком объединении они остаются на месте.
4. В PowerShell выполните по очереди:

```powershell
cd "$env:USERPROFILE\PlayScout"
npm.cmd ci
npm.cmd run start:desktop
```

Запуск выполняйте после успешного завершения установки. Обновите старую вкладку браузера. Ожидаемая версия — 4.1.3; ключи повторно импортировать не нужно.
