# Play Scout 4.1.4 — исправление команды обновления Mac

Команда `npm run update:mac -- --start` в старом скрипте принимала `--start` за рабочую папку и завершалась с `cd: --start: No such file or directory`. Ошибка возникала до скачивания и замены кода. Инструкция теперь передаёт путь явно, поэтому подходит и для установленной версии 4.0.2.

Откройте новое окно Терминала и выполните обе строки:

```sh
cd "$HOME/Desktop/play-scout-v31"
npm run update:mac -- "$PWD" --start
```

Скрипт скачает актуальную версию, проверит и остановит сервер из этой папки, создаст резервную копию, заменит код, установит зависимости и запустит CRM. Рабочая папка, `.env`, история, ручные исключения и настройки сохраняются. Ключи повторно вводить не нужно.

После установки ожидается строка `Готово: Play Scout 4.1.4` и открытие CRM. Если окно не открылось автоматически, используйте http://127.0.0.1:3000/crm (при стандартном порте). Терминал с работающей программой оставьте открытым.

Новый скрипт также принимает `--start` без пути (использует текущую папку) и параметры перед явным путём. Пропущенное значение `--source`, неизвестный флаг или две рабочие папки завершаются понятной ошибкой до изменения файлов.

Это исправление Mac-updater; правила поиска и настройки ИИ не меняются. Проверки обновления выполнены в Linux с путями, содержащими пробелы и кириллицу; нативный Mac здесь недоступен. Полный порядок и обходные варианты: [MAC.md](MAC.md).
