# Play Scout 2.4.0

Поиск новых бизнес-счетов и платёжных сервисов в **Google Play**. Профиль настроен под примеры Stable.com, Kleos, LurraPay, Rampy и PhotonPay: собственная банковская лицензия не обязательна, свойства счёта показываются отдельно и не выдумываются.

## Автоматический поиск по новым источникам

На странице **«Изменения и компании»** нажмите **«Включить весь ежедневный мониторинг»**. Это включает Google Play, веб-поиск, публикации с дневной ротацией и отдельное наблюдение за страницами/лентами/карточками. [Источники, форумы и правила проверки](SOURCES.md).

- 19 групп источников: профильные СМИ, BaaS-партнёры, рассылки, Reddit, бизнес-форумы, реестры и каталоги. 18 рекомендованных групп выбраны; «Мои сайты» включается при заполненных доменах.
- До 8 запросов Brave за запуск публикаций; 24 активные пары в режиме анонсов проходят за 3 последовательных дня. Лимит можно изменить. Ручные повторы оплачиваются отдельно.
- `/watch`: изменения точных публичных страниц и найденных приложений, RSS/Atom по заданным адресам, история исходных состояний, CSV и группы компаний с пометкой неподтверждённых связей.
- Расписания: Google Play 09:00, публикации 09:15, веб-сервисы 09:20, изменения 09:30 по Калининграду. Существующее время и отключение расписаний при обновлении сохраняются.

## Исправление 2.3.2

Убран зависающий ограничитель запросов библиотеки Google Play: после сетевой ошибки он мог блокировать следующие обращения до 30-секундного предела. Вместо него действует прерываемая очередь стартов HTTP-запросов с интервалом 500 мс, включая страницы выдачи. После трёх последовательных сбоев выдачи или сетевых ошибок чтения карточек поиск останавливается с сообщением об источнике и сохраняет очередь; недоступная карточка (404) не считается сбоем подключения. Успешный ответ сбрасывает счётчик ошибок.

Другие исправления ожиданий: первая страница выдачи сохраняется при сбое пагинации с явным статусом неполного поиска; повторный токен пагинации прерывается. Отмена освобождает общую очередь Brave даже при запросе, который не завершился. Некорректные редиректы и оборванные ответы обрабатываются как ошибки. При выходе сервер сохраняет очередь, затем закрывает незавершённые соединения браузера; повторный сигнал не запускает параллельное завершение. Все вкладки ограничивают ожидание ответа локального API 40 секундами без автоматического повторения операций записи.

После обновления с переносом `data` и `.env` нажмите «Продолжить проверку», если есть сохранённая очередь. Для диагностики с Mac выполните из папки проекта `npm run doctor -- --play`: два настоящих обращения к Google Play, без Brave, изменения истории или вывода ключа. Исправление зависания не гарантирует доступность Google Play из конкретной сети.

## Остальные возможности

- Английские и местные запросы: business account, corporate account, IBAN account, multicurrency account, SEPA account и другие.
- Все выбранные страны ЕС; сбалансированный или полный план, дополнительная страна аккаунта телефона.
- Прямые ID и ссылки из Google Play с телефона. Образцы помечаются отдельно от независимо найденных приложений.
- Дополнительный поиск карточек в индексе Brave, поиск по доменам образцов и проверка фрагментов сайта разработчика.
- Основной профиль включает бизнес-счета / EMI / платёжные сервисы. Отдельный строгий профиль требует явных заявлений о бизнес-счёте, EU IBAN и лицензии.
- IBAN, EU IBAN, бизнес-обслуживание, SEPA и лицензия — отдельные поля со статусом «упомянуто / не подтверждено». EUR и SEPA не доказывают EU IBAN.
- Отдельная очередь кандидатов с неполными сведениями, постоянная история, CSV, исключения по словам, доменам и ID.
- Ежедневное расписание по Калининграду, выбранный период 1–24 месяца или все даты, без повторов по package ID.
- По умолчанию 12 месяцев и порог установок 0, чтобы не терять ранние приложения. Категория Finance, бесплатная загрузка. Условия меняются в форме.

## Запуск для разработчика

Node.js 22+, проверено на 24:

```sh
npm ci
npm run configure
npm start
```

`npm run configure` необязателен для Google Play; сохраняет ключ Brave Search API в локальный `.env` с закрытыми правами. Сервер загружает `.env` при запуске, переменные процесса имеют приоритет. Ключ не сохраняется в истории и не отправляется клиенту. Через интерфейс можно проверить API одним запросом.

Основные переменные: `PORT` (3000), `HOST` (0.0.0.0), `DATA_DIR` (`./data`), `APP_PASSWORD` (логин admin), `BRAVE_SEARCH_API_KEY` (необязательный для Google Play). `/api/health` сообщает версию и работоспособность сервера, но не источников. UI и остальные API защищены паролем, если задан `APP_PASSWORD`; Render требует его.

## Данные и обновление

**Сохраняйте `data` и `.env` при обновлении.** Один процесс на один файл `state.json`. Хранилище атомарно заменяет JSON, записывает находку до показа и не сбрасывает повреждённую историю. Без переноса истории другой экземпляр будет считать старые приложения новыми.

При обновлении до 2.3 к сохранённым источникам однократно добавляются рекомендованные группы; запросы, исключения, свои домены, история и включение расписаний сохраняются. Новое наблюдение получает отдельный раздел `watch` в том же файле.

При обновлении 1.x настройки без поля профиля переводятся на профиль примеров: 12 месяцев, порог 0, новые запросы. История, страны, время, включение, пользовательские исключения и ID сохраняются. Старые полные настройки дополнительно сохранены в `previousSearchFilters`. Старые стандартные исключения стран заменяются исключениями типов мусорных приложений; собственные исключения сохраняются. Явно выбранные профили не заменяются при следующем запуске.

Пропущенное ежедневное задание выполняется один раз после возобновления работы. Компьютер должен работать, процесс не должен быть остановлен. Браузер не нужен. Для облака требуется постоянный диск и постоянно работающий сервис.

Он не гарантирует обнаружение всех новых приложений, фактическую установку в стране, доступность открытия счёта для вашей компании или дату основания банка. Новая дата релиза и дата первой находки — разные сведения. Новые продукты компаний дополнительно ищутся на странице «Сайты и публикации».
