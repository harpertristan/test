# Play Scout

Веб-инструмент для поиска новых финансовых приложений Google Play в странах ЕС. Интерфейс и CSV на русском языке. Для базового Google Play API-ключ и база данных не нужны. Строгая проверка по умолчанию использует описание; индекс сайта разработчика дополнительно проверяется при наличии ключа Brave.

**Новое в 1.2:** [ежедневный поиск публичных публикаций LinkedIn/Facebook](SOCIAL.md) о запуске необанков и бизнес-счетов в Европе. Для этого отдельного источника нужен Brave Search API; Google Play работает без ключа. Перейдите в «Сайты и публикации» через меню или верхнюю ссылку. Старые данные и расписание Google Play сохраняются.

**Запуск без включённого компьютера:** см. [пошаговую инструкцию для Render](CLOUD.md). В проекте есть Dockerfile и render.yaml с постоянным диском и защитой входа паролем.

**Версия 1.3:** строгий отбор бизнес-счёта с EU IBAN и заявленной банковской лицензией; исключения по словам, ID и доменам; Finextra, Sifted, Tech.eu, EU-Startups, App Store и свои сайты. Старые находки сохранены в архиве. [Обновление на Mac и подключение ежедневного мониторинга](MONITORING.md).

## Запуск

Требуется Node.js 22 или новее (проверено на Node.js 24).

```sh
cd /workspace/test
npm ci --cache /tmp/play-finder-npm-cache
npm start
```

Сервер слушает порт 3000. `PORT` и `HOST` позволяют изменить порт и адрес привязки. Откройте интерфейс через доступный в вашей среде доступ к этому порту. Для локальной проверки сервера: `curl -f http://127.0.0.1:3000/api/health`. Этот endpoint подтверждает работу сервера, но не доступность Google Play.

## Ежедневный поиск и отсутствие повторов

Автопоиск включён по умолчанию: **каждый день в 09:00 по Europe/Kaliningrad (UTC+2)**, независимо от часового пояса сервера. Время, включение и фильтры сохраняются кнопкой «Сохранить расписание». В расписании используются запросы, страны, порог установок и глубина выдачи из формы. Период даты первого выпуска каждый раз пересчитывается на последний календарный месяц.

При первом запуске после 09:00 поиск начинается сразу. Если программа была выключена или сервер спал, один пропущенный поиск выполняется после возобновления работы; программа не воспроизводит отдельные задания за каждый пропущенный день. Для ежедневной работы процесс должен быть постоянно запущен. Браузер при этом можно закрыть. На локальном компьютере нужен включённый компьютер, в облаке — постоянно работающий сервер с постоянным диском.

В «Новые за последний поиск» попадают **только впервые найденные подходящие приложения**. «Все находки» хранит общий список, без повторов. Идентификатор — package ID, не название: переименование или новая страна не создают второй записи. Кандидаты, не прошедшие фильтры, не считаются найденными: они могут попасть в список при следующей проверке, если начнут соответствовать условиям.

Находка записывается на диск до появления в списке. Файл `data/state.json` содержит общий список, последние 20 заданий и расписание; при обновлении используется атомарная замена файла. После перезапуска история сохраняется. Прерванный выключением автопоиск повторяется при запуске, уже сохранённые находки при этом исключаются. Остановка кнопкой пользователя не вызывает немедленного автоповтора.

**Не удаляйте папку `data` при обновлении приложения.** Делайте резервные копии `state.json` при остановленном процессе. Для другого расположения задайте `DATA_DIR`; в Render используется `/var/data` на постоянном диске. Работать с одним файлом должна одна копия программы. При ошибке чтения история не сбрасывается автоматически. CSV предназначен для просмотра, для восстановления истории нужен `state.json`.

Старые версии хранили результаты только в памяти. Уже потерянные при выключении результаты восстановить автоматически нельзя. При переносе на другой компьютер или в облако перенесите существующий `state.json` отдельно, иначе история начнётся заново. Ранее выданный архив не содержит обновлённую функциональность; скачайте свежий.

## Фильтры по умолчанию

- Категория `FINANCE`, бесплатная загрузка.
- Подтверждённый минимальный диапазон установок **строго больше 100**. Google Play показывает глобальные диапазоны; `100+` не доказывает превышение 100 и исключается, `500+` проходит. Это не установки только в ЕС.
- Дата **первого выпуска** от соответствующего дня предыдущего месяца до сегодняшнего дня включительно, часовой пояс Europe/Kaliningrad. Конец месяца корректно ограничивается последним днём предыдущего месяца. Дата обновления не используется; приложения без даты выпуска исключаются с отдельным счётчиком.
- Запросы: `бизнес аккаунт`, `бизнес банк`, `бизнес счет`, язык выдачи — русский. Английские варианты добавляются отдельной кнопкой по желанию.
- Все 27 стран ЕС. Достаточно присутствия в выдаче **одной** выбранной страны. В таблице и CSV перечисляются только страны, в выдаче которых приложение действительно найдено.

Каждый запрос выполняется для каждой выбранной страны. Карточки проверяются отдельно, язык карточек английский для однозначного разбора дат. Дубликаты объединяются по package ID. Проверка карточки выполняется в первой успешной стране из найденных, указанной в `detailCountry` API; это не проверка тарифа или возможности установки во всех перечисленных странах.

Фильтры редактируются. Результаты сортируются по дате или установкам и экспортируются в UTF-8 CSV с BOM, разделитель `;`, совместимый с Excel. CSV включает статус поиска и время проверки. Запросы выполняются последовательно с паузами; пагинация ограничена двумя запросами в секунду. Остановка прерывает дальнейшую обработку после завершения текущего сетевого запроса.

## Источник и ограничения

Нужен исходящий HTTPS-доступ к **play.google.com**. Поддерживается существующий `HTTPS_PROXY` / `https_proxy`; значения прокси не сохраняются в проекте. Проверка TLS остаётся включённой.

Google Play не предоставляет публичного полного поиска по дате выпуска. Инструмент фильтрует публичную ранжированную выдачу: до 50, 100 или 250 приложений на запрос и страну. Он **не гарантирует нахождение всех новых приложений**. Отсутствие в выдаче не доказывает недоступность приложения в стране. Присутствие в выдаче не подтверждает установку с конкретным аккаунтом или местонахождение разработчика. Бесплатная загрузка не означает бесплатные банковские услуги.

Используется сторонний `google-play-scraper`, парсер может потребовать обновления при изменении Google Play. Ошибки источника не выдаются за отсутствие совпадений: есть статусы `failed`, `partial`, `cancelled` и подробности пропущенных карточек. Неизвестные даты и установки не угадываются.

Одновременно выполняется один поиск: ручной и ежедневный не пересекаются. История и последние 20 заданий сохраняются на диск; общий список находок не ограничен последними 20 заданиями. При заданном `APP_PASSWORD` интерфейс и API защищены входом с логином `admin`; `/api/health` доступен хостингу без пароля. В облачной конфигурации Render пароль генерируется автоматически. Пользуйтесь облачным интерфейсом через HTTPS.

## Проверки

```sh
npm test
npm run check
```

Тесты проверяют границы дат и установок, 27 стран ЕС, объединение результатов, правило одной страны, ошибки источника, отмену, CSV, HTTP, ежедневное расписание, перезапуски, атомарное сохранение находок, отсутствие повторов, повреждение файла, отказ записи и защиту паролем. Тестовый источник подставляется только в тестах; `npm start` всегда обращается к Google Play.

## Проверка живого поиска

Запустите поиск из интерфейса. При сетевом отказе 403 разрешите `play.google.com` в настройках среды, примените изменения и повторите запрос. В облачной среде черновик сетевых правил сам по себе не изменяет работающую машину.

При проверке 19 октября 2026 года полный первый автопоиск выполнил все 81 сочетание трёх исходных запросов и 27 стран ЕС, проверил 125 уникальных карточек без ошибок. Новых подходящих приложений не найдено: 61 карточка была другой категории, 64 — вне периода первого выпуска. Это результат публичной выдачи с глубиной 100 на запрос и страну, а не гарантия полноты каталога. Также отдельно проверены поиск по Германии и получение карточки Revolut. Первоначальный отказ прокси 403 устранён после добавления домена в настройки. Тесты на подставном источнике сами по себе не подтверждают живой поиск. Запуск с IP-адреса вашего будущего хостинга ещё не проверен.
