# Помощник регистраций компаний · первая версия 0.1

Отдельный проект для трёх пользователей. Приоритет — Windows и Dolphin **307.36437**; то же расширение предназначено для Chromium-профилей на macOS. Это исходный код и проверяемый прототип, а не опубликованный сервис. Совместимость с настоящим Dolphin и банковскими сайтами должна быть проверена на устройстве пользователя.

Помощник показывает панель поверх открытой анкеты. Он предлагает подтверждённые сведения с цитатой, объясняет вопросы на русском при подключённом API и вставляет значение только после нажатия пользователя. Анкеты не отправляются, подписи и юридические подтверждения не проставляются.

## Что уже реализовано

- Отдельные учётные записи и карточки компаний. Карточки разных пользователей изолированы; совместное редактирование одной карточки несколькими пользователями пока не реализовано.
- Загрузка до 8 PDF / DOCX / TXT / PNG / JPG за один раз. До 15 МБ на файл; до 60 текстовых или до 8 сканированных страниц в PDF. Фото — до 16 мегапикселей.
- Чтение текста и локальное OCR английского / русского на сервере. Документы не отправляются во внешний ИИ. OCR может ошибаться; пользователь сверяет значения с оригиналом.
- Добавление сведений из блокнота через текстовую заметку. Заметка — утверждение пользователя, а не независимое подтверждение.
- Сохранение факта только с цитатой из источника и явным подтверждением пользователя. Реквизиты не извлекаются сразу в «проверенную» карточку: пользователь выбирает тип, значение и цитату. Автоматическое структурированное извлечение — следующий этап.
- Сверка стандартных названий полей, показ источника и вставка по нажатию. Незнакомое поле можно сопоставить с подтверждённым значением вручную в панели. Перевод или транслитерация самого значения не выполняются незаметно.
- Отслеживание изменения полей страницы через DOM. В расширении нет скриншотов, удалённого управления браузером или передачи уже введённых значений полей.
- Исправления текстом, привязанные к пользователю через компанию, домену и названию поля. Исправление останавливает обычное предложение на соответствующем поле. Это проверяемая память правил, не дообучение весов модели и не полноценный разговорный чат.
- Необязательный API для перевода и объяснения вопроса. В API передаётся текст вопроса, без карточки компании и документов. Введённые значения полей не отправляются.

## Самый простой порядок работы

1. Администратор один раз разворачивает сервер по [инструкции](docs/SERVER.md), создаёт до трёх пользователей и передаёт каждому его логин / пароль по защищённому каналу.
2. Пользователь открывает HTTPS-адрес сервиса и входит.
3. Создаёт карточку компании, загружает документы или добавляет заметку.
4. Выбирает документ и страницу. Выделяет цитату, нажимает «Использовать выделенную цитату», указывает тип и точное значение. Сверяет оригинал, отмечает подтверждение, сохраняет.
5. Устанавливает расширение по [инструкции Windows / Dolphin](docs/WINDOWS-DOLPHIN.md).
6. Открывает анкету в Dolphin и нажимает значок расширения. Выбирает нужную компанию.
7. Читает подсказку и источник, нажимает «Вставить в это поле». Для неизвестных полей использует «Выбрать поле и данные вручную».
8. Если помощник ошибся в смысле поля, пишет исправление внизу панели. Значение карточки исправляет отдельно в веб-интерфейсе.
9. Самостоятельно проверяет итоговую анкету и отправляет её.

## Запуск для разработки или предварительной проверки на Windows

Этот вариант необязателен: при работе с сервером пользователям Node.js устанавливать не нужно.

1. Установите **Node.js 24 LTS** с https://nodejs.org. При установке оставьте стандартные параметры.
2. Распакуйте проект в постоянную папку, например `C:\RegistrationAssistant`.
3. Дважды нажмите `Install-Windows.cmd`. Дождитесь установки, придумайте логин латиницей и пароль от 14 символов. Пароль вводится скрыто.
4. Дважды нажмите `Start-Windows.cmd`. Не закрывайте это окно, пока пользуетесь сервисом.
5. В обычном браузере откройте `http://127.0.0.1:3100` и войдите. Для локальной проверки именно этот адрес, не `localhost`.
6. Для второго / третьего пользователя откройте терминал в папке проекта и выполните `node scripts/create-user.js`.

По умолчанию сервер слушает только этот компьютер. Не меняйте `HOST` на публичный адрес для обхода настройки HTTPS. На рабочем сервере используйте инструкцию Docker / Caddy.

На macOS для предварительного запуска установите Node.js 24, в терминале перейдите в папку проекта и выполните:

```sh
npm ci --ignore-scripts
node scripts/create-user.js
npm start
```

Нативный запуск на Windows / macOS в текущем облачном стенде не проверен.

## Проверки разработчика

```sh
npm ci --ignore-scripts
npm run check
npm test
node scripts/verify-browser.js
```

Последняя команда требует установленный Chromium. На Linux он определяется автоматически; для другой системы задайте `CHROMIUM_PATH` как путь к исполняемому файлу Chromium. Используются только синтетические документы и тестовая анкета. Runtime расширения в этой проверке имитируется: проверяются реальный веб-интерфейс, DOM панели и серверные запросы. Настоящие банки и платные API тесты не вызывают.

`node scripts/verify-extension.js` — отдельная проверка с настоящей загрузкой расширения в тестовый Chromium-профиль. В облачном стенде она заблокирована администраторской политикой браузера, запрещающей распакованные расширения. Она не считается пройденной и не заменяет проверку в Dolphin на Windows.

## Границы первой версии

Универсальная поддержка любых сайтов не заявляется. Доступны обычные подписанные поля верхнего документа. Поля внутри iframe, закрытого Shadow DOM, canvas и нативных банковских приложений не читаются. Сложные адресные формы, разделение имени по частям, юридические вопросы и преобразования форматов часто требуют решения пользователя. Для списков выбирается только единственное точное соответствие; подтверждения и флажки заполняются вручную.

Существующее значение поля заменяется только после дополнительного подтверждения. Перед вставкой повторно проверяются актуальность факта и соответствие текущей страницы. Сайт может дополнительно преобразовать значение; проверка пользователем обязательна. Панель закрывается кнопкой ×; повторное нажатие значка открывает её снова. Она может перекрывать часть формы — её можно временно скрыть.

Первое OCR занимает больше времени, чем чтение готового текста. Очередь OCR ограничена, документы обрабатываются по одному, чтобы не замораживать веб-сервер. Нельзя обещать постоянную задержку без измерения на выбранном сервере.

На сервере хранятся оригиналы, извлечённый текст, подтверждённые значения и исправления. Данные защищены авторизацией и файловыми правами; отдельное прикладное шифрование файлов пока не реализовано. Для рабочего использования нужны HTTPS, шифрование диска / резервных копий и ограниченный доступ администратора. Удаление компании удаляет её действующие данные и оригиналы; копии живут до удаления резервных архивов. Общая история действий, 2FA, антивирусная проверка загрузок и восстановление пароля через интерфейс в прототип не входят.

Сведения о моделях, бюджете и подключении API: [MODELS.md](docs/MODELS.md). Публичное развёртывание не выполнено автоматически: нужны сервер и домен пользователя.
