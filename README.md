# Play Scout 3.0

Единое рабочее место для поиска бизнес-счетов, сервисов с EU IBAN и криптобанков: Google Play, Apple App Store, веб-сервисы, публикации, партнёры, Trustpilot, европейские регуляторы и наблюдение за страницами.

**[Подробная инструкция с нуля для Mac](START_HERE.md)** · **[Скачать ZIP](https://github.com/harpertristan/test/archive/refs/heads/main.zip)**

```sh
npm ci
npm run configure
npm run configure:ai
npm start
```

Открыть **http://localhost:3000/crm**. Требуется Node.js 22+. Google Play и Apple Search работают без ключей; Brave — для веб-индекса, OpenAI — для анализа и перевода. Ключи вводятся скрыто и хранятся в `.env`, отдельно от результатов.

При обновлении перенесите старые `data` и `.env` в новую папку. Они сохраняют находки, историю, ручные решения и ключи. Не публикуйте их.

## Что изменилось

- CRM всех источников: новые, на проверку, подходит, наблюдать, итоговый список, неподходящие, ручные и автоматические исключения.
- Нигерия / NGN / naira / домены .ng исключаются из рабочего списка и ИИ-очереди; причина доступна для аудита.
- Google Play: категории «Финансы», «Бизнес», «Продуктивность», «Инструменты»; рекомендации и приложения разработчика. Коннектор не отсекает выдачу после 250 результатов, читает доступную пагинацию. Карточки проверяются во время сбора.
- Apple App Store: прямой поиск Apple по странам ЕС, отдельно от веб-индекса. Ограничения и ошибки Apple показываются как ошибки источника.
- Все заданные запросы выполняются без программной квоты; лимиты старых настроек снимаются при миграции. Ограничения самих API, паузы и тайм-ауты сохраняются.
- ИИ собирает цитаты с официальных страниц и описаний, использует дополнительные веб-источники, анализирует по мере сбора и переводит полученные тексты на русский с сохранением оригинала.
- Отдельная выборка **EMI** и **MiCA / CASP**. Только цитаты официальных регуляторов могут стать сведением о разрешении; заявки, VASP и неизвестные даты отмечаются отдельно.
- Экспорт CRM в Word, CSV и JSON для разбора в ChatGPT. Выбор вкладки и ручные исключения учитываются. Выгрузка не запускает платный анализ.

«Новый» означает впервые найденный проект, а не новую компанию. EUR / SEPA / наличие офиса в ЕС не подтверждают выдачу компании IBAN страны ЕС. Пометка о веб-кабинете показывает упоминание / опубликованную ссылку; вход не выполняется. Маркетинговые заявления и регуляторные записи не гарантируют открытие счёта.
