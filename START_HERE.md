# Play Scout — запуск на Windows и Mac

Актуальная версия **4.1.4**. Для чистого запуска на Windows без истории: **[WINDOWS.md](WINDOWS.md)**. Используйте файлы `.cmd`: импорт только ключей — `9-Import-keys-only.cmd`, установка — `1-Install.cmd`, запуск — `2-Start.cmd`.

Для Mac полная инструкция находится в **[MAC.md](MAC.md)**:

- **[Обновить существующую папку одной командой](MAC.md#1-обновить-уже-установленный-play-scout-одной-командой)** — код скачивается и обновляется на месте; `data`, `.env`, история и исключения сохраняются. Резервная копия создаётся автоматически.
- **[Запуск и остановка](MAC.md#3-обычный-запуск-после-обновления)** — `2-Запустить.command` / `5-Остановить.command`.
- **[Локальный ИИ и выбор модели](MAC.md#5-локальный-ии-для-вашего-mac-с-apple-silicon-и-16-гб)** — сначала экономный режим и одна карточка.
- **[Ключи Brave / OpenAI / Gemini](MAC.md#6-ключи-поиска-и-облачного-ии)** — прежние ключи повторно вводить не требуется.
- **[Чистая установка](MAC.md#9-если-нужна-установка-с-нуля)** и **[диагностика](MAC.md#10-диагностика-и-общая-ссылка)**.

Рабочее пространство: **http://127.0.0.1:3000/crm**. Для Windows: [WINDOWS.md](WINDOWS.md).
