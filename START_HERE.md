# Play Scout 2.4.0 — инструкция с нуля для Mac

Программа ищет в Google Play финансовые сервисы вроде ваших примеров: бизнес-счета, мультивалютные счета, платёжные организации / EMI, счета с IBAN и сервисы на стыке фиата и цифровых активов. Основной источник — сам Google Play. Brave расширяет обнаружение карточек и помогает проверить сведения на сайте разработчика.

**Сначала установите новую версию.** Изменения в GitHub не обновляют программу на вашем Mac автоматически.

## 1. Установить Node.js

1. Откройте https://nodejs.org/ .
2. Выберите **LTS**, установщик **macOS (.pkg)**. Нужен Node.js 22 или новее; версия 24 проверена.
3. Откройте скачанный установщик и завершите установку.

## 2. Скачать и разместить программу

1. Откройте [ссылку скачивания ZIP](https://github.com/harpertristan/test/archive/refs/heads/main.zip).
2. В папке «Загрузки» дважды нажмите `test-main.zip` — появится папка `test-main`.
3. Выделите эту папку, нажмите Enter, назовите её **play-scout**, снова нажмите Enter.
4. Перетащите **play-scout** на Рабочий стол.

**Если у вас уже работала старая версия:**

1. В её Терминале нажмите **Control + C** и дождитесь строки ввода.
2. Сохраните копию старой папки.
3. Скопируйте её папку **data** в новую папку **play-scout**. Это история, исключения и расписания.
4. Перенесите файл **.env**, если сохраняли ключ. Чтобы увидеть скрытые файлы Finder: **Command + Shift + точка**. Не копируйте `node_modules`.

Не удаляйте историю для исправления поиска. Если данные не перенести, новая папка будет считать все приложения ранее не найденными.

## 3. Подключить ваш ключ Brave

У вас уже есть ключ. Используется ключ **Search API** из кабинета Brave, активированный тариф Search.

1. В новой папке откройте **1-Настроить-ключ.command**.
2. Появится Терминал с запросом ключа. Вставьте **только значение ключа** и нажмите Enter.
3. Символы при вводе не показываются. Это нормально.
4. После сообщения об успешном сохранении нажмите Enter, чтобы закрыть окно.

Ключ сохраняется в локальный `.env` с правами только владельцу файла. Другие настройки `.env` сохраняются. Не публикуйте этот файл и не присылайте ключ в чат. Если программа уже была запущена, остановите её и запустите снова: работающий процесс сам не перечитывает новый ключ.

**Если macOS не открывает .command или пишет, что разработчик не проверен:**

1. Нажмите **Command + пробел**, напишите **Терминал**, нажмите Enter.
2. Вставьте и выполните:

   ```sh
   cd ~/Desktop/play-scout
   npm run configure
   ```

3. Вставьте ключ в скрытый запрос и нажмите Enter.

Если появляется `command not found: node` или `npm`, завершите установку Node.js и заново откройте Терминал.

## 4. Запустить программу

1. В папке **play-scout** откройте **2-Запустить.command**.
2. При первом запуске он установит зависимости. Дождитесь завершения.
3. В браузере откроется программа. Если браузер не открылся, введите в адресную строку:

   ```text
   http://localhost:3000
   ```

4. Внизу страницы должна быть **версия 2.4.0**. Оставьте Терминал открытым.

Если файл запуска не открывается, в Терминале выполните:

```sh
cd ~/Desktop/play-scout
bash ./2-Запустить.command
```

Обычный запуск вручную тоже работает:

```sh
cd ~/Desktop/play-scout
npm ci
npm start
```

Если программа сообщает, что порт 3000 уже занят, найдите старое окно с `npm start`, нажмите там Control+C, затем откройте новый файл запуска. Новая версия и новый ключ применяются после перезапуска.

При первом запуске после 09:00 ежедневный поиск может начаться сразу. Если он уже идёт, дождитесь завершения или остановите кнопкой в интерфейсе, прежде чем запускать другой.

## 5. Проверить подключение Brave

1. На главной найдите кнопку **«Проверить ключ Brave · 1 запрос»**.
2. Нажмите её и дождитесь **«Подключение работает»**.
3. Если показана ошибка, проверьте активацию Search API в Brave, квоту и сохранение ключа в **этой** папке. После изменения ключа перезапустите программу.

Наличие ключа само по себе не подтверждает подключение. Эта кнопка делает один настоящий запрос к API; ключ не отображается. Google Play продолжает работать и без Brave.

## 6. Первый полезный поиск

1. Для сравнения с ручным поиском нажмите **«Широкий каталог + рекомендации»**. Он ищет за всё время, выполняет все запросы по выбранным странам, обходит похожие приложения и приложения разработчиков. История и ваши исключения сохраняются. Для отбора недавно выпущенных приложений отдельно снимите «За всё время» и задайте даты.
2. Проверьте настройки:

   - **Профиль:** «Как ваши примеры · бизнес-счета, EMI, платёжные сервисы».
   - **EU IBAN:** «Показывать похожие сервисы, неизвестный EU IBAN отмечать».
   - **Дата:** **«За всё время»** для первого каталога. Tide EU, Bankera, HYPE Business и Wamo выпущены в 2021–2024 годах, поэтому фильтр первого выпуска за последний месяц их исключает. Новые продукты старых банков ищутся отдельно в анонсах.
   - **Установок более:** **0**, чтобы видеть самые ранние приложения. Для прежнего условия можно поставить **100**: диапазон `100+` тогда исключается, так как он не доказывает строго больше 100.
   - **Страны:** страны ЕС. Это география выдачи, а не подтверждение установки или юрисдикции компании.
   - **Бесплатная загрузка**, категория **Финансы**.

3. Для поиска, близкого к вашему телефону, раскройте **«Дополнительные источники и лимиты»** и впишите код страны аккаунта Google Play: например **RU**, **DE**, **GB**. Этот поиск добавляется к выбранным странам ЕС. Устройство может получать персонализированную выдачу, поэтому полного совпадения всё равно не гарантируется.
4. Нажмите **«Найти приложения»** вверху формы. Поиск по многим странам занимает несколько минут. Видны текущий запрос и проверка карточек.

Для первого сравнения с телефоном можно выбрать одну страну и 2–3 запроса, затем расширить поиск. Сбалансированный план выполняет все запросы в Германии, Литве, Ирландии, Нидерландах, Франции и Испании (если они выбраны), первые два запроса — в остальных выбранных странах. Добавляются местные запросы для нескольких стран. Полный план проверяет каждый запрос в каждой выбранной стране. Фактическое число запросов показано в форме.

## 7. Как читать результаты

- **Результаты поиска:** новые и подходящие сохранённые записи, связанные с текущей выдачей. Старые помечены «Из истории» и не требуют повторного добавления. Счётчик «Новых за поиск» учитывает только первые находки.
- **Все находки:** накопленный список без повторов по ID приложения, в том числе после перезапуска.
- **На проверку:** финансовые сервисы, где бизнес-обслуживание или нужные свойства счёта неясны.
- **Ваш образец · прямая проверка:** карточка добавлена из известного ID или ссылки. Это не независимое обнаружение по общим запросам. Если карточка также была в поисковой выдаче, показана и эта метка.

У каждой записи раскрывается описание отбора:

- **Бизнес:** упомянут или не подтверждён.
- **IBAN:** упомянут или не подтверждён.
- **EU IBAN:** есть явное заявление источника об IBAN страны ЕС или не подтверждён.
- **SEPA:** упомянут или не подтверждён.
- **Лицензия:** заявление источника, если найдено. В основном профиле собственная банковская лицензия не обязательна.

**Euro IBAN, EUR или SEPA не подтверждают сами по себе IBAN страны ЕС.** Выберите режим «Требовать явное заявление об IBAN страны ЕС», если хотите оставить только такие заявления; остальные подходящие записи потребуют проверки. Это всё равно не проверка реестра регулятора и не гарантия открытия счёта вашей компании. Уточняйте юридическое лицо, доступные страны компаний и резидентов, собственный или общий/виртуальный IBAN и тарифы.

Новизна приложения определяется датой первого выпуска в Google Play. «Впервые найдено» — дата обнаружения программой. Ни одна из них не доказывает дату основания компании или выхода бизнеса на рынок. Новые продукты компаний дополнительно ищутся на странице «Сайты и публикации».

## 8. Добавить найденное на телефоне

1. Откройте нужное приложение в Google Play на телефоне → **«Поделиться»** → скопируйте ссылку.
2. В программе раскройте **«Дополнительные источники и лимиты»**.
3. В поле **«Образцы · ID или ссылки Google Play»** добавьте ссылку отдельной строкой.
4. Нажмите «Найти приложения» или сохраните расписание.

По умолчанию шесть известных образцов; они проходят те же фильтры, что остальные карточки:

## 9. Исключения

IBAN Checker / Validator / Generator, расчёт контрольной суммы и поиск BIC отсеиваются по назначению приложения. Одна фраза «business», «SEPA» или «IBAN» не считается предложением открыть счёт.

Программа отсеивает местные UPI/IFSC-сервисы без международных счётных признаков, калькуляторы кредитов, проверку кредитного рейтинга, азартные игры, учётные трекеры без открытия счёта, чистые криптокошельки без фиатных/IBAN-признаков. Глобальный сервис не исключается только за слово «crypto»: ваши примеры могут сочетать фиат и цифровые активы. Упоминание Индии в перечне стран или адресе само по себе не означает непригодность глобального бизнес-счёта.

Настройки исключений:

- **«Исключить это приложение»** — сохраняет его точный ID и текущие настройки формы.
- **Слова и фразы:** по одному на строку, без регулярных выражений. Проверяются название, разработчик и доступный текст. Слишком общая фраза может убрать полезный результат.
- **Домены:** без протокола и пути, например `example.com`; исключаются также поддомены.
- **«Скрывать известные крупные приложения»:** убирает перечисленные в форме известные ID. Это не полный реестр старых банков. Галочку можно снять.

Уже подходящие записи могут перепроверяться спустя семь дней и при первом подключении проверки сайта, если EU IBAN неизвестен. Это обновляет сведения, не создавая повторов.

После изменения настроек нажмите **«Сохранить расписание»**. Старые исключённые записи остаются в архиве, сохраняя защиту от повторов.

## 10. Включить ежедневный поиск

1. Настройте форму и исключения.
2. Включите **«Автоматически каждый день»**.
3. Выберите время по **Калининграду (UTC+2)**.
4. Нажмите **«Сохранить расписание»**. Сохранится профиль, выбранное число месяцев, страна телефона, образцы, источники и исключения.

Браузер можно закрыть. **Терминал должен оставаться открытым, Mac — включённым и с интернетом.** Файл запуска использует `caffeinate`, чтобы Mac не засыпал сам по бездействию, пока работает программа. Он не обеспечивает работу при закрытой крышке, выключении или остановке программы. После перезагрузки откройте `2-Запустить.command` снова. Пропущенный запуск выполняется один раз при возобновлении работы.

Для **24/7 без включённого Mac** используйте постоянно работающий сервер с постоянным диском — [инструкция Render](CLOUD.md). В Render ключ задаётся в Environment как `BRAVE_SEARCH_API_KEY`. Подготовленный проект сам не создаёт платный сервис и не размещается в вашем аккаунте хостинга.

### Включить всё одной кнопкой

В программе откройте **«Изменения и компании» → «Включить весь ежедневный мониторинг»**. Это сохранит включение Google Play, расширенных источников и наблюдения за изменениями. Времена по умолчанию — 09:00, 09:15 и 09:30 по Калининграду. Уже изменённое вами время сохраняется. Если время прошло, пропущенная проверка может начаться сразу. Без Brave публикации ожидают ключа, Google Play и прямое наблюдение работают независимо. Кнопка использует сохранённые настройки, поэтому редактируемую форму сначала сохраните.

### Сайты, новости и соцсети — отдельное расписание

1. Вверху программы откройте **«Сайты и публикации»**. После успешной проверки ключа дополнительных подключений не требуется.
2. Нажмите **«Добавить все рекомендованные источники»**. Добавятся профильные СМИ, партнёры, рассылки, форумы, реестры и каталоги. Лимит — 8 обращений Brave за запуск. В режиме «Конкретные анонсы» активны новости, партнёры и публичные объявления: 24 пары за 3 дня; для всех пар каждый день задайте лимит 24. Режим «Все сигналы» включает форумы, реестры и каталоги: 36 пар за 5 дней, либо лимит 36 для ежедневного полного круга. Это увеличивает расход API. Свои источники и запросы тоже можно выбрать вручную.
3. Для наблюдения за конкретными сайтами включите **«Мои сайты»**, впишите домены по одному на строку: `lurrapay.com`, `rampy.money`, `stable.com`, `photonpay.com`. Включение этой галочки обязательно: одни домены не запускают поиск.
4. В запросах используйте, например, `("business account" OR "corporate account") (IBAN OR SEPA OR EUR)`. Не требуйте точную фразу «EU IBAN» во всех запросах: сайты часто пишут «Euro IBAN» или «multicurrency account».
5. Выполните ручной поиск, затем включите **ежедневный поиск на этой странице**, выберите время и сохраните расписание. Расписание Google Play и расписание сайтов сохраняются отдельно.

Этот режим регулярно ищет новые индексированные страницы по вашим критериям. Для изменений текста используйте отдельную страницу «Изменения и компании»; поиск публикаций не отслеживает каждое изменение текста на уже найденной странице и не входит в закрытые аккаунты LinkedIn/Facebook. Найденные URL сохраняются без повторов. Постоянная работа требует включённой программы или сервера.

### Наблюдение за изменениями

1. Откройте **«Изменения и компании»**. Там уже указаны четыре сайта ваших образцов и две известные карточки Google Play.
2. При необходимости добавьте точные ссылки на страницы бизнес-продукта, тарифов или регистрации — они полезнее общей главной. Адрес должен начинаться с `https://`.
3. Оставьте галочки наблюдения за найденными приложениями и сайтами разработчиков: новые находки Google Play будут подключаться к наблюдению.
4. Нажмите **«Проверить сейчас»**. Первый успешный просмотр сохраняет исходное состояние и не считается новым запуском компании.
5. Следующие проверки показывают добавленные/удалённые финансовые фрагменты, изменения версии или даты приложения. Обновление версии само по себе не доказывает новые условия счёта.
6. Включите ежедневное наблюдение и сохраните расписание этой страницы, если не использовали общую кнопку.

За один запуск — до 20 страниц, 20 указанных RSS/Atom-лент и 30 приложений. Дополнительные найденные приложения и сайты чередуются по дням. Обычные новости остаются в «Сайтах и публикациях», изменения — здесь. Прямые проверки не используют Brave, но требуют доступности самих сайтов; закрытые кабинеты, CAPTCHA и страницы, требующие JavaScript, могут быть недоступны. Ошибка не заменяет последнее успешное исходное состояние.

RSS/Atom: впишите точный адрес публичной ленты в отдельное поле. По умолчанию ленты не заданы: неизвестные RSS-адреса не подставляются автоматически. Подходящие записи сохраняются без повторов.

Внизу — группы компаний: приложения связываются по сайту разработчика, публикации о ваших образцах — также по названию с пометкой неподтверждённой связи. Это не полное автоматическое установление юридических лиц.

## 11. Расход Brave

Google Play API-ключа не требует. Для одного поиска в основном профиле программа делает:

- 2 обращения Brave по дополнительным карточкам Google Play;
- до 10 обращений по доменам образцов (по умолчанию 4);
- затем проверки фрагментов сайтов разработчиков, пока общий лимит **20 обращений Brave за этот запуск** не исчерпан.

Для режима «Сайты и публикации» расход считается отдельно: выполняется часть пар **источники × запросы** в пределах установленного лимита; число и срок полного круга показаны в форме. По умолчанию — до 8 обращений за запуск. Проверка ключа добавляет один запрос. Ручные повторы расходуют квоту. Пример: 20 обращений Google Play + 8 обращений новостей ежедневно — до 840 за 30 дней, без ручных повторов. Проверьте актуальные условия вашего тарифа Brave; с версии 2.4 действует общий программный предел Brave: по умолчанию 1000 запросов в месяц, меняется через `BRAVE_MONTHLY_REQUEST_LIMIT` в `.env` с перезапуском.

Отсутствие Brave или ошибка его API не прекращают основной сбор Google Play. Ошибка и ограничение полноты отображаются отдельно. Индекс может не знать свежее приложение, страница сайта может быть устаревшей, а выдача Google Play не охватывает весь каталог.

## 12. Если что-то не работает

В Терминале:

```sh
cd ~/Desktop/play-scout
npm run doctor
```

Команда покажет версию, Node.js, наличие ключа и истории, не раскрывая ключ. Она не делает платных запросов. Ошибки источника и причины исключения смотрите в **«Подробностях проверки»**. Лимит проверяемых карточек делает поиск **неполным** — увеличьте его в дополнительных настройках. Отсутствие ссылки у образца не равно отсутствию банка на рынке.

Не присылайте `.env` или сам ключ. Для диагностики достаточно текста ошибки, версии и счётчиков проверки.

## Рекомендации и продолжение проверки

1. Раскройте «Дополнительные источники и лимиты» → «Дополнительные настройки». Включите **«Обходить “Похожие приложения” Google Play»** и **«Другие приложения того же разработчика»**. В режиме широкого каталога они включены сразу.
2. Добавляйте точные ссылки с телефона в образцы: код `gl=DE`, `gl=AT` или `gl=IT` сохраняется. Программа читает публичный блок Similar apps и его список, затем до двух переходов проверяет подходящие карточки. До 20 списков рекомендаций и 12 разработчиков за запуск. Это отдельные обращения к Google Play, без ключа Brave.
3. Предел карточек по умолчанию — **1000**. Если осталось больше, нажмите **«Продолжить проверку»** у результатов. Очередь сохраняется в `data/state.json`, продолжение не собирает все запросы заново. Остановленный запуск также сохраняет непроверенные карточки.
4. Подходящие рекомендации видны с указанием исходного приложения. Каждая проходит фильтры бесплатности, Finance, даты, установок, бизнес-счёта и исключений. Чекер не становится банком только из-за рекомендации.
5. Нажмите **«Сохранить расписание»** для выбранных параметров. Ежедневный поиск сначала учитывает сохранённую очередь; уже найденные ID повторно не добавляются. На Mac программа должна работать; для работы при выключенном компьютере используйте [CLOUD.md](CLOUD.md).

Публичные рекомендации могут отличаться от персонализированных на телефоне. Охват всего каталога Google Play не гарантируется.

## Новое в 2.3: веб-версии

1. После обновления с сохранением `data` и `.env` откройте **«Веб-версии»** в верхнем меню. Внизу/в расписании должна быть версия **2.4.0**.
2. Ваш существующий ключ Brave используется автоматически. Если его нет, остановите программу → `npm run configure` → сохраните ключ → снова запустите. Второй ключ не нужен. Проверка доступа — кнопкой на главной.
3. Нажмите **«Найти веб-сервисы»**. Ищутся страницы бизнес-счетов, IBAN, мультивалютных счетов и веб-банкинга, включая сайты без Android-приложения. Дополняют поиск сайты образцов и разработчиков находок. Статьи и обзоры отсеиваются; дата обновления страницы не ограничивает поиск.
4. В карточке видно **«Веб-кабинет упомянут»** с цитатой либо **«Веб-кабинет не подтверждён»**. Для первого варианта включите **«Только с упоминанием веб-кабинета»**. Это текст источника, не проверка работоспособности входа. Ссылка ведёт на найденную страницу продукта; адрес входа не придумывается.
5. Включите «Каждый день», выберите время (по умолчанию **09:20 по Калининграду**) и нажмите **«Сохранить расписание»**. История и расписание независимы от Google Play и публикаций. Если до обновления все расписания были выключены, веб-поиск тоже начнёт с выключенного состояния.

Веб-поиск дополнительно расходует до **8 обращений Brave за запуск** (лимит меняется от 1 до 20). При стандартных верхних пределах всех поисков: (20 Google Play + 8 публикации + 8 веб) × 30 = до 1080 обращений за 30 дней, плюс ручные повторы и проверки ключа. С версии 2.4 дополнительно действует общий месячный предел Brave: по умолчанию 1000, меняется через `BRAVE_MONTHLY_REQUEST_LIMIT`. Проверьте тариф и баланс Brave.

## Убрать ненужную находку одним нажатием

Нажмите заметную кнопку **«✕ Исключить приложение / сервис / запись»** прямо в карточке или строке. Она доступна в последних результатах, всех находках, кандидатах, публикациях, веб-сервисах, событиях и связанных сигналах компаний. Исключение сохраняется **сразу**: кнопку расписания нажимать не нужно.

- Приложение исключается по ID во всех списках и будущих поисках.
- Веб-сервис исключается по домену, включая поддомены и приложения с этим сайтом разработчика.
- Публикация или страница события исключается по конкретной ссылке. Остальные материалы источника остаются.

После действия появится **«Отменить»**. Позже раскройте **«Исключённые вручную»** над результатами любой страницы → **«Восстановить»**. Это возвращает сохранённую запись без повторного поиска. История остаётся на диске; исключённое скрывается даже из архива и CSV. Ваши отдельные исключения в полях слов / доменов / ID по-прежнему действуют: восстановление ручной записи не отменяет эти фильтры.

## Если после остановки было «Поиск уже идёт» (исправлено в 2.3.1)

В 2.3 кнопка могла показывать остановленный поиск, пока сервер ещё ожидал ответ источника. Версия 2.3.1 прерывает ожидание, сохраняет очередь и только затем позволяет новый запуск. Также видно, что именно ожидается: выдача, карточка, рекомендации, список разработчика или сведения сайта. Одно обращение ограничено 30 секундами, весь поиск по многим странам занимает дольше.

1. В старом Терминале нажмите **Control+C**. Если окно долго не возвращается к строке ввода, закройте именно окно Терминала с этой программой и выберите завершение её процессов. Другие окна и программы закрывать не нужно.
2. Скачайте свежую версию, перенесите **data** и **.env**. Не удаляйте историю и не запускайте две копии программы.
3. Откройте **2-Запустить.command**, проверьте версию **2.4.0** и обновите страницу браузера.
4. После «Остановить поиск» появится «Останавливаем поиск…». Дождитесь «Поиск остановлен», затем запускайте снова либо нажмите «Продолжить проверку» для сохранённой очереди. Повторно подключать ключ не нужно.

Для временного восстановления старой версии можно остановить `npm start` через Control+C и запустить заново. Обновление требуется для исправления причины.

## Если каждый запрос ждёт 30 секунд (исправление 2.3.2)

Три сообщения «Google Play не ответил вовремя» подряд говорят об ошибках получения данных, а не об отсутствии подходящих сервисов. В 2.3.1 после первой сетевой ошибки мог зависнуть ограничитель запросов библиотеки. В 2.3.2 он заменён. Поиск также останавливается после трёх последовательных сбоев, сохраняя очередь карточек; ждать все 444 этапа не нужно.

1. Скачайте свежий ZIP по ссылке из раздела 2. Остановите старую программу, сохраните старую папку, перенесите `data` и `.env` в новую. Ключ заново вводить не нужно.
2. Откройте `2-Запустить.command`, обновите страницу браузера. Убедитесь, что показана версия **2.4.0**.
3. Если над результатами есть «Продолжить проверку», нажмите её: сначала будут проверяться сохранённые карточки без повторного сбора всех запросов.
4. Если снова появляются тайм-ауты, откройте **новое** окно Терминала (Command+N). Введите `cd ` с пробелом, перетащите **новую папку программы** из Finder в Терминал, нажмите Enter.
5. Выполните:

   ```sh
   npm run doctor -- --play
   ```

Команда выполнит два запроса: поиск `business account` в Австрии и чтение карточки Wamo. У каждого предел 30 секунд. Она не вызывает Brave, не меняет историю и не выводит ключ. Пришлите строки после «Проверка Google Play» для диагностики. Успех одного запроса не гарантирует доступность всего каталога; если оба завершаются тайм-аутом, нужна проверка соединения с Google Play из вашей сети. Открытие сайта в браузере само по себе не доказывает, что запросы Node.js проходят.
