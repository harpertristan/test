# Play Scout — запуск на Windows и Mac

**4.7.0: новый экран из четырёх разделов, полный проверяемый отсев до ИИ, память ручных решений и исправления сохранения / остановки. [Что изменилось](RELEASE_4_7.md). Ручные решения и очередь сохраняются; пересчёт без API. [Квоты и расходы API](API_LIMITS.md).**

Основные разделы: **«Подходят»**, **«На проверку»**, **«Уже в работе»**, **«Отсеяно»**. Для старта нажмите **«Новый поиск»**, выберите источник и запустите его. Для ИИ-разбора новых кандидатов используйте **«Проверить очередь»**. Автоматический отсев доступен с причиной и кнопкой возврата.

**[Установить Windows с нуля: папки, ключи, NVIDIA и команды](INSTALL_WINDOWS.md).**

Актуальная версия **4.7.0**. Обновить через код: [Mac M5](RELEASE_4_7_MAC.md), [Windows](RELEASE_4_7_WINDOWS.md). [Локальный GPU-агент и ферма](GPU_AGENT.md). Для чистого запуска на Windows без истории: **[WINDOWS.md](WINDOWS.md)**. Используйте файлы `.cmd`: импорт только ключей — `9-Import-keys-only.cmd`, установка — `1-Install.cmd`, запуск — `2-Start.cmd`.

Обновление с 4.4 сохраняет новые решения и исключения; повторного сброса нет. Резервная копия создаётся автоматически.
- **[Запуск и остановка](MAC.md#3-обычный-запуск-после-обновления)** — `2-Запустить.command` / `5-Остановить.command`.

- **[Ключи Brave / OpenAI / Gemini](MAC.md#6-ключи-поиска-и-облачного-ии)** — прежние ключи повторно вводить не требуется.
