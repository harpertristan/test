# Play Scout 3.0 — запуск с нуля на Mac

Основное рабочее место теперь находится по адресу **http://localhost:3000/crm**.

## 1. Обновить программу и сохранить свои данные

1. В старом Терминале остановите программу: **Control + C**. Если она не завершилась, откройте «Мониторинг системы», найдите процесс `node` именно этой программы и завершите его.
2. Скачайте [новую версию ZIP](https://github.com/harpertristan/test/archive/refs/heads/main.zip) и распакуйте. Старую папку пока сохраните.
3. Из старой папки скопируйте в новую **папку `data`** и **файл `.env`**. В них находятся ваши находки, исключения и ключи. Показать скрытые файлы Finder: **Command + Shift + точка**. Не публикуйте эти файлы.
4. Новую папку удобно назвать `play-scout` и положить на Рабочий стол.

## 2. Установить Node.js

Если `npm ci` у вас уже работал, Node.js установлен. Для новой установки скачайте macOS `.pkg` с [nodejs.org](https://nodejs.org/) — LTS, версия 22 или новее.

## 3. Открыть Терминал в папке программы

Command + пробел → введите «Терминал» → Enter.

Если папка называется `play-scout` и лежит на Рабочем столе, вставьте **одной строкой**, затем Enter:

```sh
cd ~/Desktop/play-scout
```

Для другой папки: напечатайте `cd ` **с пробелом**, перетащите папку из Finder в окно Терминала и нажмите Enter. `cd` и путь должны быть на одной строке.

Установите зависимости:

```sh
npm ci
```

## 4. Подключить ключ поиска Brave

Если перенесли старый `.env` с работающим ключом, повторно вводить его не нужно.

```sh
npm run configure
```

Вставьте только ключ Brave Search API и нажмите Enter. При вводе символы скрыты. Ключ хранится локально в `.env`. Brave ищет сайты, новости, отзывы и публичные материалы регуляторов; для Google Play и Apple Search отдельный ключ Brave не обязателен.

## 5. Подключить ИИ и автоматический перевод

Это **другой ключ**, не Brave и не подписка ChatGPT:

1. Откройте [platform.openai.com/api-keys](https://platform.openai.com/api-keys).
2. Проверьте баланс и оплату **API** в своём аккаунте OpenAI. Подписка ChatGPT оплачивается отдельно.
3. Создайте ключ и выполните в той же папке:

```sh
npm run configure:ai
```

Вставьте ключ и Enter. Скрипт сохранит его, не меняя ключ Brave. **Не присылайте ключи в чат.**

По умолчанию используется `gpt-5-mini`. Другую доступную в вашем аккаунте модель можно задать строкой `OPENAI_MODEL=имя-модели` в `.env`. После изменения ключей или модели перезапустите программу.

## 6. Запустить

```sh
npm start
```

Когда появится `Play Finance Finder: port 3000`, откройте браузер:

**http://localhost:3000/crm**

Также можно открыть файл **`2-Запустить.command`** двойным щелчком. Он устанавливает зависимости при необходимости, открывает CRM и препятствует автоматическому сну по бездействию, пока работает. Если macOS не открывает файл, из папки проекта выполните:

```sh
bash ./2-Запустить.command
```

Не закрывайте Терминал, пока программа нужна. Первая успешная проверка покажет, действительно ли ваш ключ и тариф принимаются API; просто наличие ключа ещё не означает успешное соединение.

## 7. Первый полный поиск

1. Откройте **«Настройки источников, перевода и исключений»**.
2. Проверьте поисковые фразы, страны и категории Google Play / App Store. Для самых новых проектов оставьте порог установок 0; в нейронном сборе нет ограничения по возрасту приложения.
3. Оставьте **автоматический перевод** включённым.
4. Сохраните настройки.
5. Нажмите **«Искать во всех источниках + ИИ»**.

Пять источников собираются независимо. Google Play проверяет карточки во время сбора выдачи, ИИ получает новые материалы по мере их сохранения. Сбор всех стран, рекомендаций и доступных страниц может занимать долгое время: программных квот нет. Нажмите **«Остановить всё и сохранить»**, если хотите прервать запуск. Проверенные находки и очередь Google Play сохраняются. На странице Google Play кнопка **«Продолжить проверку»** проверяет сохранённую очередь без повторения поисковых запросов.

## 8. Где смотреть результаты

- **Рабочий список** — активные находки всех источников.
- **Новые** — впервые найденные записи; это не доказательство недавнего запуска компании.
- **На проверку** — сведений ещё недостаточно.
- **Подходит** — есть цитаты по критериям ИИ либо вы установили этот статус вручную. Открытие конкретной компании всё равно надо подтвердить.
- **Наблюдать** — ваш список наблюдения.
- **Итоговый список** — отобранные вами проекты.
- **Не подходит** — ваши отрицательные решения / выводы ИИ.
- **Исключены вручную** — записи, убранные кнопкой исключения. Можно восстановить.
- **Автоисключения** — в частности Нигерия / Nigerian / NGN / naira / домены .ng. Само упоминание может встретиться у международного сервиса; причина видна в карточке.
- **Лицензии** — материалы официальных регуляторов об EMI и MiCA / CASP, с отдельным фильтром типа.
- **Все** — включая исключения, для аудита.

Откройте сервис слева. Справа находятся ссылки, ваш статус, комментарий, ИИ-разбор, источники, перевод и оригинал. **«Исключить из всех списков»** сохраняет правило во всех разделах. **«Вернуть в рабочий список»** снимает ручное исключение, сохраняя комментарии.

## 9. EMI и MiCA

Вкладка **«Лицензии»** → **«EMI и MiCA / CASP»**, «Только EMI» или «Только MiCA / CASP».

До ИИ-разбора это материал для проверки. После разбора карточка может содержать название компании, тип, статус, регулятора, дату решения и точную цитату с официальной ссылкой. Если дата решения не найдена в цитате, она остаётся неизвестной. Дата обнаружения и дата статьи её не заменяют. Заявки, отозванные разрешения и старые VASP-регистрации не считаются выданной авторизацией CASP.

Есть два канала:

- Поиск по официальным доменам через Brave: EBA, ESMA, Банк Литвы, национальные регуляторы стран ЕС.
- Прямое наблюдение за читаемыми страницами ESMA MiCA, EBA и Банка Литвы. Первый просмотр сохраняет исходный снимок, следующие показывают изменения. Страницы с обязательным JavaScript / недоступными таблицами могут не читаться; ошибки показываются отдельно. Поиск по индексу продолжает работать.

Это не полная синхронизация всех реестров. Лицензия EMI / CASP сама по себе не подтверждает выдачу бизнесу EU IBAN.

## 10. Ежедневная работа

Нажмите **«Включить ежедневный сбор + ИИ»**. В настройках задайте время нейронного запуска по **Калининграду (UTC+2)**. Отдельные расписания отключаются, чтобы не дублировать поиск; единый режим и время видны наверху CRM. Сохранённые настройки источников используются в общем запуске. Завершённые подходящие сборы за тот же день могут переиспользоваться, вместо повторного обращения к источнику.

Для постоянной работы Mac должен быть включён, подключён к интернету, а программа запущена. Закрытие крышки или выключение мешает расписанию. Для работы без компьютера перенесите программу, `.env` и `data` на постоянно работающий сервер: [CLOUD.md](CLOUD.md).

## 11. Как получить мой разбор в этом чате

Встроенный ИИ использует **ваш OpenAI API**. Этот чат автоматически не видит программу на вашем Mac.

1. В CRM выберите, например, **«Новые»**, **«На проверку»** или **«Итоговый список»**.
2. Нажмите **«Скачать данные для разбора в ChatGPT»**.
3. Прикрепите скачанный JSON к этому чату.
4. Напишите: «Проверь сайты, бизнес-счёт, страну выдаваемого IBAN, кабинет и дату запуска. Отдельно проверь EMI и MiCA».

В JSON находятся сохранённые публичные тексты и ваши комментарии. Ключей API в выгрузке нет. Выберите нужную вкладку перед выгрузкой: «Все» включает и исключённые записи.

## 12. Выгрузка документа

Выберите вкладку / строку поиска → **«Скачать Word»** или **«Скачать таблицу CSV»**. Выгружается весь отфильтрованный список, а не только первые 50 строк на экране. Ручные исключения учитываются; вкладка «Все» включает их явно.

Word содержит комментарии, оценки, оригинальные цитаты, переводы, лицензии и ссылки. Его можно открыть в Word / Pages и сохранить в PDF. CSV удобно открыть в Excel / Numbers как UTF-8 с разделителем «запятая».

## 13. Почему ещё бывают задержки

Нет квот за запуск, за месяц, на число карточек, списков рекомендаций и ИИ-разборов. Старые ограничения настроек снимаются при обновлении. `BRAVE_MONTHLY_REQUEST_LIMIT` больше не ограничивает программу.

Остаются технические свойства источников: страницы Brave до 20 результатов и смещения 0–9, ответы Apple до 200 приложений на фразу и страну без полной пагинации, доступная Google выдача. Google-запросы выполняются параллельно с ограничением одновременной нагрузки; Brave и Apple получают паузы между обращениями. Тайм-ауты, проверка повторяющихся токенов и остановка при сетевом сбое защищают от зависаний.

ИИ работает с фрагментами общедоступных источников в пределах контекста модели. Наличие перевода не означает, что прочитан весь сайт. В карточке сохранены исходные тексты, на которых основан разбор. Кэш неизменных материалов уменьшает повторную работу. Увеличение количества запросов не гарантирует полноту каталога или первенство обнаружения.

**Платные API могут расходовать весь доступный баланс:** программных квот больше нет, фактический учёт запросов и токенов остаётся.

Диагностика без вывода ключей:

```sh
npm run doctor
```

Проверка Google Play (реальные сетевые обращения):

```sh
npm run doctor -- --play
```

403 / ошибка DNS / тайм-аут означают проблему доступа к источнику. Это не равно «подходящих проектов нет». Не удаляйте `data` для исправления ошибки.
