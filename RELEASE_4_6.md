# Play Scout 4.6.0 — распределение после проверки

После успешного разбора ручная очередь автоматически разделяется:

- **«Совпадения ИИ»** — прямыми цитатами из приложения / сайта провайдера подтверждены бизнес-счёт, предоставление счёта и выдача IBAN страны ЕС. Это сильный кандидат для вашей оценки.
- **«Проверить вручную»** — сомнения, противоречия, неполные сведения, лист ожидания / будущий продукт, недоступный источник или незавершённый разбор.
- **«Автоисключения»** — явная утилита / игра / отдельный криптокошелёк, исключённая юрисдикция или прямое однозначное отрицание нужного критерия. Из рабочего списка и ручной очереди такие записи уходят.

Проценты достоверности не выдумываются. Каждое автоматическое решение содержит причину и исходный источник. Отсутствие подтверждения не считается отрицанием: EUR / SEPA / лицензия без доказательства выдачи EU IBAN остаются вопросом. Криптосервис с фиатным бизнес-счётом или провайдер через банк / EMI-партнёра не исключается только из-за этой модели обслуживания. Фраза «мы не банк» не означает отсутствие бизнес-счёта.

Ни язык, ни страна магазина не заменяют юрисдикцию. Учитываются выбранные ранее ограничения стран; Румыния, Словакия и Словения сохранены. Для восстановленных записей отсутствие европейского предложения в неполном тексте само по себе не вызывает отсев.

## Готовые разборы и продолжение

При обновлении с 4.5 ваши сохранённые успешные разборы текущего прохода распределяются **без повторных запросов**. Модель не включается от самого обновления. Старые разборы до начала повторной проверки, устаревшие входные данные и неподтверждённые цитаты сохраняются для ручной оценки.

Для оставшихся карточек нажмите **«Продолжить полную проверку»**. По мере готовности растёт «Совпадения ИИ» / «Автоисключения» и сокращается ручная очередь. Основная кнопка полного прохода теперь берёт только то, что осталось в ручной категории. Ошибки и недоступные карточки остаются доступными для продолжения. OpenAI / Brave при выполнении запросов расходуют соответствующий баланс; Ollama обрабатывает локально.

## Ваши решения

«Подтверждено мной», «В работе / был в работе», ручные исключения, итоговый список и наблюдение сохраняются. ИИ не присваивает вашу ручную отметку.

Автоисключения остаются в отдельной вкладке с объяснением. Можно выгрузить их для проверки, либо нажать **«Вернуть на ручную проверку»** у одной / выбранных записей. Это ручное решение сохраняется. Новый адресный разбор может затем обновить автоматический вывод по новым материалам.

Комментарии, история, ключи, выбранный режим GPT + Ollama / Ollama / другой ИИ, кэш и расход API не сбрасываются. CSV, Word и JSON используют те же категории и включают причину распределения.
