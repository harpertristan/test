# Play Scout 4.1.3 — Windows: перенос с Mac со всеми ключами

Основная установка: Windows, Ollama и NVIDIA с видеопамятью 8 ГБ или больше. Для общей ссылки компьютер должен оставаться включённым, программа — работать. Отдельный сервер для этого сценария не нужен.

Это **тот же код поиска и CRM, что на Mac**, а не отдельный упрощённый поиск. Для вашего сценария ниже описан **чистый запуск без истории**, с переносом только ключей и паролей из `.env`. Старые находки и ручные исключения не загружаются. Полный зашифрованный перенос профиля оставлен как необязательный вариант в разделе 2а.

Ключи берутся с **вашего Mac**, где они действительно сохранены. Общедоступный ZIP содержит только программу. Для переноса не нужно присылать API-ключи в чат или вводить их на Windows повторно.

## 1. Скачать и расположить программу

1. Установите **Node.js LTS 22 или новее**: https://nodejs.org/ . Выберите Windows Installer x64 и обычные настройки установки.
2. Скачайте [ZIP проекта](https://github.com/harpertristan/test/archive/refs/heads/main.zip). В Проводнике нажмите «Извлечь всё». Не запускайте файлы прямо внутри ZIP.
3. Назовите распакованную папку **PlayScout**. Откройте Проводник, вставьте в адресную строку `%USERPROFILE%`, нажмите Enter и перенесите туда папку.

Получится примерно `C:\Users\ВашеИмя\PlayScout`. Внутри должны сразу находиться `package.json`, `server.js`, папки `lib`, `public` и файлы `1-Install.cmd`, `2-Start.cmd`.

На Windows запускайте **`.cmd`**. Файлы `.command` предназначены для Mac; они присутствуют в том же архиве, потому что код общий.

## 2. Перенести только ключи — без истории

Если ключи на Windows хотите ввести заново, этот раздел можно пропустить: после установки используйте `4-Keys.cmd`. Чтобы не вводить уже имеющиеся ключи повторно:

### На Mac

Откройте новое окно Терминала и выполните:

```sh
cd "$HOME/Desktop/play-scout-v31"
cp .env "$HOME/Desktop/PlayScout-keys.env"
```

На Рабочем столе появится видимый файл **`PlayScout-keys.env`** с вашими ключами. Обновлять Mac или переносить папку `data` для этого не нужно. Если папку программы переименовали, используйте её фактический путь в `cd`.

Скопируйте этот файл на флешку и затем на Рабочий стол Windows. Это личный файл с ключами в открытом виде: не размещайте его в GitHub, общей папке или чате. Если копия с таким именем уже есть на Рабочем столе Mac, команда заменит её текущими ключами; исходный `.env` в программе не меняется.

### На Windows

1. После установки Node.js откройте распакованную папку `%USERPROFILE%\PlayScout`.
2. Дважды щёлкните **`9-Import-keys-only.cmd`**.
3. В Проводнике нажмите правой кнопкой на `PlayScout-keys.env` → «Копировать как путь». При необходимости удерживайте Shift.
4. Вставьте путь в окно импорта через Ctrl+V и нажмите Enter. Кавычки допускаются.
5. Дождитесь **«Ключи перенесены. История с Mac не переносилась»**. Значения ключей не печатаются.

Вариант через PowerShell:

```powershell
cd "$env:USERPROFILE\PlayScout"
npm.cmd run transfer:keys -- --file "$env:USERPROFILE\Desktop\PlayScout-keys.env"
```

Путь `DATA_DIR` будет исправлен автоматически на `./data`. На Windows появится только `.env`; пустая новая история создастся при первом запуске. **Не копируйте `data`, `.psbackup` или JSON CRM**, если хотите начать с чистого списка. Если в выбранной папке Windows уже есть история, импорт только ключей её не удаляет: распакуйте программу в новую папку.

После успешного запуска временные копии `PlayScout-keys.env` на Рабочих столах / флешке можно удалить. Рабочий `.env` внутри PlayScout сохраните. Продолжайте с раздела 3.

## 2а. Необязательно: перенести полный профиль с историей

**Для чистого запуска этот раздел пропустите.** Он нужен только если впоследствии решите перенести находки, исключения, комментарии и настройки целиком.

### На Mac — создать файл переноса

Откройте **новое** окно Терминала: Command+N. Если папка не переименована, выполните команды по очереди:

```sh
cd "$HOME/Desktop/play-scout-v31"
npm run update:mac
npm run stop
npm run transfer:export
```

1. Первая команда обновления установит код **4.1.3 или новее** в прежней папке. Без `--start` программа после обновления не запускается. `npm run stop` также безопасен, если она уже остановлена.
2. Придумайте **новый пароль переноса от 12 символов**, например сочетание латинских букв и цифр. Это не API-ключ и не пароль OpenAI. Введите его дважды; символы на экране не показываются — это нормально.
3. Дождитесь «Готово. Файл переноса: …». На Рабочем столе появится **`play-scout-transfer-ДАТА.psbackup`**. Команда покажет только наличие ключей, числа приложений / разборов / исключений и имя выбранной модели. Сами значения ключей не печатаются.
4. Скопируйте `.psbackup` на флешку и затем на Рабочий стол Windows. Запомните пароль переноса. Не публикуйте файл и пароль вместе.

Вместо последней команды можно запустить `9-Перенести-на-Windows.command` из папки программы на Mac. Для экспорта в другое место:

```sh
npm run transfer:export -- --file "$HOME/Desktop/мой-профиль.psbackup"
```

Если выбранное имя файла уже существует, оно не перезаписывается. Выберите другое имя. Исходные `.env` и `data` на Mac остаются нетронутыми. Нестандартный `DATA_DIR` учитывается при экспорте; при импорте используется переносимая папка `./data`.

### На Windows — восстановить тот же профиль

1. Убедитесь, что Node.js установлен. После его установки закройте и заново откройте Терминал.
2. В папке **`C:\Users\ВашеИмя\PlayScout`** дважды щёлкните **`7-Import-from-Mac.cmd`**. Устанавливать зависимости перед импортом не нужно.
3. В Проводнике найдите перенесённый `.psbackup`. Удерживая Shift, нажмите на файл правой кнопкой → **«Копировать как путь»**. На Windows 11 этот пункт может быть виден без Shift.
4. Вставьте путь в окно импорта через Ctrl+V и нажмите Enter. Кавычки вокруг пути допускаются.
5. Введите **тот же пароль переноса**, который придумали на Mac. Ввод скрыт. Дождитесь «Готово. Профиль перенесён».
6. Сверьте показанные числа приложений, разборов и исключений с экспортом на Mac. Для ранее заданных ключей будет написано `перенесён`.

Импорт создаст `PlayScout\data\state.json` и скрытый файл `PlayScout\.env`. Если профиль на Windows уже был, прежние `data` и `.env` сохранятся рядом в **`PlayScout-before-import-...`**. Неверный пароль, повреждённый файл или ошибка записи не должны подменить рабочий профиль; частичная установка откатывается. При нестандартной старой папке данных вне PlayScout она остаётся на прежнем месте.

Вариант через PowerShell:

```powershell
cd "$env:USERPROFILE\PlayScout"
npm.cmd run transfer:import -- --file "$env:USERPROFILE\Desktop\имя-вашего-файла.psbackup"
```

Результаты поиска из CSV, PDF или кнопки «Данные для ChatGPT» **не являются полным профилем**: они не содержат ключей и всей истории исключений. Для точной копии нужен именно `.psbackup`.

## 3. Установить зависимости

Дважды щёлкните **`1-Install.cmd`**. Дождитесь установки и диагностики **Play Scout 4.1.3 или новее**. Если Node.js ещё нет, файл откроет официальный сайт; после установки запустите `1-Install.cmd` снова.

Если удобнее командами, откройте «Терминал» / PowerShell:

```powershell
cd "$env:USERPROFILE\PlayScout"
npm.cmd ci
npm.cmd run doctor
```

В PowerShell используйте именно `npm.cmd`: менять политику выполнения PowerShell для запуска этих файлов не требуется.

В диагностике ожидается `Файл .env: прочитан`, наличие прежних ключей и прежняя история. Надпись «ключ задан» означает наличие значения, а не проверку доступа / баланса API. Ключи остаются теми же: создавать новые только из-за переноса не требуется.

## 4. Установить локальный ИИ для вашей NVIDIA

1. Обновите драйвер NVIDIA при необходимости: https://www.nvidia.com/en-us/drivers/ .
2. Установите Ollama для Windows: https://ollama.com/download/windows .
3. Откройте приложение Ollama. Оно должно работать в фоне.
4. Если переносите текущий профиль без изменения ИИ, установите **ту же модель, имя которой напечатал импорт**. Например, для `qwen2.5:7b`:

```powershell
ollama pull qwen2.5:7b
```

Установка той же модели сохраняет соответствие прежнему кэшу. Если хотите сравнить более компактную модель, в папке PlayScout запустите **`5-Local-AI.cmd`**: этот файл скачает `qwen3.5:4b` — несколько гигабайт. Смена модели в CRM выполняется явно и может потребовать нового разбора карточек.

Та же команда в новом окне Терминала:

```powershell
ollama pull qwen3.5:4b
```

Перенесённая с Mac история не переносит веса модели: на Windows модель нужно установить отдельно. Для этого профиля программа использует короткий контекст и отключает отдельный режим рассуждений Qwen3. Одновременно выполняется один локальный разбор, чтобы не переполнять видеопамять.

## 5. Подключить ключи

Запустите **`4-Keys.cmd`** и выберите нужный пункт:

- `1` — Brave: веб-поиск, публикации, реклама, реестры.
- `2` — OpenAI API, если хотите использовать его.
- `3` — Gemini API как дополнительный облачный ИИ.
- `4` — пароли владельца и пользователей просмотра.

Если выполнили импорт только ключей или полный импорт с Mac, **пропустите повторный ввод ключей**. `4-Keys.cmd` понадобится только для их замены. Для Google Play отдельный поисковый API-ключ не нужен; для локальной Ollama ключ ИИ не требуется.

Ключ Gemini создаётся в https://aistudio.google.com/apikey . Бесплатные квоты, доступные модели и условия оплаты зависят от аккаунта и региона. Подписка ChatGPT не оплачивает ни Gemini, ни OpenAI API. Ключи вводятся скрыто и сохраняются локально; после изменения ключей перезапустите программу.

## 6. Запустить

Дважды щёлкните **`2-Start.cmd`**. Он дождётся ответа программы и откроет браузер:

**http://127.0.0.1:3000/crm**

Оставьте окно программы открытым. Для остановки запустите **`3-Stop.cmd`**: программа сохранит очереди и завершится. Повторный запуск `2-Start.cmd` при уже работающем приложении открывает существующий экземпляр.

В CRM откройте «Настройки источников, ИИ и ежедневного поиска»:

1. Для чистого бесплатного локального старта выберите **Ollama** в поле «Где выполнять анализ». Если переносили полный профиль, проверьте сохранённый выбранный ИИ.
2. Объём разбора: **Экономный** для первичного отбора.
3. Модель Ollama: **`qwen3.5:4b`**, если скачали её через `5-Local-AI.cmd`. При полном переносе можно оставить точное имя модели из профиля, установив её отдельно.
4. Нажмите «Сохранить настройки» и «Проверить Ollama на этом компьютере».
5. Откройте одну карточку и нажмите «Разобрать этот сервис через ИИ».

После завершения в карточке видны время генерации и скорость, сообщённые Ollama. Проверьте несколько известных подходящих и неподходящих примеров, прежде чем запускать всю очередь.

При полном переносе выбор OpenAI или Gemini также сохраняется. **Импорт только ключей не переносит выбор модели и расписания**: настройте их перед первым анализом. Перенос сам не вызывает ИИ и ничего не списывает. Обычный поиск / анализ и включённое расписание используют выбранный API и его баланс. Платного резервного переключения нет.

В новой пустой установке расписания выключены до вашего явного включения. Простой запуск программы не должен начинать платный сбор по скопированным ключам. Когда проверите источники и выбранный ИИ, включите ежедневный поиск отдельной кнопкой.

Не запускайте одновременно обе копии с одинаковым ежедневным расписанием: они будут независимо собирать данные и могут дважды расходовать API. После переноса основная копия работает на Windows; Mac остаётся остановленным. **Это копия на момент экспорта, а не автоматическая синхронизация двух машин.** Оформление и выбранные вкладки браузера могут потребовать настройки заново; поисковый профиль и история находятся в перенесённых данных.

## 7. Проверить, используется ли NVIDIA

Во время или после первой генерации запустите **`6-Diagnostics.cmd`**. Или в новом Терминале:

```powershell
ollama list
ollama ps
nvidia-smi
```

`ollama list` показывает установленные модели. В `ollama ps` ожидается `100% GPU`: это размещение модели на видеокарте. До первой генерации этот список может быть пустым. Контекст экономного запроса — 4096; ранее загруженный большой контекст Ollama иногда сохраняет до выгрузки модели.

Если память занята старой моделью, сначала остановите разбор в CRM, затем:

```powershell
ollama stop qwen2.5:7b
```

Если модель работает на CPU или возникают тайм-ауты, проверьте драйвер и попробуйте меньшую `qwen2.5:3b`. Сначала проверяйте одну карточку. Реальная скорость зависит от конкретной видеокарты, памяти и материала сайта.

## 8. Быстрая работа со списками

- Выберите причину в панели исключений один раз. Затем используйте «Исключить» прямо в строках или отметьте несколько / весь текущий список и нажмите «Исключить выбранные».
- Причины: **«Уже в работе / был в работе»**, **«Не банк и не провайдер»**, **«Не подходит локация»**.
- Во вкладке **«Исключены вручную»** есть отдельные фильтры причин, массовое восстановление и возможность изменить причину выбранным записям.
- Старые исключения без причины находятся в «Без причины / прежние исключения». Их можно классифицировать массово.
- Проверяются известные названия бренда, варианты названия, ID приложений и домены. Общее упоминание банка в описании другого сервиса не является основанием скрывать другой сервис. Причина сопоставления видна в карточке.
- Сортировка работает во всех вкладках CRM и на отдельных страницах источников. Можно выбрать релиз, публикацию, решение о лицензии или обнаружение. Неизвестные даты находятся в конце; обнаружение не выдаётся за дату запуска.
- App Store отключён. Ранее сохранённые записи доступны в «Архив источников».
- Кнопка «Лицензии → сайты → ИИ» ищет разрешения, извлекает организации и пытается найти и прочитать их сайты. Проверенные связи с сайтами добавляются в очередь того же разбора. Разрешение и предложение бизнес-счёта проверяются отдельно.
- Ночной режим переключается кнопкой в верхнем меню и запоминается для вашего браузера.

## 9. Дополнительный облачный ИИ

Если хотите сравнить скорость с локальной моделью:

1. Через `4-Keys.cmd` добавьте ключ Gemini и перезапустите приложение.
2. В CRM выберите Gemini и доступную в вашем аккаунте модель Flash / Flash-Lite. Подготовленный вариант: `gemini-2.5-flash-lite`; при изменении доступности моделей у Google укажите актуальное имя из AI Studio.
3. Сохраните настройки и нажмите «Проверить выбранный облачный ИИ». Этот тест выполняет реальное обращение и учитывается в использовании API.
4. Начните с одной карточки. Параллельность облачного разбора регулируется отдельно: 1–6 одновременных запросов, по умолчанию 3. Это не квота числа проектов. При ограничениях бесплатного тарифа уменьшите параллельность и проверьте квоту Google.

При ошибке локального ИИ платный провайдер автоматически не вызывается. Переключение выполняете вы. Неизменные данные используют сохранённый кэш соответствующей модели.

## 10. Дать ссылку людям в вашей сети

1. Через `4-Keys.cmd` → `4` задайте пароль владельца и отдельный пароль просмотра, каждый не короче 12 символов.
2. Перезапустите программу через `3-Stop.cmd`, затем `2-Start.cmd`.
3. При запросе Windows разрешите Node.js доступ в вашей частной сети.
4. Выполните `ipconfig` в Терминале и найдите IPv4 активного Ethernet / Wi-Fi.
5. Другие люди в той же сети открывают `http://ВАШ_IP:3000/crm`.

Логин **`admin`** — изменения и запуск поиска. Логин **`viewer`** — чтение и выгрузки; изменения и вызовы ИИ запрещены сервером. Передайте людям именно пароль просмотра, если им не нужно редактировать. Пространство общее, а не отдельная копия базы на каждого пользователя. Для смены сохранённого браузером входа удобно открыть приватное окно.

Без пароля обычный настольный запуск слушает только `127.0.0.1`. Для общей сети должен быть задан пароль владельца; явный `HOST=127.0.0.1` в `.env` оставляет доступ локальным.

## 11. HTTPS-ссылка людям из другой сети

Для этого можно использовать **Tailscale Funnel**. Он публикует HTTPS-доступ к программе на вашем Windows-компьютере; учётная запись, доступность Funnel и условия плана проверяются у Tailscale.

1. Сначала настройте оба пароля приложения, как в предыдущем разделе.
2. Установите Tailscale: https://tailscale.com/download/windows . Войдите в свой аккаунт.
3. Оставьте Play Scout запущенным. В новом Терминале выполните:

```powershell
tailscale funnel --bg 3000
```

4. Если Tailscale попросит включить Funnel, откройте выданную им страницу подтверждения в своём аккаунте.
5. Скопируйте напечатанный HTTPS-адрес и добавьте к нему `/crm`. Это ссылка для других людей. Им не требуется устанавливать Play Scout.
6. Люди входят как `viewer` с вашим паролем просмотра. Ключи Brave / Gemini / OpenAI остаются на вашем ПК.

Отключить публикацию:

```powershell
tailscale funnel reset
```

При выключении или сне компьютера ссылка и ежедневный поиск недоступны. Документация Funnel: https://tailscale.com/kb/1223/funnel . Вариант для доступа только участников вашей сети Tailscale — `tailscale serve`, а не публичный Funnel.

## 12. Ежедневная работа

В CRM задайте время по Калининграду и нажмите «Включить ежедневный сбор + ИИ». Программа должна работать к этому времени. В Windows настройте сон так, чтобы включённый в питание ПК продолжал работать; экран можно выключить или заблокировать.

Для автозапуска при входе в Windows нажмите Win+R → `shell:startup` → Enter и поместите туда **ярлык** `2-Start.cmd`. Ollama также должна запускаться при входе. Пропущенный запуск выполняется после следующего включения приложения; очередь и исключения сохраняются.

## 13. Обновление и резервные копии

Для обновления текущей папки с сохранением ключей и очереди, включая переход с 4.1.1, используйте **[пошаговый порядок 4.1.3](RELEASE_4_1_3.md#обновить-windows-в-существующей-папке)**. Остановите программу через прямую команду Node, затем объедините новый код с существующей папкой. Удалять прежнюю папку не нужно.

Остановите приложение через `3-Stop.cmd`. Для личной резервной копии запустите **`8-Export-profile.cmd`**: он создаёт такой же зашифрованный `.psbackup` из Windows-профиля. Сохраните пароль. Распакуйте новую версию, восстановите профиль через `7-Import-from-Mac.cmd` (работает и с Windows-экспортом), затем выполните `1-Install.cmd` и `2-Start.cmd`.

При ручном переносе сохраняйте всю папку `data` и `.env`. Не заменяйте заполненную историю пустой. Полная история находится в `data/state.json`; Word / CSV / JSON для ChatGPT её не заменяют.

## 14. Если не запускается

- **«Программа не ответила за 40 с»**: это срок ожидания ответа браузером, а не подтверждение потери данных. В новом окне PowerShell выполните `curl.exe --noproxy "*" --max-time 5 http://127.0.0.1:3000/api/health`. Ответ `status: ok` означает, что программа сейчас доступна; обновите страницу один раз и проверьте активное задание. Повторно запускать тот же поиск до проверки состояния не нужно. В 4.1.3 сокращены повторные пересчёты больших списков и добавлено восстановление активного задания после пропавшего ответа.
- **Окно закрывается при вставке пути, а выше написано `orlevel`, `de` или `not recognized`**: в 4.1.1 обнаружена ошибка формата Windows-файлов запуска. Используйте архив 4.1.3 или новее. Для обхода откройте папку программы в Проводнике, напечатайте `powershell` в её адресной строке и нажмите Enter. В открывшемся окне выполните `node .\scripts\import-keys.js`. После импорта — `npm.cmd ci` и `npm.cmd run start:desktop`. Это окно останется открытым и покажет настоящую ошибку, если она есть. Вводимый путь не является командой: дождитесь приглашения импортера.
- **В окне написано «node не является …»**: установите Node.js LTS 22+ и заново откройте окно. Проверьте `node --version` и `npm.cmd --version`.
- **«Неверный пароль переноса»**: проверьте раскладку и Caps Lock. Пароль переноса отличается от ключа API и пароля входа в CRM. Импорт не меняет прежние данные при этой ошибке.
- **«Порт занят»**: выполните `3-Stop.cmd` и дождитесь завершения старого окна. Затем повторите импорт / запуск. Другую программу на порту автоматически не завершают.
- **Вместо истории пустой список**: выполните `6-Diagnostics.cmd`. Проверьте, что открыли именно `%USERPROFILE%\PlayScout`, импорт завершился успешно, а в ней есть `data\state.json`. Не создавайте новый пустой state.json и не удаляйте старый.
- **«Модель Ollama не установлена»**: выполните `ollama list`, скачайте точное имя из перенесённых настроек через `ollama pull ИМЯ`, затем нажмите проверку Ollama в CRM.
- **Иконка программы не открылась в браузере**: оставьте окно запущенным и вручную откройте **http://127.0.0.1:3000/crm**. Если в `.env` другой PORT, используйте напечатанный при запуске адрес.
- **Запрос логина после переноса**: `admin` и прежний пароль владельца из Mac-профиля; для просмотра — `viewer` и прежний пароль просмотра. Сам API-ключ вместо пароля не подходит.

Команды диагностики в PowerShell:

```powershell
cd "$env:USERPROFILE\PlayScout"
node --version
npm.cmd run doctor
ollama list
ollama ps
```

Проверки выпуска описаны в [VALIDATION.md](VALIDATION.md). В среде разработки нет физической Windows / NVIDIA, поэтому реальное ускорение GPU нужно проверить на одной карточке после установки.
