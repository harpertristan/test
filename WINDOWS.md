# Play Scout 4.0 — Windows, NVIDIA и доступ по ссылке

Основная установка: Windows, Ollama и NVIDIA с видеопамятью 8 ГБ или больше. Для общей ссылки компьютер должен оставаться включённым, программа — работать. Отдельный сервер для этого сценария не нужен.

## 1. Скачать и расположить программу

1. Установите **Node.js LTS 22 или новее**: https://nodejs.org/ . Выберите Windows Installer x64 и обычные настройки установки.
2. Скачайте [ZIP проекта](https://github.com/harpertristan/test/archive/refs/heads/main.zip). В Проводнике нажмите «Извлечь всё».
3. Назовите распакованную папку **PlayScout**. Откройте Проводник, вставьте в адресную строку `%USERPROFILE%`, нажмите Enter и перенесите туда папку.

Получится примерно `C:\Users\ВашеИмя\PlayScout`. Внутри должны сразу находиться `package.json`, `server.js`, папки `lib`, `public` и файлы `1-Install.cmd`, `2-Start.cmd`.

## 2. Перенести находки и ключи с Mac

1. На Mac нажмите в CRM «Остановить всё и сохранить», затем завершите программу через Control+C в её Терминале.
2. Откройте старую папку программы, например `Desktop/play-scout-v31`.
3. Покажите скрытые файлы сочетанием **Command+Shift+точка**.
4. Скопируйте **всю папку `data`** и **файл `.env`** на флешку или передайте их личным способом.
5. На Windows поместите их прямо в `%USERPROFILE%\PlayScout` до первого запуска. В результате должен существовать файл `%USERPROFILE%\PlayScout\data\state.json`, а рядом с `package.json` — `.env`.

`data` сохраняет результаты, причины исключений, заметки, историю и кэш ИИ. `.env` содержит ключи и пароли: это личный файл, его не нужно загружать в GitHub или присылать в чат. Зависимости Windows установятся на следующем шаге.

Если в старом `.env` вручную задавали `DATA_DIR=/Users/...` или серверный путь `/var/...`, откройте файл Блокнотом и замените эту строку на `DATA_DIR=./data`. Это направит программу в перенесённую папку истории. Строки ключей оставьте как есть.

## 3. Установить зависимости

Дважды щёлкните **`1-Install.cmd`**. Дождитесь установки и диагностики **Play Scout 4.1.0**. Если Node.js ещё нет, файл откроет официальный сайт; после установки запустите `1-Install.cmd` снова.

Если удобнее командами, откройте «Терминал» / PowerShell:

```powershell
cd "$env:USERPROFILE\PlayScout"
npm.cmd ci
npm.cmd run doctor
```

В PowerShell используйте именно `npm.cmd`: менять политику выполнения PowerShell для запуска этих файлов не требуется.

## 4. Установить локальный ИИ для вашей NVIDIA

1. Обновите драйвер NVIDIA при необходимости: https://www.nvidia.com/en-us/drivers/ .
2. Установите Ollama для Windows: https://ollama.com/download/windows .
3. Откройте приложение Ollama. Оно должно работать в фоне.
4. В папке PlayScout запустите **`5-Local-AI.cmd`**. Этот файл скачает `qwen3.5:4b` — несколько гигабайт.

Та же команда в новом окне Терминала:

```powershell
ollama pull qwen3.5:4b
```

Перенесённая с Mac история не переносит веса модели: на Windows модель нужно установить отдельно. Для этого профиля программа использует короткий контекст и отключает отдельный режим рассуждений Qwen3. Одновременно выполняется один локальный разбор, чтобы не переполнять видеопамять.

## 5. Подключить ключи

Запустите **`4-Keys.cmd`** и выберите нужный пункт:

- `1` — Brave: веб-поиск, публикации, реклама, реестры.
- `2` — OpenAI API, если хотите использовать его.
- `3` — Gemini API как дополнительный облачный ИИ.
- `4` — пароли владельца и пользователей просмотра.

Если `.env` уже перенесён с Mac, прежние ключи сохраняются. Для Google Play отдельный поисковый API-ключ не нужен; для локальной Ollama ключ ИИ не требуется.

Ключ Gemini создаётся в https://aistudio.google.com/apikey . Бесплатные квоты, доступные модели и условия оплаты зависят от аккаунта и региона. Подписка ChatGPT не оплачивает ни Gemini, ни OpenAI API. Ключи вводятся скрыто и сохраняются локально; после изменения ключей перезапустите программу.

## 6. Запустить

Дважды щёлкните **`2-Start.cmd`**. Он дождётся ответа программы и откроет браузер:

**http://127.0.0.1:3000/crm**

Оставьте окно программы открытым. Для остановки запустите **`3-Stop.cmd`**: программа сохранит очереди и завершится. Повторный запуск `2-Start.cmd` при уже работающем приложении открывает существующий экземпляр.

В CRM откройте «Настройки источников, ИИ и ежедневного поиска»:

1. Где выполнять анализ: **Ollama**.
2. Объём разбора: **Экономный**.
3. Модель Ollama: **`qwen3.5:4b`**.
4. Нажмите «Сохранить настройки» и «Проверить Ollama на этом компьютере».
5. Откройте одну карточку и нажмите «Разобрать этот сервис через ИИ».

После завершения в карточке видны время генерации и скорость, сообщённые Ollama. Проверьте несколько известных подходящих и неподходящих примеров, прежде чем запускать всю очередь.

## 7. Проверить, используется ли NVIDIA

Во время или после первой генерации запустите **`6-Diagnostics.cmd`**. Или в новом Терминале:

```powershell
ollama list
ollama ps
nvidia-smi
```

`ollama list` показывает установленные модели. В `ollama ps` ожидается `100% GPU`: это размещение модели на видеокарте. До первой генерации этот список может быть пустым. Контекст экономного запроса — 4096; ранее загруженный большой контекст Ollama иногда сохраняет до выгрузки модели.

Если память занята старой моделью, сначала остановите разбор в CRM, затем:

```powershell
ollama stop qwen2.5:7b
```

Если модель работает на CPU или возникают тайм-ауты, проверьте драйвер и попробуйте меньшую `qwen2.5:3b`. Сначала проверяйте одну карточку. Реальная скорость зависит от конкретной видеокарты, памяти и материала сайта.

## 8. Быстрая работа со списками

- Выберите причину в панели исключений один раз. Затем используйте «Исключить» прямо в строках или отметьте несколько / весь текущий список и нажмите «Исключить выбранные».
- Причины: **«Уже в работе / был в работе»**, **«Не банк и не провайдер»**, **«Не подходит локация»**.
- Во вкладке **«Исключены вручную»** есть отдельные фильтры причин, массовое восстановление и возможность изменить причину выбранным записям.
- Старые исключения без причины находятся в «Без причины / прежние исключения». Их можно классифицировать массово.
- Проверяются известные названия бренда, варианты названия, ID приложений и домены. Общее упоминание банка в описании другого сервиса не является основанием скрывать другой сервис. Причина сопоставления видна в карточке.
- Сортировка работает во всех вкладках CRM и на отдельных страницах источников. Можно выбрать релиз, публикацию, решение о лицензии или обнаружение. Неизвестные даты находятся в конце; обнаружение не выдаётся за дату запуска.
- App Store отключён. Ранее сохранённые записи доступны в «Архив источников».
- Кнопка «Лицензии → сайты → ИИ» ищет разрешения, извлекает организации и пытается найти и прочитать их сайты. Проверенные связи с сайтами добавляются в очередь того же разбора. Разрешение и предложение бизнес-счёта проверяются отдельно.
- Ночной режим переключается кнопкой в верхнем меню и запоминается для вашего браузера.

## 9. Дополнительный облачный ИИ

Если хотите сравнить скорость с локальной моделью:

1. Через `4-Keys.cmd` добавьте ключ Gemini и перезапустите приложение.
2. В CRM выберите Gemini и доступную в вашем аккаунте модель Flash / Flash-Lite. Подготовленный вариант: `gemini-2.5-flash-lite`; при изменении доступности моделей у Google укажите актуальное имя из AI Studio.
3. Сохраните настройки и нажмите «Проверить выбранный облачный ИИ». Этот тест выполняет реальное обращение и учитывается в использовании API.
4. Начните с одной карточки. Параллельность облачного разбора регулируется отдельно: 1–6 одновременных запросов, по умолчанию 3. Это не квота числа проектов. При ограничениях бесплатного тарифа уменьшите параллельность и проверьте квоту Google.

При ошибке локального ИИ платный провайдер автоматически не вызывается. Переключение выполняете вы. Неизменные данные используют сохранённый кэш соответствующей модели.

## 10. Дать ссылку людям в вашей сети

1. Через `4-Keys.cmd` → `4` задайте пароль владельца и отдельный пароль просмотра, каждый не короче 12 символов.
2. Перезапустите программу через `3-Stop.cmd`, затем `2-Start.cmd`.
3. При запросе Windows разрешите Node.js доступ в вашей частной сети.
4. Выполните `ipconfig` в Терминале и найдите IPv4 активного Ethernet / Wi-Fi.
5. Другие люди в той же сети открывают `http://ВАШ_IP:3000/crm`.

Логин **`admin`** — изменения и запуск поиска. Логин **`viewer`** — чтение и выгрузки; изменения и вызовы ИИ запрещены сервером. Передайте людям именно пароль просмотра, если им не нужно редактировать. Пространство общее, а не отдельная копия базы на каждого пользователя. Для смены сохранённого браузером входа удобно открыть приватное окно.

Без пароля обычный настольный запуск слушает только `127.0.0.1`. Для общей сети должен быть задан пароль владельца; явный `HOST=127.0.0.1` в `.env` оставляет доступ локальным.

## 11. HTTPS-ссылка людям из другой сети

Для этого можно использовать **Tailscale Funnel**. Он публикует HTTPS-доступ к программе на вашем Windows-компьютере; учётная запись, доступность Funnel и условия плана проверяются у Tailscale.

1. Сначала настройте оба пароля приложения, как в предыдущем разделе.
2. Установите Tailscale: https://tailscale.com/download/windows . Войдите в свой аккаунт.
3. Оставьте Play Scout запущенным. В новом Терминале выполните:

```powershell
tailscale funnel --bg 3000
```

4. Если Tailscale попросит включить Funnel, откройте выданную им страницу подтверждения в своём аккаунте.
5. Скопируйте напечатанный HTTPS-адрес и добавьте к нему `/crm`. Это ссылка для других людей. Им не требуется устанавливать Play Scout.
6. Люди входят как `viewer` с вашим паролем просмотра. Ключи Brave / Gemini / OpenAI остаются на вашем ПК.

Отключить публикацию:

```powershell
tailscale funnel reset
```

При выключении или сне компьютера ссылка и ежедневный поиск недоступны. Документация Funnel: https://tailscale.com/kb/1223/funnel . Вариант для доступа только участников вашей сети Tailscale — `tailscale serve`, а не публичный Funnel.

## 12. Ежедневная работа

В CRM задайте время по Калининграду и нажмите «Включить ежедневный сбор + ИИ». Программа должна работать к этому времени. В Windows настройте сон так, чтобы включённый в питание ПК продолжал работать; экран можно выключить или заблокировать.

Для автозапуска при входе в Windows нажмите Win+R → `shell:startup` → Enter и поместите туда **ярлык** `2-Start.cmd`. Ollama также должна запускаться при входе. Пропущенный запуск выполняется после следующего включения приложения; очередь и исключения сохраняются.

## 13. Обновление и резервные копии

Остановите приложение через `3-Stop.cmd`, скопируйте `data` и `.env` в отдельную личную папку с датой. Распакуйте новую версию, перенесите туда `data` и `.env`, запустите `1-Install.cmd`, затем `2-Start.cmd`. При переустановке не заменяйте заполненную папку `data` пустой. CSV / Word — выгрузки, а полная история для восстановления находится в `data/state.json`.
