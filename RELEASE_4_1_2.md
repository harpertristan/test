# Play Scout 4.1.2 — исправление Windows-файлов запуска

В 4.1.1 при открытии `9-Import-keys-only.cmd` Windows могла читать обрезанные фрагменты команд (`orlevel`, `de`, слова из сообщения вместо команды). Файл не доходил до приглашения ввода пути; нажатие клавиши в `pause` закрывало окно. Это ошибка выпуска, а не неправильный путь пользователя.

- Все девять `.cmd` теперь содержат только ASCII-команды и настоящие окончания строк CRLF без BOM. Сообщения Node и интерфейс остаются на русском.
- `.gitattributes` сохраняет CRLF непосредственно в Git и ZIP, а не только при локальном checkout. Проверяется именно содержимое архива.
- Windows-запуски сохраняют код ошибки после `pause`; включены расширения CMD, выключено отложенное раскрытие переменных для путей с восклицательным знаком.
- Исправление не меняет историю, ключи, критерии поиска или ИИ-модели. Чистая установка по-прежнему начинает с пустой базы и выключенных расписаний.

**Без повторного скачивания:** в Проводнике откройте папку программы, в адресной строке напечатайте `powershell` и нажмите Enter. Выполните по очереди:

```powershell
node .\scripts\import-keys.js
npm.cmd ci
npm.cmd run start:desktop
```

Первую команду завершите вводом пути к `PlayScout-keys.env`. Перед выполнением следующей дождитесь окончания предыдущей. Импорт только ключей не переносит историю.
