# Play Scout 4.6.0 — обновление Windows / 32 ГБ / NVIDIA 8 ГБ

После проверки явно неподходящие уходят в «Автоисключения», сильные кандидаты — в «Совпадения ИИ», сомнительные остаются в «Проверить вручную». Готовые разборы текущего прохода распределяются без новых запросов. Ручные решения, очередь, ключи и выбранный ИИ сохраняются. [Подробности](RELEASE_4_6.md).

Для чистой установки: [INSTALL_WINDOWS.md](INSTALL_WINDOWS.md).

## Обновить установленную копию через код

Откройте новое окно **PowerShell**. По вашим скриншотам программа находится в **`C:\Users\ivano\PlayScout`**; `$env:USERPROFILE` подставит `C:\Users\ivano`. Если вы переместили папку, замените путь в первой строке.

Скопируйте весь блок:

```powershell
& {
  $ErrorActionPreference = 'Stop'
  Set-Location "$env:USERPROFILE\PlayScout"
  if (-not (Test-Path -LiteralPath '.\package.json')) { throw 'Open the PlayScout folder containing package.json.' }
  $PlayScoutUpdater = Join-Path $env:TEMP ('play-scout-bootstrap-' + [guid]::NewGuid().ToString('N') + '.ps1')
  try {
    [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
    Invoke-WebRequest -UseBasicParsing -Uri 'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-windows.ps1' -OutFile $PlayScoutUpdater -TimeoutSec 60
    & powershell.exe -NoProfile -ExecutionPolicy Bypass -File $PlayScoutUpdater -Target (Get-Location).Path -Start
    if ($LASTEXITCODE -ne 0) { throw 'Update failed. Read the error above; keep data and .env.' }
  } finally {
    if (Test-Path -LiteralPath $PlayScoutUpdater) { Remove-Item -LiteralPath $PlayScoutUpdater -Force }
  }
}
```

Скрипт скачает архив во временную папку, попросит старую программу остановиться и сохранить очередь, создаст резервную копию рядом с PlayScout, заменит код в **той же папке**, выполнит `npm ci`, диагностику и запуск. Он не переносит данные в новую папку программы. `.env`, `data`, комментарии и выбранный ИИ остаются на месте. Обновление с 4.4 не сбрасывает действующие решения и исключения.

Дождитесь **«Готово: Play Scout 4.6.0»** и откройте **http://127.0.0.1:3000/crm**. Обновите старую вкладку один раз. При нестандартном порте используйте адрес из окна программы. Ключи заново импортировать не нужно. Окно программы оставьте открытым.

Если старая программа не отвечает на остановку, обновление не начинает замену кода. Остановите именно её старое окно через Ctrl + C, дождитесь приглашения PowerShell и повторите блок. Если установка зависимостей завершится ошибкой, updater восстановит прежний код и напечатает путь к резервной копии; перед повторным запуском может понадобиться `npm.cmd ci` в рабочей папке.

После этого для следующих обновлений доступен **`10-Update.cmd`**, либо из папки программы:

```powershell
cd "$env:USERPROFILE\PlayScout"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-windows.ps1 -Target (Get-Location).Path -Start
```

Файлы `.command` предназначены для Mac; Windows использует `.cmd` / `.ps1`. Архив скачивается с GitHub без ваших ключей; ключи берутся из существующей локальной `.env`.

## Обычный запуск

```powershell
cd "$env:USERPROFILE\PlayScout"
npm.cmd run start:desktop
```

Или **`2-Start.cmd`**. Для остановки — **`3-Stop.cmd`**, диагностики — **`6-Diagnostics.cmd`**. Не запускайте npm из `C:\Windows\System32`.

## Отдельные источники и общая база

В CRM нажмите **«Выбрать источник поиска»**. У каждого отдельного сайта, издания или реестра есть «Искать только здесь», остановка и собственное ежедневное расписание. Google Play остаётся отдельным основным источником. App Store не возвращается.

Для очереди Google нажмите **«Продолжить карточки Google Play»**. Для всех записей ручной вкладки — **«Все карточки на проверке → сайты + ИИ»**. После остановки доступно **«Продолжить полную проверку»** без повторения успешно завершённых карточек. Ручные исключения и записи в работе пропускаются. Облачные API могут быть платными.

В настройках выберите **«GPT + Ollama · общая очередь параллельно»**, сохраните и проверьте оба ИИ отдельными кнопками. Требуются работающая Ollama с установленной моделью и отдельный ключ / баланс OpenAI. На вашей NVIDIA 8 ГБ можно начать с `qwen2.5:3b`; установите **Ollama для Windows с https://ollama.com/download/windows**, откройте новое PowerShell и выполните:

```powershell
ollama pull qwen2.5:3b
ollama list
```

Укажите **`qwen2.5:3b`** в поле модели Ollama. Одна локальная и выбранное число облачных карточек работают одновременно. Проверьте `ollama ps` во время разбора: использование GPU определяется драйвером и установкой Ollama. Профиль llama.cpp из GPU_AGENT.md также сохранён как отдельный вариант; гибридный режим 4.5 использует именно Ollama + OpenAI.

Кнопка «Находки в общей базе» включает фильтр; Word / CSV / JSON используют тот же фильтр и ручные исключения. Фильтр не создаёт другую базу. Один проект может иметь подтверждения из нескольких источников.

Если осталось прежнее общее расписание, интерфейс покажет его. Нажмите «Отключить прежние общие расписания» и включите только нужные отдельные. Время — Калининград UTC+2. Сбор и ИИ не запускаются автоматически лишь от применения аппаратного профиля.

## Распределение после проверки

Откройте «Совпадения ИИ» для сильных кандидатов. «Проверить вручную» содержит оставшиеся сомнения и непроверенное. «Продолжить полную проверку» продолжает незавершённую очередь, сохраняя выбранный GPT + Ollama. Явно неподходящие доступны в «Автоисключения» с причиной / источником и кнопкой «Вернуть на ручную проверку». «Подтверждено мной» ставится вами. Обновление не запускает новый платный проход автоматически.

## ИИ и видеокарты

Установка CUDA-сборки llama.cpp, модели, профиль **Windows · 32 ГБ RAM / NVIDIA 8 ГБ** и проверка одной карточки — **[GPU_AGENT.md](GPU_AGENT.md#windows-одна-карта)**.

Шесть RTX 2060 Super на одном компьютере: **[запуск шести GPU-обработчиков](GPU_AGENT.md#ферма-шесть-rtx-2060-super-в-одном-компьютере)**. Профиль фермы распределяет разные карточки; он не объединяет VRAM автоматически и не ускоряет ограничения Google / Brave. Цена облачного API не возникает при локальном разборе; Brave остаётся отдельным источником со своим биллингом.

Из среды разработки нельзя проверить ваш драйвер, физические GPU, PowerShell 5.1 и пропускную способность PCIe. Проверены логика обновления / отката и протокол локальных серверов; аппаратный результат измеряется на вашем компьютере по инструкции.
