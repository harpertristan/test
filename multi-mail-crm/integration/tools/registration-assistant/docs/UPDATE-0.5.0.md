# 0.5.0 · Помощник как второй раздел Play Scout

Добавлен серверный режим общего пространства: Play Scout и помощник открываются по одному адресу, помощник работает по `/assistant/`, доступ наследуется от Play Scout. Отдельная форма входа помощника в этом режиме скрыта. Локальный самостоятельный режим совместим с прежними данными и входом.

- Единая навигация между CRM и документами; сохранены роли admin / viewer и ограниченный токен расширения.
- Расширение принимает HTTPS-адрес с `/assistant/` и обращается к правильному API.
- Экспорт данных для сервера включает SQLite, оригиналы файлов и `.secrets/ai-master.key`. Импорт проверяет контрольные суммы, запрещает ссылки и выход за папку, не заменяет существующую базу.
- Скрипт установки сохраняет существующие данные CRM, её `.env`, сертификаты Caddy и модель Ollama. Код новой панели размещается отдельно; создаётся согласованная резервная копия CRM и предусмотрен возврат прежних приложения и Caddy.
- Для Play Scout подготовлены обычное, ночное и фиолетовое оформление с новым персонажем с лупой. Изображение помощника не изменено.

Полная инструкция: [PLAY-SCOUT-MIGRATION.md](PLAY-SCOUT-MIGRATION.md).

Проверено: 99 тестов помощника, 545 тестов Play Scout, перенос зашифрованной настройки OpenAI с последующей расшифровкой, реальные Docker-образы и Caddy, браузерный переход без второго входа, доступ viewer, запросы расширения по токену, отклонение поддельных заголовков, мобильная компоновка и обычный режим помощника. Сервер пользователя из этой среды не изменялся: установка выполняется командами инструкции в его SSH-сессии.
