# 0.3.3: PDF до 30 сканированных страниц

Ограничение в 8 страниц было установлено в локальном OCR помощника для ограничения времени и потребления ресурсов, а не в модели OpenAI. Теперь один PDF может содержать до 30 сканированных страниц. Общий предел для PDF остаётся 60 страниц, размер файла — до 15 МБ.

Страницы распознаются по очереди с сохранением их номеров. После каждой страницы освобождается растровый холст. Лимит обработки одного файла увеличен с 3 до 15 минут. Это максимальное время ожидания, а не обещание, что любой документ будет прочитан за одинаковое время: оно зависит от качества сканов и скорости компьютера/сервера. Файлы с ошибкой не сохраняются как успешно прочитанные.

После загрузки результат показывает количество прочитанных страниц. В регрессионном тесте настоящий OCR обрабатывает все 30 страниц синтетического PDF без текстового слоя; проверяется реквизит, расположенный только на 30-й странице. Всего проходят 46 тестов.

Обновите помощник через код. После успешного обновления перезагрузите страницу http://127.0.0.1:3100 и заново загрузите PDF, который раньше был отклонён. Данные, существующие документы и ключ OpenAI сохраняются. После появления новых данных повторно проверьте итоговую карточку компании и подтвердите её оператором.
