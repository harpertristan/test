# Обновление 0.3.0: анкеты и OpenAI

1. Сохраните черновик банковской анкеты. В папке помощника запустите `Update-Windows.cmd`. Дождитесь сообщения об успешном обновлении. Если используете версию 0.1/0.2, сначала остановите её Ctrl+C и следуйте [инструкции обновления](AUTO-UPDATE.md).
2. В Dolphin откройте `chrome://extensions`, включите «Режим разработчика», найдите помощника и нажмите кнопку перезагрузки с круглой стрелкой. Обновите вкладку анкеты. Если расширение загружалось из другой папки, удалите его и загрузите папку `extension` из обновлённой установки через «Загрузить распакованное расширение».
3. В панели загрузки документов откройте «Настройки OpenAI». Вставьте API-ключ только туда и укажите доступную вашему проекту модель, например `gpt-4.1-mini`. Нажмите «Сохранить», затем «Проверить соединение». Подписка ChatGPT не заменяет оплату API. Ключ хранится на сервере зашифрованным; каталог данных и ключ шифрования нужно сохранять вместе в резервной копии. Для сервера используйте HTTPS.
4. Загрузите блокнот и официальные документы. Запустите извлечение. Для сложного текста доступен отдельный смысловой разбор OpenAI с подтверждением отправки текста документов. Проверьте расхождения и итоговые данные, затем поставьте общую галочку подтверждения оператором.
5. Откройте помощника на анкете. Сначала выберите компанию. Подписи над и под полями, блоки Registered/Operating address и варианты названий учитываются совместно. Нажмите «Заполнить найденные пустые поля» либо вставляйте значения по одному.
6. Подсказки у полей включены автоматически. Нажмите значок возле поля или переведите в него курсор: появятся значение, источник и русское объяснение. Уже введённые данные при групповом заполнении сохраняются.
7. Для нестандартных форм нажмите «Агент: разобрать анкету». После согласия OpenAI получает подписи и структуру полей, без введённых значений и документов. Новые смысловые соответствия подтвердите кнопкой «Подтвердить назначение поля». Подтверждённое соответствие сохраняется для этой компании, сайта и структуры поля. Это память сопоставлений, а не обучение весов модели.

Юридическое название подходит для Company or Trading name. Отдельное Trading name требует отдельного подтверждённого торгового названия. Адрес регистрации и операционный адрес разделены; неизвестный операционный адрес не копируется автоматически. Адресные строки, город, индекс и страна извлекаются отдельно; непонятный формат требует проверки.

VAT, Tax/TIN/UTR и LEI — разные реквизиты. Отсутствующий VAT не заменяется UTR. Для Tax number учитывается страна налогового резидентства: если в анкете выбрана Malta, а подтверждены сведения UK, заполнение блокируется до проверки страны. Страна регистрации сама по себе не доказывает налоговое резидентство. Формат даты подстраивается под явно указанный MM-DD-YYYY/DD-MM-YYYY.

Галочки юридических подтверждений, одинаковости адресов, подпись и отправка анкеты остаются оператору. Неизвестные значения помощник оставляет пустыми. Универсальное распознавание любых сайтов без ошибок не гарантируется.

Проверка разработки: 40 автоматических тестов и браузерные сценарии с искусственными данными. OpenAI и API расширения в сценариях имитируются; платный запрос с реальным ключом здесь не выполнялся. Chromium среды запрещает установку расширений политикой администратора, поэтому панель и оверлей проверены в браузере с имитацией runtime расширения. После установки выполните проверку соединения и пробное заполнение в Dolphin.
