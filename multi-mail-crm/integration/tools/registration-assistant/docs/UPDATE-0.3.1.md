# OpenAI: исправление подключения 0.3.1

Общая ошибка сервера больше не скрывает известные причины отказа OpenAI: неподключённый ключ, неверный ключ, недоступная модель, квота/оплата API, частота запросов, сеть и таймаут. Текст провайдера и ключ не выводятся. Для GPT-5 включена низкая интенсивность рассуждений; проверке соединения выделен больший лимит ответа. Это устраняет возможный пустой текст из-за расхода лимита на рассуждения; реальное соединение проверяйте кнопкой в интерфейсе.

Поддерживаются AI_API_KEY/AI_MODEL и названия из Play Scout OPENAI_API_KEY/OPENAI_MODEL. Если модель не указана, при наличии ключа используется gpt-5-mini. Настройка конкретного пользователя в интерфейсе имеет приоритет над настройками сервера.

Для переноса настроек остановка фонового процесса вручную больше не нужна. После обновления откройте PowerShell и выполните:

```powershell
Set-Location "$env:USERPROFILE\OneDrive\Desktop\registration-assistant"; $scout=(Read-Host 'Вставьте путь к папке Play Scout').Trim().Trim('"'); node scripts/import-play-scout.mjs $scout
```

Команда читает .env установленного Play Scout, переносит только ключ OpenAI и модель в .env помощника и перезапускает только проверенный экземпляр этой установки через закрытый локальный механизм остановки. Она не копирует ключи Brave, Gemini или другие настройки Play Scout. Ключ не печатается. Исходный Play Scout не меняется. Если ключа в исходном .env нет, выводится ошибка, текущие настройки не изменяются.

Обновите страницу http://127.0.0.1:3100 и нажмите «Проверить подключение». Если показано «Используется ваш сохранённый ключ», а нужен ключ сервера, нажмите «Удалить мой сохранённый ключ». Удаляется только личная настройка помощника; ключ Play Scout и .env сервера сохраняются.

Ошибки подключения проверены с имитацией OpenAI; настоящий ключ разработчику не передавался.
