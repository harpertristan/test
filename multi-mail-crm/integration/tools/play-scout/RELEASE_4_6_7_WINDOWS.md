# Play Scout 4.6.7 — Windows / 32 ГБ RAM / NVIDIA 8 ГБ

Те же исправления отсева и локальная перепроверка, что на Mac.
[Поведение и ограничения](RELEASE_4_6_7.md).

Остановите приложение через Ctrl + C. Откройте PowerShell:

```powershell
cd "$env:USERPROFILE\PlayScout"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-windows.ps1 -Target (Get-Location).Path
if ($LASTEXITCODE -ne 0) { throw 'Обновление не завершено.' }
npm.cmd run start:manual
```

Для другой рабочей папки замените первую строку. Дождитесь
**«Готово: Play Scout 4.6.7»**. CRM откроется на http://127.0.0.1:3000/crm.

База не очищается. Updater сохраняет backup кода / всей `data` / `.env`.
Все записи в работе, комментарии, ручные решения, очередь карточек, фильтры,
выбранные модели, расход и настройки NVIDIA 8 ГБ / шести RTX 2060 Super сохраняются.
Ежедневные задания при ручном запуске приостановлены; их настройки не удаляются.

Первый локальный пересчёт сохранённых ответов не вызывает сайты, Brave или ИИ.
Для применения исправлений кнопка «Повторить проблемные» не нужна.
Неизвестный EU IBAN остаётся неизвестным; ручное подтверждение не выставляется.

Для проверки конкретных оставшихся ошибок экспортируйте полный JSON из
**«Автоисключений»**, а для сопоставления прежних отметок — **«В работе /
был в работе» → «Данные для ChatGPT»**. Обе операции без API.

Остановка — Ctrl + C или `3-Stop.cmd`. Повторный ручной запуск —
`npm.cmd run start:manual` из рабочей папки. Обычный `2-Start.cmd` использует
сохранённые включённые расписания.
