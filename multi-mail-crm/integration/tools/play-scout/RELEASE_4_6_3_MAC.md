# Play Scout 4.6.3 — Mac M5 / 16 ГБ: очистить старые результаты

Блок ниже обновляет программу и **очищает все старые находки / очереди, кроме
проектов «В работе / был в работе»**, с обязательной резервной копией. Старые
подтверждения и ручные исключения других категорий также удаляются.
Действующие критерии, реестр ориентиров, модель, расписания, ключи и учёт
расхода сохраняются. [Точный состав очистки](RELEASE_4_6_3.md).

## Обновление и очистка

Сначала нажмите Control + C в окне прежней программы, дождитесь завершения.
Если открыт диагностический экземпляр, его тоже остановите. Откройте новое
окно Терминала и вставьте блок целиком:

```bash
(
  set -e
  cd "$HOME/Desktop/play-scout-v31"
  PLAY_SCOUT_UPDATER=$(mktemp "${TMPDIR:-/tmp}/play-scout-update.XXXXXX")
  trap 'rm -f -- "$PLAY_SCOUT_UPDATER"' EXIT
  curl --fail --location --retry 2 \
    --connect-timeout 15 --max-time 60 \
    'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-mac.sh' \
    -o "$PLAY_SCOUT_UPDATER"
  bash "$PLAY_SCOUT_UPDATER" "$PWD"
  npm run history:clean -- --apply
)
```

Дождитесь «Готово: Play Scout 4.6.3», затем «Очистка завершена».
Команда напечатает число сохранённых проектов в работе и полный путь к копии
старой истории. Приложение / поиск / ИИ автоматически не запускаются.

Если хотите сначала увидеть план, замените последнюю команду на
`npm run history:clean` без `--apply`. Она ничего не меняет. Затем для очистки
выполните `npm run history:clean -- --apply` в той же папке.

Если порт занят, сначала завершите программу. Если резервная копия не создана,
очистка не выполняется. Не удаляйте `data`, `.env` и напечатанную копию.

## Посмотреть результат без внешних заданий

```bash
cd "$HOME/Desktop/play-scout-v31" && npm run start:diagnostic
```

Оставьте окно открытым. На http://127.0.0.1:3000/crm будут надписи
«Диагностический запуск» и «База очищена». Старая ручная очередь будет пустой,
записи в работе останутся в своей вкладке. Известные приложения / сайты / статьи
о них защищены от повторного добавления по сохранённым идентификаторам.

Причина XProtect ещё не установлена. Эта очистка её не устраняет и не является
проверкой безопасности Mac. Полную проверку пока не возобновляйте. Если macOS
снова показывает блокировку, завершите процесс и не обходите защиту.

Для нового обычного поиска после выяснения причины блокировки сначала
остановите диагностический режим. `npm run start:desktop` использует прежние
расписания: включённые задания могут запуститься автоматически и расходовать API.
Кнопка «Всю базу на повторную проверку» для нового старта не нужна.

Чтобы только обновить код без очистки, выполните лишь updater; команду
`history:clean -- --apply` в этом случае пропустите.
