# Play Scout 4.6.2 — Mac M5 / 16 ГБ

Исправлена чрезмерная перезапись базы. Причина предупреждения XProtect пока
не установлена: [что изменено и что подтверждено](RELEASE_4_6_2.md).

## Обновление без автоматического запуска

Остановите прежнюю программу через Control + C в её Терминале.
Откройте новое окно Терминала и вставьте блок целиком:

```bash
(
  set -e
  cd "$HOME/Desktop/play-scout-v31"
  PLAY_SCOUT_UPDATER=$(mktemp "${TMPDIR:-/tmp}/play-scout-update.XXXXXX")
  trap 'rm -f -- "$PLAY_SCOUT_UPDATER"' EXIT
  curl --fail --location --retry 2 \
    --connect-timeout 15 --max-time 60 \
    'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-mac.sh' \
    -o "$PLAY_SCOUT_UPDATER"
  bash "$PLAY_SCOUT_UPDATER" "$PWD"
)
```

Дождитесь «Готово: Play Scout 4.6.2». Программа автоматически не запускается.
Updater сохраняет резервную копию всей папки данных и `.env`, устанавливает
зависимости без их установочных скриптов. Если macOS блокирует сам updater,
не обходите блокировку. Не удаляйте `data`, `.env` и резервную копию.

## Первый запуск — без поиска и ИИ

```bash
cd "$HOME/Desktop/play-scout-v31" && npm run start:diagnostic
```

Оставьте окно открытым. После «Программа готова» откроется
http://127.0.0.1:3000/crm. Вверху должно быть **«Диагностический запуск»**.
В этом режиме доступны сохранённые списки и выгрузки; поиск, ИИ, проверки
подключений и изменение карточек заблокированы. Файлы истории и сохранённые
расписания не меняются. Для завершения нажмите Control + C.

Пока предупреждение XProtect не разобрано, **не возобновляйте полную проверку**.
Если системное окно появляется даже здесь, завершите процесс и сохраните время
срабатывания / сообщения Терминала. Не отключайте защиту и не снимайте карантин.
Диагностический запуск не является заключением, что блокировка устранена.

## После выяснения причины блокировки

Для возврата к обычному режиму сначала остановите диагностический, затем
используйте `npm run start:desktop`. В обычном режиме сохранённые включённые
расписания могут запускать поиск и платные API. Готовые результаты и оставшаяся
очередь сохраняются; повторный сброс всей базы не нужен.

Выбранные GPT + Ollama и qwen2.5:7b не меняются. Для M5 / 16 ГБ по-прежнему
доступны отдельные профили qwen2.5:3b и llama.cpp / Metal в [GPU_AGENT.md](GPU_AGENT.md).
Обновление хранения не увеличивает скорость генерации самой модели.

Для ручного резервирования копируйте **всю `data` и `.env` после остановки**.
`state.json.journal` содержит актуальные изменения между полными снимками;
удалять его нельзя. Для переноса используйте штатный экспорт профиля.
