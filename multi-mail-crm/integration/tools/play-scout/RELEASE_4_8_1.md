# Play Scout 4.8.1 — результат проверки в открытой карточке

В 4.8.0 проверка могла успешно сохранить результат и обновить список, а открытая справа карточка продолжала показывать прежние сведения. Повторное открытие карточки загружало результат. Исправлено автоматическое обновление открытой карточки, в том числе когда остальные провайдеры в очереди ещё проверяются.

- В карточке видны ожидание, ход проверки, дата и модель последнего сохранённого разбора. Ошибка привязана к конкретному провайдеру. Если цитат недостаточно, это указано явно.
- Обновление читает сохранённые сведения: дополнительный сбор Apify или вызов ИИ не нужен. Неизменившаяся карточка при опросе не перерисовывается.
- Сохраняются черновик заметки, фокус и выделение в поле, раскрытые материалы и прокрутка карточки. Запоздавший ответ не заменяет другую выбранную карточку.
- При смене раздела, источника или поискового фильтра прежняя карточка закрывается. Ручная отметка «Подходит» по-прежнему оставляет подтверждение в открытой карточке.
- При ошибке чтения кнопка «Обновить карточку» повторяет только чтение CRM. «Проверить сведения» запускает разбор ИИ и блокируется на время работы.

Обновление не меняет правила отбора или формат базы и не требует повторной проверки провайдеров. Ключи, настройки задач Apify, результаты, заметки и ручные решения сохраняются.

Дождитесь завершения текущей проверки. Остановите программу в её Терминале через **Ctrl+C** и выполните в папке программы `npm run update:mac`, затем `npm run doctor -- --storage` и `npm run start:manual`. После запуска обновите страницу браузера и откройте нужную карточку: уже сохранённый результат загрузится без нового обращения к ИИ.

Полная проверка и её ограничения описаны в [VALIDATION.md](VALIDATION.md).
