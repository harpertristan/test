# Play Scout 4.4.0 — обновление Mac M5 / 16 ГБ

Обновление вернёт сохранённый список на ручную перепроверку, сохранив записи «Уже в работе / был в работе». Подробное поведение категорий и сброса: [RELEASE_4_4.md](RELEASE_4_4.md). История, комментарии, ключи, выбранная модель и её настройки остаются.

## Вставить в Терминал

Откройте **новое окно Терминала (Command + N)** и вставьте весь блок:

```bash
(
  set -e
  cd "$HOME/Desktop/play-scout-v31"

  PLAY_SCOUT_UPDATER=$(mktemp "${TMPDIR:-/tmp}/play-scout-update.XXXXXX")
  trap 'rm -f -- "$PLAY_SCOUT_UPDATER"' EXIT

  curl --fail --location --retry 2 \
    --connect-timeout 15 --max-time 60 \
    'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-mac.sh' \
    -o "$PLAY_SCOUT_UPDATER"

  bash "$PLAY_SCOUT_UPDATER" "$PWD" --start
)
```

Рабочая папка остаётся `~/Desktop/play-scout-v31`. Не вставляйте код в окно работающего Node. Updater остановит экземпляр из этой папки, сохранит резервную копию, обновит код и зависимости и запустит программу.

Дождитесь **«Готово: Play Scout 4.4.0»**, затем откройте **http://127.0.0.1:3000/crm** и обновите вкладку через **Command + R**. При первом старте выполняется разовый возврат базы на ручную проверку с отдельной копией состояния. Большой список может потребовать нескольких секунд.

## После обновления

Откройте **«Проверить вручную»**. Проверенные вами подходящие проекты отмечайте кнопкой **«Проверено: подходит»**. Они появятся в **«Подтверждено мной»**. В **«Впервые найденные»** старые восстановленные записи не попадают. Вкладка **«В работе / был в работе»** сохраняет защищённые записи.

Повторный запуск не повторяет сброс. Для отдельного повторного прохода есть кнопка **«Всю базу на повторную проверку»**. Её действие не вызывает ИИ.

Следующий обычный запуск:

```bash
cd "$HOME/Desktop/play-scout-v31" &&
bash ./2-Запустить.command
```

Остановка из нового окна:

```bash
cd "$HOME/Desktop/play-scout-v31" &&
npm run stop
```

Для вашего M5 / 16 ГБ остаётся [профиль llama.cpp / Metal](GPU_AGENT.md#mac-m5-16-гб). Это обновление не переключает выбранный движок, не переустанавливает модель и не включает платный API.
