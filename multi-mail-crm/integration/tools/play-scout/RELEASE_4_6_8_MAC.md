# Play Scout 4.6.8 — Mac M5 / 16 ГБ

Исправлен отсев по валютам, направлениям переводов, клиентским странам и
дополнительным функциям настоящих финансовых сервисов. [Изменения и пределы проверки](RELEASE_4_6_8.md).

Остановите текущий Play Scout через Control + C. В новом окне Терминала вставьте:

```bash
(
  set -e
  cd "$HOME/Desktop/play-scout-v31"
  PLAY_SCOUT_UPDATER=$(mktemp "${TMPDIR:-/tmp}/play-scout-update.XXXXXX")
  trap 'rm -f -- "$PLAY_SCOUT_UPDATER"' EXIT
  curl --fail --location --retry 2 \
    --connect-timeout 15 --max-time 60 \
    'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-mac.sh' \
    -o "$PLAY_SCOUT_UPDATER"
  bash "$PLAY_SCOUT_UPDATER" "$PWD"
  npm run start:manual
)
```

Дождитесь **«Готово: Play Scout 4.6.8»**. Терминал оставьте открытым.
CRM откроется на http://127.0.0.1:3000/crm в ручном режиме без ежедневных заданий.
Настройки расписаний сохраняются.

Сохранённые ответы пересчитаются локально один раз, без API. Updater делает
резервную копию всей `data` и `.env`; зависимости устанавливаются без install-скриптов.
Новая очистка не нужна. Все ваши записи в работе, комментарии, исключения,
незавершённые карточки, модели GPT + Ollama / qwen2.5:7b и расход сохраняются.
Счётчик записей в работе не ограничен исходными 39: новые ручные отметки тоже
сохраняются. Модель / профиль и параллельность автоматически не меняются.

Проверьте **«Проверить вручную»**, **«Впервые найденные»** и **«Автоисключения»**. Сервис, у которого
ещё не доказан EU IBAN, не становится подтверждённым от одного возвращения в
проверку. Повторный платный разбор для применения новых правил не требуется.

Если после обновления остался спорный отсев, для проверки доступны:

- **«Автоисключения» → «Выгрузить все автоисключения для проверки в ChatGPT · JSON»**.
- **«В работе / был в работе» → «Данные для ChatGPT»** — если нужно сверить
  сопоставление ранее отмеченного проекта с новым приложением / названием.

Эти выгрузки не вызывают API. Сохранённый статус и выбранная в поле причина
для следующего нажатия «Исключить» — разные вещи.

Следующий ручной запуск: `cd "$HOME/Desktop/play-scout-v31" && npm run start:manual`.
Причина прежнего XProtect не установлена; релиз её устранением не объявляется.
При новой блокировке остановите приложение и не повторяйте действие ради обхода.
