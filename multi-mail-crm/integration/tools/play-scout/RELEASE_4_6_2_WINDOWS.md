# Play Scout 4.6.2 — Windows / 32 ГБ RAM / NVIDIA 8 ГБ

[Изменения хранения, диагностический запуск и ограничения проверки](RELEASE_4_6_2.md).
Профили одной NVIDIA 8 ГБ и шести RTX 2060 Super сохраняются. Изменения
журнала базы общие для Windows и Mac; нативного прогона Windows здесь нет.

## Обновление существующей папки

Остановите Play Scout через Ctrl + C. Откройте PowerShell:

```powershell
cd "$env:USERPROFILE\PlayScout"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-windows.ps1 -Target (Get-Location).Path
```

Нет `-Start`: после установки приложение не запускается автоматически.
Используется updater из прежней версии, установку выполняет уже новый модуль.
`-ExecutionPolicy Bypass` относится к этому процессу PowerShell, не отключает
антивирус Windows. Дождитесь «Готово: Play Scout 4.6.2».
Updater сохраняет всю папку `data`, `.env` и резервную копию; база не сбрасывается.
Для другой рабочей папки замените первую строку её действительным путём.

## Запуск без поиска, ИИ и изменений

```powershell
cd "$env:USERPROFILE\PlayScout"
npm.cmd run start:diagnostic
```

Откроется http://127.0.0.1:3000/crm с надписью «Диагностический запуск».
Доступны сохранённые списки и выгрузки, внешние задания и изменение данных
отключены на время этого запуска. Настройки расписаний в базе не меняются.
Остановка — Ctrl + C или `3-Stop.cmd`.

## Обычный режим

После остановки диагностического экземпляра:

```powershell
npm.cmd run start:desktop
```

Обычный режим использует сохранённые расписания и выбранный ИИ. Внешние API
могут расходовать баланс. Сохраняются результаты, ручные отметки, исключения,
записи в работе, комментарии и оставшаяся очередь проверки.

Для ручной резервной копии сохраняйте **всю `data` и `.env` после остановки**,
включая `state.json.journal`. Один `state.json` во время работы может быть
неполным снимком текущей истории. Экспорт зашифрованного профиля собирает
полную переносимую историю, в том числе после аварии.

[Установка Windows с нуля](INSTALL_WINDOWS.md), [llama.cpp / NVIDIA и ферма](GPU_AGENT.md).
Все десять `.cmd` сохраняют ASCII и CRLF без BOM.
