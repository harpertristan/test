# Play Scout 4.8.4 — автоматическое объединение повторных карточек

Публикации рекламодателя Apify теперь объединяются и с карточкой сайта, найденного другим источником. Сопоставляется явно указанное имя рекламодателя с полным названием карточки сайта, без учёта пробелов и регистра. Единственный домен становится общей карточкой; при конфликтующих доменах автоматическое связывание по имени не выполняется.

Объединяются также сохранённые повторные записи архива отсеянных. Их материалы и исходные ссылки сохраняются; при наличии общей карточки архивные материалы добавляются в неё. Локальная консолидация переносит заметки, ручные решения и ссылки очереди с сохранением прежних записей в архиве идентичностей.

Обработка выполняется автоматически при открытии базы и поступлении новых записей в общий inbox. Ручной выбор дублей, повторный сбор Apify и отдельный платный разбор для объединения не нужны. Объединение не подтверждает соответствие продукта критериям: карточки используют существующие статусы и очередь проверки.

Проверки: 21 тест объединения идентичностей и Apify прошёл менее чем за секунду. Полный набор не запускался. Предел Facebook 500 и денежный параметр Apify 1 USD сохранены.

Обновление: дождитесь завершения текущих заданий, остановите приложение и сохраните резервную копию data и .env. В папке программы выполните npm run update:mac, npm run doctor -- --storage и npm run start:manual. После обновления страницы сохранённые повторы группируются автоматически. Облачная среда разработки не содержит пользовательской базы с компьютера; её обработка происходит локально после обновления.
