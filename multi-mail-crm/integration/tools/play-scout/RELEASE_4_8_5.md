# Play Scout 4.8.5 — кнопка-робот для разбора ИИ

На главной панели рядом с «Новый поиск» появилась отдельная заметная кнопка «Разобрать с ИИ» с нарисованным роботом и числом карточек. Она заменяет прежнюю «Проверить очередь» и запускает ту же общую очередь для найденных карточек независимо от первых 50 строк на экране. Нового сбора Apify кнопка не запускает; существующий разбор может обращаться к сайтам и платным API выбранной модели / поиска.

Во время работы робот показывает прогресс и мягко мигает глазами; повторный запуск блокируется. После остановки доступна кнопка «Продолжить с ИИ» для оставшихся карточек. При ненастроенном ИИ или пустой очереди показана подсказка. Сохранены ограничения доступа, кнопка остановки, поддержка клавиатуры и настройки уменьшения анимации. На узком экране кнопка занимает всю строку; поддерживаются обе темы.

Проверено: синтаксис public/crm.js; 7 существующих тестов из test/crm-live-result.test.js и test/hybrid-manual.test.js прошли за 3,4 секунды. Полный набор и визуальная проверка в браузере не выполнялись. Данные, настройки ИИ и лимиты Apify не изменены.

Обновление: остановите программу, сохраните копию data и .env, затем выполните в её папке npm run update:mac, npm run doctor -- --storage, npm run start:manual. Обновите страницу браузера.
