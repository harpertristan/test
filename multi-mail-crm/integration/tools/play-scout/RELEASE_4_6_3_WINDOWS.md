# Play Scout 4.6.3 — Windows / 32 ГБ / NVIDIA 8 ГБ

[Что удаляется и сохраняется](RELEASE_4_6_3.md). Остаются проекты
«В работе / был в работе», их комментарии, разборы и защита от повторов.
Остальные старые результаты, ручные решения / исключения и очереди очищаются.
Фильтры, ключи, модель, аппаратный профиль, расписания, ориентиры и расход API
сохраняются. Профиль шести RTX 2060 Super также не меняется.

## Обновить и очистить

Остановите программу через Ctrl + C, откройте PowerShell:

```powershell
cd "$env:USERPROFILE\PlayScout"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-windows.ps1 -Target (Get-Location).Path
if ($LASTEXITCODE -ne 0) { throw 'Обновление не завершено; очистка не запускалась.' }
npm.cmd run history:clean -- --apply
if ($LASTEXITCODE -ne 0) { throw 'Проверьте сообщение очистки выше.' }
```

Для другой рабочей папки замените первую строку её действительным путём.
Updater создаёт копию старого кода / `data` / `.env`; очистка дополнительно
сохраняет отдельный полный снимок истории. Дождитесь «Готово: Play Scout 4.6.3»
и «Очистка завершена». Путь к копии истории будет напечатан в окне.
Автоматического запуска приложения и поиска нет.

Для предварительного просмотра используйте `npm.cmd run history:clean`
без `--apply`. Он не меняет файлы. Занятый локальный порт, повреждённая история
или ошибка создания копии останавливают очистку.

## Проверить результат

```powershell
npm.cmd run start:diagnostic
```

Откроется http://127.0.0.1:3000/crm только с сохранёнными данными: старая очередь
пустая, проекты в работе — в своей вкладке. Есть надпись «База очищена».
В этом запуске поиск / ИИ / изменение карточек отключены.

Остановка — Ctrl + C или `3-Stop.cmd`. Для обычного нового поиска после
остановки диагностического режима используйте `npm.cmd run start:desktop`
или `2-Start.cmd`. Он использует сохранённые расписания; включённые задания
могут запускаться автоматически и расходовать API. Возвращать старую базу
на повторную проверку не нужно.

Не удаляйте напечатанную резервную копию до проверки результата. При ручном
резервировании сохраняйте всю папку `data` и `.env`, включая журнал базы.

Чтобы только обновить код без очистки, выполните лишь updater; команду
`history:clean -- --apply` в этом случае пропустите.
