# Play Scout 4.6.6 — Windows / 32 ГБ RAM / NVIDIA 8 ГБ

Тот же пересчёт сохранённых доказательств бизнес-IBAN, что на Mac.
[Описание исправления](RELEASE_4_6_6.md). Настройки NVIDIA 8 ГБ и шести
RTX 2060 Super, выбранные модели и ключи сохраняются.

Остановите текущий Play Scout через Ctrl + C. В PowerShell выполните:

```powershell
cd "$env:USERPROFILE\PlayScout"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-windows.ps1 -Target (Get-Location).Path
if ($LASTEXITCODE -ne 0) { throw 'Обновление не завершено.' }
npm.cmd run start:manual
```

Если программа находится в другой папке, замените только первую строку.
Дождитесь **«Готово: Play Scout 4.6.6»** и ручного запуска.
CRM откроется на http://127.0.0.1:3000/crm.

Updater создаёт резервную копию `data`, `.env` и кода. База не очищается.
Записи в работе, комментарии, ручные исключения, очередь карточек, фильтры,
сохранённые расписания, модели, аппаратный профиль и расход сохраняются.
Ежедневные задания в ручном экземпляре не запускаются.

Сохранённые ответы и кэш один раз пересчитываются локально при запуске,
без обращения к сайтам, Brave или ИИ. В проверенном сценарии Tide и Wamo
переходят в **«Совпадения ИИ»**, HYPE сохраняет неизвестный EU IBAN.
Отметку **«Подтверждено мной»** ставит только пользователь.

При необходимости нажмите **«Перепроверить сохранённое · без API»**.
Для этого исправления **«Повторить проблемные»** не требуется: эта кнопка
вызывает модель. Незавершённая очередь Google Play остаётся доступна отдельно.

Остановка — Ctrl + C или `3-Stop.cmd`. Последующий ручной запуск из папки
программы — `npm.cmd run start:manual`. Обычный `2-Start.cmd` /
`start:desktop` использует сохранённые включённые расписания.
