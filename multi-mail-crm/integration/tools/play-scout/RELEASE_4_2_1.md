# Play Scout 4.2.1 — выгрузка автоисключений для проверки

В CRM откройте вкладку **«Автоисключения»** и нажмите **«Выгрузить все автоисключения для проверки в ChatGPT · JSON»**. Скачивается **`play-scout-auto-exclusions.json`**. Прикрепите его в чат с просьбой проверить ложные исключения и предложить изменения правил.

В файле:

- весь сохранённый список автоисключений из всех источников, включая записи за пределами первых 50 строк интерфейса;
- этапы и причины: текстовые правила до ИИ, нигерийская юрисдикция, проверенные цитаты ИИ о типе продукта;
- исходные тексты, ссылки, факты / цитаты, комментарий модели и его исходный вариант, модель / режим / версии правил, ошибки источников и признак устаревшего разбора;
- текущие настройки поиска и ИИ, текущая инструкция модели, а также сохранённые настройки и счётчики прошлых запусков;
- отдельные примеры предварительной фильтрации источниками: категории, порог установок, даты, слова исключения и прочие причины. Такой предварительный отсев не всегда означает исключение из общей CRM;
- сводка по причинам и описание полноты данных.

**Эта кнопка выгружает все сохранённые автоисключения независимо от фильтров экрана.** Для Word / CSV или текущей выборки остаются обычные кнопки выгрузки вкладки. Ручные исключения не добавляются в основной список аудита; отсутствие доказательств EU IBAN само по себе не превращает находку в автоисключение.

Выгрузка не запускает ИИ, не читает сайты и не меняет решения. `.env`, ключи API, пароли и адреса локальных GPU-серверов в диагностические настройки не включаются. Оригиналы текстов и ваши комментарии сохраняются в выгрузке.

Исторические ограничения указаны в самом файле: старые тексты, которые не сохранялись, восстановить нельзя; примеры фильтрации Google Play сохранялись максимум по 30 на запуск; настройки на момент выгрузки могут отличаться от настроек старого задания. Эти пробелы не выдаются за полный архив всех когда-либо отброшенных результатов.

## Обновить Mac в прежней папке

Новое окно Терминала, затем весь блок:

```bash
cd "$HOME/Desktop/play-scout-v31" &&
npm run update:mac -- "$PWD" --start
```

Ожидаемая версия — **4.2.1**. История, ключи, модели и ручные исключения сохраняются. После запуска откройте http://127.0.0.1:3000/crm и обновите старую вкладку. [Полная инструкция Mac](RELEASE_4_2_MAC.md).

## Обновить Windows в прежней папке

В установленной версии 4.2 откройте **`10-Update.cmd`**. Или в новом PowerShell:

```powershell
cd "$env:USERPROFILE\PlayScout"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-windows.ps1 -Target (Get-Location).Path -Start
```

Для более старой Windows-копии без updater используйте [блок загрузки скрипта](RELEASE_4_2_WINDOWS.md#обновить-установленную-копию-через-код). Резервная копия создаётся автоматически; код обновляется в прежней папке. Настройки Mac M5 / 16 ГБ, Windows / 32 ГБ RAM / NVIDIA 8 ГБ и фермы остаются прежними.
