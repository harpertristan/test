# Play Scout 4.6.6 — Mac M5 / 16 ГБ

Исправлена проверка сохранённых цитат Tide и Wamo. Повторно оплачивать эти
разборы не нужно. [Поведение и ограничения](RELEASE_4_6_6.md).

## Обновить в прежней папке

Остановите работающий Play Scout через Control + C в его Терминале.
В новом окне Терминала вставьте весь блок:

```bash
(
  set -e
  cd "$HOME/Desktop/play-scout-v31"
  PLAY_SCOUT_UPDATER=$(mktemp "${TMPDIR:-/tmp}/play-scout-update.XXXXXX")
  trap 'rm -f -- "$PLAY_SCOUT_UPDATER"' EXIT
  curl --fail --location --retry 2 \
    --connect-timeout 15 --max-time 60 \
    'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-mac.sh' \
    -o "$PLAY_SCOUT_UPDATER"
  bash "$PLAY_SCOUT_UPDATER" "$PWD"
  npm run start:manual
)
```

Дождитесь **«Готово: Play Scout 4.6.6»**. Терминал оставьте открытым.
В браузере откроется http://127.0.0.1:3000/crm с надписью «Ручной запуск».
Сохранённые ответы пересчитаются локально один раз при запуске. Ежедневные
расписания в этом экземпляре приостановлены, их настройки сохраняются.

Updater делает резервную копию всей `data` и `.env`, устанавливает зависимости
без install-скриптов. Сохраняются записи в работе и заметки, незавершённые
карточки, исключения, фильтры, расход и GPT + Ollama / qwen2.5:7b. Настройка
llama.cpp не включается автоматически. `history:clean` запускать не нужно.

## Проверить результат без новой оплаты

Откройте **«Совпадения ИИ»**: в проверенном сценарии туда переходят Tide и Wamo.
Это не ставит ручную отметку «Подтверждено мной». У HYPE страна IBAN пока
не подтверждена; один оставшийся проблемный разбор ожидаем.

Для повторного локального пересчёта есть **«Перепроверить сохранённое · без API»**.
Кнопка **«Повторить проблемные»** отправляет тексты модели; для применения
этого исправления она не нужна. Новые источники и очередь Google Play
автоматически не запускаются.

Если предупреждение macOS вернётся, остановите приложение через Control + C
и не повторяйте заблокированное действие ради обхода защиты. Прежняя причина
XProtect пока неизвестна.

Следующий ручной запуск после остановки:

```bash
cd "$HOME/Desktop/play-scout-v31" && npm run start:manual
```
