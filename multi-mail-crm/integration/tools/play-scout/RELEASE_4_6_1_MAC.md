# Play Scout 4.6.1 — Mac M5 / 16 ГБ

[Исправление парсера и ограничения расследования XProtect](RELEASE_4_6_1.md).
Если уже появлялось «Вредоносный скрипт заблокирован», сначала остановите поиск
через Control + C в его Терминале и сохраните журнал. Не запускайте повторно
заблокированный файл и не отключайте защиту. Причина конкретного срабатывания
пока не установлена; новое ПО нельзя автоматически считать проверенным macOS.

## Обновление в той же папке, без автоматического запуска

Сначала завершите проверку системного предупреждения. При установке исправления
откройте новое окно Терминала. Блок скачивает опубликованный updater, обновляет
код и зависимости с резервной копией; приложение после установки не запускается:

```bash
(
  set -e
  cd "$HOME/Desktop/play-scout-v31"

  PLAY_SCOUT_UPDATER=$(mktemp "${TMPDIR:-/tmp}/play-scout-update.XXXXXX")
  trap 'rm -f -- "$PLAY_SCOUT_UPDATER"' EXIT

  curl --fail --location --retry 2 \
    --connect-timeout 15 --max-time 60 \
    'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-mac.sh' \
    -o "$PLAY_SCOUT_UPDATER"

  bash "$PLAY_SCOUT_UPDATER" "$PWD"
)
```

Если macOS блокирует updater, не обходите блокировку. Сохраните её текст и журнал.
Не удаляйте `.env`, `data` или резервную копию. Дождитесь «Готово: Play Scout
4.6.1». При обновлении зависимости устанавливаются с `--ignore-scripts`;
google-play-scraper / es5-ext больше не устанавливаются. База не сбрасывается.

## Обычный запуск после проверки предупреждения

```bash
cd "$HOME/Desktop/play-scout-v31" &&
npm run start:desktop
```

Оставьте окно открытым. Откройте http://127.0.0.1:3000/crm после сообщения
«Программа готова». Выбранный GPT + Ollama и qwen2.5:7b сохраняются; меньшая
qwen2.5:3b остаётся отдельным выбором для M5 / 16 ГБ. Профиль llama.cpp / Metal
описан в [GPU_AGENT.md](GPU_AGENT.md#mac-m5-16-гб).

Если сервер завершается, launcher теперь показывает сигнал / код. Сохраните
сообщения. Для очереди после разрешения проблемы используйте «Продолжить полную
проверку»; заново сбрасывать всю базу и отправлять готовые разборы не требуется.
Облачный разбор и Brave могут расходовать баланс при возобновлении.
