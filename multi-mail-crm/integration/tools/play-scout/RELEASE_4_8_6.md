# Play Scout 4.8.6 — подготовка переноса в Google Cloud с Ollama

Добавлены GOOGLE_CLOUD.md и deploy/google-cloud: Compute Engine GPU L4, Docker Compose, Ollama с постоянным каталогом моделей, Caddy HTTPS, защищённый запуск приложения, роли admin/viewer, согласованные копии, ежедневный timer, обновления с Mac через IAP SSH и инструкция отката.

Облачный запуск scripts/start-cloud.js требует пароль администратора и позволяет приостановить расписания при первоначальном переносе. Приложение может обращаться к Ollama в отдельном контейнере через OLLAMA_BASE_URL; обычный локальный адрес и параметр port сохранены. Dockerfile передаёт исходники владельцу node для запуска контейнера под UID 1000.

В среде разработки собран Docker-образ; проверены реальный запуск непривилегированного контейнера, health, блокировка анонимного доступа, просмотр viewer, запрет изменений viewer, доступ admin и сохранение заметки после корректного перезапуска. Конфигурация Compose и переключение расписаний проверены. Семь тестов cloud-ollama и hybrid-manual прошли за 2,9 секунды.

Google Cloud VM не создана; GPU, драйвер, DNS, публичный TLS-сертификат, импорт пользовательской базы и моделей, внешние API и сценарий обновления/отката на целевой VM не проверены. Файлы подготовлены для выполнения пользователем, это не заявление о завершённом переносе. Тариф и регион пользователь выбирает после проверки GPU-квоты и калькулятора.
