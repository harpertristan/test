# Play Scout 4.8.0 — Mac M5 / 16 ГБ

Объединение дублей, категории источников с галочками, проверка доступа, уточнение условий счёта и подключение Apify.
[Подробности](RELEASE_4_8.md).

Остановите прежний запуск через Control + C и дождитесь его завершения.
Затем вставьте в Терминал:

```bash
(
  set -e
  cd "$HOME/Desktop/play-scout-v31"
  PLAY_SCOUT_UPDATER=$(mktemp "${TMPDIR:-/tmp}/play-scout-update.XXXXXX")
  trap 'rm -f -- "$PLAY_SCOUT_UPDATER"' EXIT
  curl --fail --location --retry 2 \
    --connect-timeout 15 --max-time 60 \
    'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-mac.sh' \
    -o "$PLAY_SCOUT_UPDATER"
  bash "$PLAY_SCOUT_UPDATER" "$PWD"
  npm run doctor -- --storage
  npm run start:manual
)
```

Ожидается **«Готово: Play Scout 4.8.0»**. Диагностика хранилища без записи и API
покажет свободное место и согласованность файлов. Если диагностика завершится
ошибкой, запуск остановится; не удаляйте `data` или журнал ради её устранения.

Сохраняются записи в работе, заметки, правила, ключи, выбранные модели, очередь
и расписания. Updater делает резервную копию всей `data` и `.env`.
Очистку истории повторять не нужно. Ежедневные задания в ручном запуске приостановлены.

Для продолжения прерванного прохода используйте **«Продолжить проверку»**:
эта кнопка выбирает оставшиеся доступные карточки. **«Проверить очередь»** проверяет
текущий раздел «На проверку» и может расходовать API.

Если появится ошибка хранения, сохраните её **код** и результат
`npm run doctor -- --storage`. Не присылайте `.env`, ключи или пароли.
Сами файлы базы и журнал сохраняйте вместе. Блокировку и журнал вручную не удаляйте.

Повторный запуск:
`cd "$HOME/Desktop/play-scout-v31" && npm run start:manual`.

Подключение Facebook / LinkedIn через Apify после обновления: [SOCIAL_CONNECTIONS.md](SOCIAL_CONNECTIONS.md). Ключ и задачи вводятся локально; без настройки платный сбор не запускается.
