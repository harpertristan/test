# Проверка ИИ в Play Scout 4.1

При первом запуске 4.1 старые результаты перепроверяются по сохранённым текстам без сетевых и ИИ-запросов. Изменяются производные статусы и неверные выводы; исходные страницы, исключения и комментарии сохраняются. Автоматического платного повтора всей истории нет.

- «Перепроверить сохранённое · без API» — повторная локальная проверка цитат, лицензий, принадлежности источников и географии.
- «Повторить проблемные» — адресный разбор выбранной моделью по сохранённым материалам. Облачный API может расходовать баланс; для новых сайтов, найденных по лицензии, может использоваться Brave. Уже исключённые вручную записи в эту очередь не входят.
- При недостатке исходного текста откройте карточку и выполните обычный разбор: он попытается заново прочитать сайт. Подробный режим выбранной карточки получает больше материала.
- Факты могут подтверждаться прямым текстом официального продукта с дословной цитатой, без дополнительного вызова модели. Поле quality.recoveredFacts в JSON отмечает такие факты. Это заявление источника, не гарантия открытия вашей компании.
- Если модель не подтвердила ни одного факта, объяснение не подменяется уверенным комментарием. Непрошедшие проверку русские комментарии заменяются описанием проверенных фактов; оригинальный комментарий остаётся в карточке и диагностике. Иноязычный текст не выдаётся за русский перевод.
- Решение регулятора не доказывает наличие EU IBAN. Форма заявки не является выданным разрешением, а AMF/ESMA/NCA не являются получателями лицензии.

# ИИ в Play Scout 4.0

Три независимых варианта: **Ollama** на вашем ПК, **OpenAI API**, **Gemini API**. Выбираются в настройках CRM; автоматического переключения на платный провайдер нет. Ключи OpenAI, Gemini и Brave разные; подписка ChatGPT их не заменяет.

На Windows ключи вводятся скрыто через `4-Keys.cmd`. В терминале: `npm run configure:ai`, `npm run configure:gemini`, `npm run configure` для Brave. После изменения ключей нужен перезапуск.

## Для вашей NVIDIA с 8 ГБ+ видеопамяти

Установите Ollama и выполните `ollama pull qwen3.5:4b` или запустите `5-Local-AI.cmd`. Выберите Ollama, точное имя модели и экономный режим. Сначала проверьте одну карточку. Диагностика — `6-Diagnostics.cmd`, `ollama ps`, `nvidia-smi`.

Короткий локальный протокол выбирает пронумерованные оригинальные фрагменты, модель возвращает их ID, сервер восстанавливает цитаты и проверяет их. Контекст экономного режима 4096; отдельные рассуждения Qwen3 отключены. Ответ идёт потоком, виден прогресс. При обрыве неполный разбор не становится подтверждённым совпадением. После локальной ошибки автоматические повторы в текущем сборе приостанавливаются, новые находки сохраняются.

## Облако

Gemini: ключ https://aistudio.google.com/apikey , модель Flash / Flash-Lite, подготовлен `gemini-2.5-flash-lite`. Доступность и бесплатные квоты определяются вашим аккаунтом; если имя модели изменилось у Google, укажите доступное имя в настройках. «Проверить выбранный облачный ИИ» выполняет реальное обращение и учитывает его в счётчике.

OpenAI: ключ https://platform.openai.com/api-keys , модель задаётся `OPENAI_MODEL` в `.env`; по умолчанию `gpt-5-mini`. Баланс API отдельный от подписки ChatGPT.

Одновременных облачных разборов: 1–6, по умолчанию 3. Это параллельность, а не квота количества проектов. Она может упираться в реальные ограничения API. Локальный разбор идёт одним потоком, чтобы экономить видеопамять. Счётчики Gemini / OpenAI / Ollama разделены; неизменные входные данные используют кэш модели.

## Критерии

Ищутся бизнес-счета и IBAN-провайдеры: банк, EMI/PI, агент, BaaS / white-label и криптосервис с фиатным счётом через банк / EMI-партнёр. Само «мы не банк» допустимо. Название продукта отделяется от его спонсора / партнёра.

Для подтверждённого совпадения нужны прямые цитаты продукта об обслуживании бизнеса, предоставлении счёта и выдаче EU IBAN. EUR, SEPA, перевод на чужой IBAN, общий реквизит для пополнения, наличие европейского офиса и лицензия сами по себе не подтверждают критерии. Общие статьи, отзывы и неизвестные условия остаются на проверку. Старый сохранённый вывод без прямых фактов также не показывается как подтверждение только по старому значению `decision`; это проверяется без нового платного вызова.

Из реестров разрешения извлекаются только из точных цитат официального источника. Организация и дата решения проверяются в цитате; VASP не превращается в CASP/MiCA. Затем программа пытается найти сайт организации по ссылке из реестра либо по имени и прочитать продукт. Сайт с неподтверждённой связью не становится официальным доказательством. Проверенный сайт добавляется в текущую очередь ИИ отдельной записью.

Ручные исключения проверяются перед чтением, перед ИИ и перед сохранением. Сопоставляются известные названия, сайты и ID. Исключённый партнёр не делает другой продукт исключённым только из-за упоминания в тексте. Ошибки эвристик возможны: причины и исходные цитаты доступны в карточке, исключения восстанавливаются.

Точность и скорость реальной модели зависят от ПК, текста и модели. Проверки протокола и тестовые ответы не заменяют проверку на вашей NVIDIA. В среде разработки ключи ваших API и ваша Windows недоступны.
