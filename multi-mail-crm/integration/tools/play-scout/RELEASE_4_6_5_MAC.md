# Play Scout 4.6.5 — Mac M5 / 16 ГБ: проверка следующего подключения

Google Play уже прошёл точечный тест. Теперь можно отдельно проверить Brave,
открыв CRM с работающими кнопками и приостановленными расписаниями.
[Что делает ручной режим](RELEASE_4_6_5.md).

## Обновить и открыть ручной режим

Остановите прежний диагностический / обычный экземпляр через Control + C в его
Терминале. Откройте новое окно и вставьте блок целиком:

```bash
(
  set -e
  cd "$HOME/Desktop/play-scout-v31"
  PLAY_SCOUT_UPDATER=$(mktemp "${TMPDIR:-/tmp}/play-scout-update.XXXXXX")
  trap 'rm -f -- "$PLAY_SCOUT_UPDATER"' EXIT
  curl --fail --location --retry 2 \
    --connect-timeout 15 --max-time 60 \
    'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-mac.sh' \
    -o "$PLAY_SCOUT_UPDATER"
  bash "$PLAY_SCOUT_UPDATER" "$PWD"
  npm run start:manual
)
```

Дождитесь «Готово: Play Scout 4.6.5» и сообщения о ручном запуске.
Терминал оставьте открытым. Браузер откроет http://127.0.0.1:3000/crm.
Вверху должна быть надпись **«Ручной запуск»**. Расписания в этом экземпляре
не выполняются. Их сохранённые настройки не отключаются навсегда.

Ничего повторно очищать не нужно. Записи в работе, комментарии, фильтры,
исключения, ключи, GPT + Ollama / qwen2.5:7b, локальный профиль и расход сохраняются.
Updater создаёт резервную копию и устанавливает зависимости без install-скриптов.

## Нажать только проверку Brave

Нажмите **«Проверить Brave · 1 запрос»** рядом со строкой подключения.
Это одно обращение к Search API; оно учитывается в вашем плане Brave.
Сайты провайдеров, новые карточки и ИИ этим тестом не обрабатываются.

Успех: **«Brave отвечает»**. При ошибке видны HTTP 401 / 403 / 429 либо сообщение
о таймауте; значения ключей не печатаются. Для дальнейшей диагностики достаточно
сообщения на экране — `.env` передавать не нужно.

Полный сбор / все карточки / разбор пока не запускайте: проверяется только
следующий отдельный этап. Если macOS снова блокирует скрипт, остановите процесс
через Control + C и не повторяйте запуск ради обхода блокировки. Причина XProtect
пока не установлена.

## Повторный запуск

После остановки программы:

```bash
cd "$HOME/Desktop/play-scout-v31" && npm run start:manual
```

Просмотр без изменений — `npm run start:diagnostic` из той же папки.
Обычный `start:desktop` возобновляет сохранённые включённые расписания.
Если позже явно запускаете источник, проверьте его флажок «ИИ после сбора»:
он продолжает действовать и в ручном режиме.
