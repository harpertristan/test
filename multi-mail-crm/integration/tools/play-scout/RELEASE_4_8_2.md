# Play Scout 4.8.2 — Facebook через Apify до 500 результатов

Facebook: допустимый лимит сохранённой задачи, maxItems запуска и чтение набора результатов увеличены с 20 до 500. LinkedIn остаётся на 20. Денежный параметр maxTotalChargeUsd=1, таймаут 120 секунд, ручное подтверждение платного запуска и отсутствие автоматического повтора сохранены. Денежный параметр не гарантирует полную стоимость любого актора: проверьте тариф и ограничения расходов в Apify.

В сохранённой задаче Facebook в Apify увеличьте resultsLimit / maxPosts / maxItems (поддерживаемое актором поле) до 500. Задача с прежним лимитом 20 продолжит собирать до 20. Остаётся один URL или поисковый запрос, без cookies и логина. 500 — верхний предел; бюджет и время могут остановить сбор раньше.

Путь находок проверен по коду: createApifyMonitor → inboxEntry → storeInbox → общая ai.inbox → groupedCandidates → reviewCandidates / dueReviews → обычная очередь createAIReview. Сохраняются общие правила допуска, исключения и дедупликация. Автоматический разбор после сбора происходит при включённом «ИИ после сбора» и настроенном ИИ; иначе находки доступны для обычного ручного разбора.

Проверка выпуска: выполнена проверка синтаксиса изменённых JavaScript-файлов. Тесты для этого изменения не запускались по запросу пользователя; существующие ожидания лимита Facebook обновлены. Платный запуск Apify не выполнялся. База и её формат не меняются.
