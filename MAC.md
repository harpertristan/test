# Play Scout 4.2.1 — Mac: обновление в той же папке

Это та же CRM и функции версии 4.0 для Windows, с запуском и обновлением для macOS. История, исключения, ключи, выбранный ИИ и его кэш остаются в вашей рабочей папке. Переносить `data` и `.env` для обновления не требуется.

После обновления 4.1 сохранённые разборы один раз перепроверяются локальными правилами, без вызова API. История, комментарии и ручные исключения сохраняются. Общие документы регуляторов находятся во вкладке «Материалы источников». Кнопка «Перепроверить сохранённое · без API» повторяет локальную проверку; «Повторить проблемные» вызывает выбранную модель только для оставшихся проблемных записей. [Подробности 4.1](RELEASE_4_1.md).

**Новая инструкция для вашего M5 / 16 ГБ: [обновление 4.2](RELEASE_4_2_MAC.md), [llama.cpp / Metal и ферма](GPU_AGENT.md).** Выбранный ИИ не меняется автоматически.

## 1. Обновить уже установленный Play Scout одной командой

Откройте **новое окно Терминала**: Command + N. Не вставляйте команды в окно, занятое работающим сервером: оно сейчас не принимает команды оболочки.

Ваша прежняя рабочая папка по скриншотам — **`~/Desktop/play-scout-v31`**. Если она не переименована, скопируйте **весь блок**, вставьте в новое окно и нажмите Enter:

```sh
(
  set -e
  cd "$HOME/Desktop/play-scout-v31"
  PLAY_SCOUT_UPDATER=$(mktemp "${TMPDIR:-/tmp}/play-scout-bootstrap.XXXXXX")
  trap 'rm -f -- "$PLAY_SCOUT_UPDATER"' EXIT
  curl --fail --location --retry 2 --connect-timeout 15 --max-time 60 \
    'https://raw.githubusercontent.com/harpertristan/test/main/scripts/update-mac.sh' \
    -o "$PLAY_SCOUT_UPDATER"
  bash "$PLAY_SCOUT_UPDATER" "$PWD" --start
)
```

Что выполнит блок:

1. Проверит, что это папка Play Scout и Node.js версии 22 или новее.
2. Скачает новый код во временную папку.
3. Если старый сервер работает на порту из вашего `.env` (обычно 3000), проверит, что процесс Node / `server.js` запущен именно из этой рабочей папки. Затем попросит его завершиться и дождётся сохранения очереди. Другой экземпляр из другой папки не останавливается.
4. Создаст рядом резервную папку, например `play-scout-v31-backup-2026-10-27T...`. В ней будут `data`, `.env`, прежние заменяемые файлы в `code` и сведения об обновлении. При отдельном `DATA_DIR` сохраняется указанная там папка данных.
5. Заменит код в **вашей существующей папке**, установит зависимости и выполнит диагностику. Личные файлы остаются на месте. Если установка зависимостей завершится ошибкой, прежний код восстанавливается; перед повторным запуском может понадобиться `npm ci`.
6. Запустит программу и откроет CRM после ответа сервера.

Ожидаемая версия в диагностике — **Play Scout 4.2.1 или новее**. Старые ключи заново вводить не нужно.

Если папка называется иначе, замените только строку `cd` своим путём. Можно напечатать `cd ` с пробелом, перетащить папку из Finder в Терминал и нажать Enter; затем выполнить блок начиная с `PLAY_SCOUT_UPDATER=...` внутри скобок. Путь и `cd` должны находиться **на одной строке**.

## 2. Если обновление попросило остановить старую программу

Если прежняя команда только скачала архив и сразу вернулась к `%`, повторите блок из раздела 1: начиная с 4.0.2 исправлен пропуск запуска из временной папки macOS. После скачивания должны появиться этап установки и строка «Готово: Play Scout 4.2.1».

Для версий, которые отвечают на сигнал завершения, обновление сделает это само. Если появилось «Программа не завершилась» или «На порту работает другой экземпляр», код ещё не менялся:

1. Перейдите в старое окно Терминала, где написано `Play Finance Finder: port 3000`.
2. Нажмите **Control + C** — клавиша Control, не Command. Дождитесь строки с `%`.
3. Повторите блок обновления в новом окне.

Для зависшего процесса используйте «Мониторинг системы» и завершите именно Node этой программы. Обновляющий скрипт не применяет принудительный `kill -KILL` ко всем процессам на порту и не удаляет историю. Если вы переименовали папку после запуска, сначала остановите старое окно: его рабочий путь мог измениться.

## 3. Обычный запуск после обновления

В Терминале:

```sh
cd "$HOME/Desktop/play-scout-v31"
bash ./2-Запустить.command
```

Либо откройте **`2-Запустить.command`** двойным щелчком в Finder. Если macOS не разрешает открыть скачанный файл двойным щелчком, используйте команду `bash` выше.

Откроется **http://127.0.0.1:3000/crm**. При нестандартном `PORT` используйте адрес, напечатанный программой. Терминал оставьте открытым. При уже запущенной той же версии второе открытие показывает существующий экземпляр. Если работает старая версия, запуск попросит сначала остановить её.

Файл запуска использует `caffeinate`: пока он работает, Mac не засыпает от бездействия. Закрытие крышки, ручной сон или выключение всё равно прерывают работу.

## 4. Остановить

В новом окне Терминала:

```sh
cd "$HOME/Desktop/play-scout-v31"
npm run stop
```

Либо откройте **`5-Остановить.command`**. Он использует пароль владельца из вашей `.env`, останавливает сервер и ждёт сохранения очередей. Другой вариант — Control + C в окне запущенной программы.

«Остановить всё и сохранить» в браузере останавливает задания поиска; сама программа продолжает работать.

## 5. Локальный ИИ для вашего Mac с Apple Silicon и 16 ГБ+

Выбранная модель не меняется при обновлении. Для быстрого первичного отбора начните с **`qwen2.5:3b` и экономного режима**. Уже установленную `qwen3.5:4b` также можно сравнить на тех же карточках. Большая 7b не обязательно даст приемлемую скорость всей очереди.

1. Установите и откройте [Ollama для Mac](https://ollama.com/download/mac), если её ещё нет.
2. Если нужна маленькая модель, в **новом** Терминале выполните:

```sh
ollama pull qwen2.5:3b
```

Или запустите **`6-Локальный-ИИ.command`**. Если нужная модель уже видна в `ollama list`, повторно скачивать её не нужно.

3. В CRM откройте «Настройки источников, ИИ и ежедневного поиска»:
   - Где выполнять анализ: **Ollama**.
   - Объём разбора: **Экономный**.
   - Модель Ollama: **`qwen2.5:3b`** или точное имя установленной модели.
   - Нажмите «Сохранить настройки», затем «Проверить Ollama на этом компьютере».
4. Сначала разберите одну известную карточку. Сравните результат с реальными условиями сайта, прежде чем отправлять весь список.

Проверка моделей и GPU:

```sh
ollama list
ollama ps
```

`ollama ps` обычно показывает GPU во время и некоторое время после генерации; до первого запроса список может быть пустым. Полная скорость зависит от Mac, модели и текстов. Экономный режим использует короткий контекст и не запускает отдельные рассуждения Qwen3. Платного резервного переключения нет.

Если память занята прежней 7b, сначала остановите ИИ в CRM, затем:

```sh
ollama stop qwen2.5:7b
```

Встроенный ИИ работает отдельно от этого чата. Для моего самостоятельного разбора выберите вкладку CRM → «Данные для ChatGPT» и прикрепите полученный JSON к сообщению здесь.

## 6. Ключи поиска и облачного ИИ

Если ключи уже записаны, они остаются на месте. Для ввода / замены откройте новое окно Терминала:

```sh
cd "$HOME/Desktop/play-scout-v31"
```

Затем выполните нужную команду:

| Задача | Команда | Файл Finder |
| --- | --- | --- |
| Ключ Brave для сайтов и публикаций | `npm run configure` | `1-Настроить-ключ.command` |
| Отдельный ключ OpenAI API | `npm run configure:ai` | `3-Настроить-ИИ.command` |
| Отдельный ключ Gemini API | `npm run configure:gemini` | `8-Настроить-Gemini.command` |
| Пароли владельца / просмотра | `npm run configure:access` | Команда в Терминале |

Ввод ключей скрыт. После изменения перезапустите программу. Для Ollama ключ ИИ не требуется. Подписка ChatGPT не оплачивает OpenAI API; бесплатные квоты Gemini зависят от аккаунта и региона. Провайдер выбирается вами в CRM.

Перед изменением паролей остановите сервер через `npm run stop`, чтобы пароль работающего процесса совпадал с `.env` при остановке.

## 7. Где искать функции версии 4.0

- Быстрое исключение — кнопка в строке. Выберите причину один раз; для нескольких записей используйте отметки и «Исключить выбранные».
- «Исключены вручную» — отдельная вкладка с причинами «Уже в работе / был в работе», «Не банк и не провайдер», «Не подходит локация» и восстановлением. Названия, сайты и приложения сопоставляются между источниками.
- Сортировка по дате релиза, публикации и решения о лицензии находится над списком. Неизвестные даты идут в конце.
- Ночной режим переключается в верхнем меню.
- В разделе «Выбрать источник поиска» каждый реестр запускается отдельно. Его отметка «ИИ после сбора» включает чтение сайтов названных организаций и разбор. Своя банковская лицензия не обязательна для IBAN-провайдера через партнёра. Доступность бизнес-счёта и EU IBAN проверяется отдельно.
- App Store отключён; прежние находки доступны в архиве.
- Word, CSV и JSON учитывают текущую вкладку, причины исключения и сортировку.
- У каждого источника есть отдельное ежедневное расписание по Калининграду. Mac, программа и выбранный локальный ИИ должны работать.

## 8. Следующее обновление без нового блока команд

Из той же папки (команда совместима и со старым скриптом версии 4.0.2):

```sh
cd "$HOME/Desktop/play-scout-v31"
npm run update:mac -- "$PWD" --start
```

Если прежняя команда выдала `cd: --start: No such file or directory`, она завершилась до замены файлов: старый скрипт требует рабочую папку первым аргументом. Повторите две команды выше, включая `"$PWD"`. В версии 4.1.4 также работает вариант без явного пути; основная инструкция оставляет путь для совместимости.

Или откройте **`4-Обновить.command`**. Он заново скачает актуальный код, сделает резервную копию и обновит текущую папку. Запускайте только одно обновление одновременно. После аварийного закрытия обновления может остаться `.cache/update.lock`: сначала убедитесь, что обновляющее окно / процесс уже завершён, и только затем удалите эту папку блокировки.

## 9. Если нужна установка с нуля

Установите [Node.js LTS 22+](https://nodejs.org/). Скачайте [ZIP проекта](https://github.com/harpertristan/test/archive/refs/heads/main.zip), распакуйте один раз и положите папку на Рабочий стол. Откройте Терминал в этой папке и выполните:

```sh
bash ./2-Запустить.command
```

Файл запуска сам установит зависимости, если их ещё нет.

Устанавливать заново вместо обновления существующей папки не требуется.

## 10. Диагностика и общая ссылка

Откройте **`7-Диагностика.command`** или выполните в папке программы:

```sh
npm run doctor
curl --noproxy '*' --max-time 5 http://127.0.0.1:3000/api/health
```

В ответе ожидается `"status":"ok"` и версия `4.2.1` или новее. Ключи в диагностике не печатаются. Не удаляйте `data` при ошибках.

Для общей ссылки на Mac также работают пароли `admin` / `viewer`, локальная сеть и Tailscale Funnel. Установите [Tailscale для Mac](https://tailscale.com/download/mac), настройте оба пароля и выполните `tailscale funnel --bg 3000`. Доступность Funnel зависит от аккаунта / условий Tailscale; компьютер и программа должны продолжать работать. Выключить публикацию: `tailscale funnel reset`. Точные ограничения социальных источников описаны в [SOCIAL_CONNECTIONS.md](SOCIAL_CONNECTIONS.md).

## 11. Перенести эту же копию на Windows со всеми ключами

После обновления до 4.1.4 откройте новое окно Терминала:

```sh
cd "$HOME/Desktop/play-scout-v31"
npm run stop
npm run transfer:export
```

Введите новый пароль переноса от 12 символов дважды. На Рабочем столе появится `.psbackup` с полной историей и ключами из `.env`. Этот файл зашифрован; значения ключей в окно не выводятся. Можно также запустить `9-Перенести-на-Windows.command`.

Скопируйте `.psbackup` на Windows. В распакованной папке программы запустите `7-Import-from-Mac.cmd` и введите путь к файлу и пароль переноса. Затем `1-Install.cmd` и `2-Start.cmd`. Модель Ollama скачивается отдельно; её имя и выбранный ИИ сохраняются в профиле.

Полная инструкция с папками, командами и проверкой NVIDIA — **[WINDOWS.md](WINDOWS.md)**. Оставьте Mac-копию остановленной, если ежедневный поиск теперь выполняется на Windows. Перенос создаёт снимок данных, а не синхронизацию компьютеров.
