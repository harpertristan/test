# Play Scout 4.1.1 — та же версия для Windows с переносом профиля

Код поиска, критерии, нейронный разбор и CRM одинаковы на Mac и Windows. Для чистого запуска **без истории** есть импорт только ключей: `9-Import-keys-only.cmd`. Он читает копию `.env` с Mac, исправляет `DATA_DIR` и не копирует / не создаёт прежнюю историю. Правила отбора 4.1 не меняются. Полный перенос личного профиля ниже необязателен.

- **Mac → Windows:** `npm run transfer:export` и `7-Import-from-Mac.cmd`. Ключи / пароли `.env`, полная история `data`, кэш, исключения, заметки, очереди, фильтры, выбранный ИИ и расписания сохраняются.
- Файл `.psbackup` зашифрован AES-256-GCM с ключом от пароля переноса через scrypt. Пароль вводится скрыто; содержимое профиля и ключи не публикуются и никуда не отправляются.
- Учитывается внешняя папка `DATA_DIR` на Mac; Windows восстанавливает данные в `PlayScout\data`. Остальные значения `.env` сохраняются. Для локальной модели нужно отдельно установить Ollama и скачать ту же модель.
- Импорт проверяет целостность, имена файлов Windows, совместимость версии и занятость порта. Прежние `data` / `.env` сохраняются в резервной папке. При сбое установки профиль откатывается.
- Есть обратный экспорт с Windows: `8-Export-profile.cmd`. Формат один для обеих платформ.
- Windows-установщик больше не сообщает об успешной установке после провала диагностики; запуск прекращается при ошибке установки зависимостей.
- При создании новой пустой базы расписания выключены, пока вы не включите их явно. Скопированные ключи не запускают платный сбор сами по себе. Существующие расписания старых / полностью перенесённых профилей сохраняются.

Открытый ZIP содержит только код. Чтобы получить копию **с вашими** ключами и текущей историей, экспорт нужно один раз выполнить на вашем Mac, где находятся исходные файлы. CSV / PDF / JSON для ChatGPT не являются полной резервной копией.

**[Подробная инструкция Windows с нуля](WINDOWS.md)** · [Обновить Mac в прежней папке](MAC.md) · [Проверки](VALIDATION.md)

Перенос не расходует API и не запускает поиск. После обычного запуска включённые расписания и выбранный API работают по перенесённым настройкам. Две копии не синхронизируются автоматически; для ежедневного поиска используйте одну основную машину. Настройки внешнего браузера и веса модели Ollama не входят в профиль.
