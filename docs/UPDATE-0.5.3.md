# 0.5.3 · Паспорт / ID с фото → анкета → расширение

Исправление относится только к помощнику регистраций. Play Scout, инструмент почты и их настройки не изменяются.

## Что исправлено

Ранее `NIC/Passport No` не сопоставлялся с номером документа, а основная анкета не хранила номер паспорта и его срок действия. Для роли Director эти реквизиты также не передавались как данные выбранного представителя. Поэтому даже найденный в документе номер не всегда доходил до поля регистрации.

Добавлены поля основной анкеты:

- Identity document type — выбранный документ: Passport / National ID card.
- Passport number, Passport date of issue, Passport expiry date.
- National ID card number, ID card date of issue, ID card expiry date.
- Personal identification number, Nationality, Issuing country, Sex / gender.
- Date of birth, First Name и Last Name сохраняются вместе с этими реквизитами.

При распознавании сохраняются буквы и ведущие нули. Номер паспорта, номер ID-карты и персональный код не подменяют друг друга. При наличии обоих документов нужно выбрать тип документа для регистрации; комбинированные поля NIC/Passport No, Document number, Date of issue / expiry берут реквизиты выбранного документа. Печатная дата выдачи не выдумывается из MRZ: обычно её там нет.

Поддержаны явные подписи на паспорте/ID и MRZ TD1/TD2/TD3. Контрольные цифры номера и дат проверяются; неподтверждённый символ MRZ не исправляется догадкой. Для гражданства и страны выдачи поддержаны ISO alpha-2/alpha-3, а также распространённые английские названия гражданства. Буква O автоматически не превращается в цифру 0.

Паспортные сведения сопоставляются с именем представителя; срок действия сверяется с выбранным номером документа. При смене человека в редакторе паспортные поля очищаются. Сохранённые оператором значения остаются приоритетными и требуют проверки при расхождениях с документами.

Расширение распознаёт Passport No / Passport number / NIC/Passport No / Document number, даты, гражданство, страну выдачи, пол и персональный код. Даты преобразуются под поддержанные форматы поля, гражданство сопоставляется с вариантом обычного выпадающего списка. Скрытые, недоступные и секретные поля не заполняются; кредитные карты не смешиваются с ID-картой. Разрешения iframe и ограничения закрытого Shadow DOM остаются прежними.

## Применение на сервере

```bash
(
  set -e
  curl --fail --location --show-error \
    https://raw.githubusercontent.com/harpertristan/test/registration-assistant/deploy/play-scout/update-assistant.sh \
    -o /tmp/update-registration-assistant.sh
  sudo bash /tmp/update-registration-assistant.sh
)
```

Это обновляет только контейнер `registration-assistant`. Документы и ключи остаются в текущем хранилище.

После обновления:

1. Обновите кабинет и скачайте ZIP расширения 0.5.3 в разделе «Подключить Dolphin».
2. Распакуйте его и перезагрузите расширение в Dolphin. Обновите страницу внешней анкеты после сохранения её черновика.
3. Выберите компанию и нажмите «Разобрать все документы заново» — новые правила должны обработать уже загруженные фото.
4. В основной анкете проверьте номер паспорта / ID, дату рождения, выдачу, срок действия, гражданство и страну выдачи по оригиналу. При двух типах документов выберите используемый документ.
5. Сохраните подтверждённую основную анкету, затем в расширении обновите поля и проверьте выбранную компанию / роль.

## Проверка

123 автоматических теста прошли; дополнительно выполнены браузерные проверки паспортного пути, кабинета, обычной формы, вложенных форм и готовых ответов.

Проверяются PNG и JPEG с небольшим наклоном, номер с ведущими нулями, даты и личные реквизиты, TD3 паспорта и TD1 ID-карты, повреждённая контрольная цифра, два разных человека и два паспорта одного человека.

В Chromium выполняется реальная загрузка тестового PNG через API, OCR, сохранение анкеты директора и вставка в две формы: обычные label и ARIA-подписи. Проверяются NIC/Passport No, отдельный Passport number, разные форматы дат, списки гражданства и страны выдачи, пол, персональный код. Кредитная карта остаётся пустой; уже введённые значения не передаются обратно в запросах чтения формы. Транспорт сообщений расширения в этом браузерном сценарии моделируется; OCR и серверный API работают реально, платные ИИ-запросы не используются.

Фотография настоящего паспорта пользователя и его текущая форма на сервере недоступны в этой среде. Результат OCR конкретного снимка следует проверить в кабинете по сохранённому оригиналу. Качество/наклон/блики и закрытые компоненты сторонних форм могут ограничивать распознавание; универсальная работа в любой регистрации не гарантируется.
