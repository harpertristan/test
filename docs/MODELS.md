# Модели, скорость и бюджет

## Рекомендуемая схема для начала

До трёх пользователей: сервер Linux с 4 vCPU, 8 ГБ RAM и SSD от 40 ГБ; без GPU. OCR, документы и проверенные данные хранятся на сервере. Вставка проверенных значений не требует запроса к модели. Необязательная модель через API переводит и объясняет текст вопроса.

Ориентир бюджета, не проверенная коммерческая котировка:

| Статья | План в месяц |
|---|---:|
| Сервер | $25–50 |
| Резервные копии / хранилище | $10–20 |
| API с ограничением расходов в кабинете провайдера | до $150 |
| Остаток бюджета $200–300 | Резерв на нагрузку, домен и колебания цен |

Лицензии Dolphin и работа по внедрению в эту оценку не входят. Тариф и регион выбираются перед покупкой, с учётом места хранения документов компании.

## Какую модель выбрать

Для коротких русских пояснений начните с быстрой недорогой текстовой модели API, поддерживающей OpenAI Chat Completions. Для сложных форм в следующем этапе можно отдельно подключить более сильную модель, оставив подтверждённые факты и вставку детерминированными.

Точный идентификатор модели должен быть доступен в вашем API-аккаунте. В этой версии нет непроверенного «лучшего» имени по умолчанию: укажите `AI_MODEL` после выбора модели в кабинете. Совместимость конкретной модели проверяется запросом на синтетическом вопросе. Платный запрос в облачном стенде не выполнялся, потому что ключ пользователя не настроен.

Собственная локальная LLM без GPU может тормозить при одновременных запросах; арендованный GPU расходует значительную часть этого бюджета. Для первого запуска это не рекомендуется. Локальный сервер модели пока не подключён: реализован только фиксированный OpenAI HTTPS endpoint. Поддержка других API / локальных моделей — отдельная доработка, не скрытое переключение.

## Как подключить пояснения

1. В API-кабинете создайте ключ и задайте лимит расходов, например $150 в месяц. Подписка на чат и оплата API могут быть разными услугами.
2. На сервере откройте `deploy/.env`. Впишите ключ в `AI_API_KEY`, а идентификатор модели — в `AI_MODEL`. Не отправляйте этот файл или его содержимое в чат.
3. Сохраните файл и перезапустите приложение:

```sh
cd /opt/registration-assistant/deploy
docker compose up -d --no-deps --force-recreate app
```

4. На тестовой анкете нажмите «Объяснить по-русски». В API передаётся только название вопроса. Проверьте русский ответ и расход в кабинете.

`AI_DAILY_CALL_LIMIT=100` ограничивает число попыток обращений к ИИ в сутки для всей установки. Это **не денежный лимит**; ошибки и повторы тоже учитываются. В ответе ограничено количество выходных токенов. Денежный предел обязательно задаётся отдельно у провайдера.

## Исправления и развитие

Память исправлений сохраняется в базе и сразу показывается при следующем совпадении компании, домена и названия поля. Она не распространяется на другие компании. Для исправления значений нужно открыть карточку, проверить источник и сохранить новое значение.

Перед добавлением автоматического извлечения карточек или LLM-сопоставления новых полей потребуется набор размеченных примеров, проверка отсутствия выдуманных данных, подтверждение источников и тесты на похожих юридических вопросах. На этой версии модель не получает права менять подтверждённые факты или отправлять анкету.
