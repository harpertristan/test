# 0.4.3 · Автозаполнение по совпадениям документов

Основная анкета сама выбирает предварительные значения из найденных источников, включая одиночные значения, которые раньше требовали нажатия кнопки. Все варианты остаются под полем. Сохранение анкеты требует проверки и подтверждения оператором.

## Как выбирается значение

1. Значения приводятся к общему виду (регистр, формат даты, код страны и существующие правила нормализации).
2. Выбирается значение, встречающееся в наибольшем числе документов с разным сохранённым текстом. Повторения на страницах, результаты разных парсеров и идентичные копии не добавляют голосов.
3. При равенстве учитывается источник: регистрационный документ для юридических реквизитов, документ личности для имени. При полном равенстве выбирается стабильный предварительный вариант с явным предупреждением.
4. Сохраняются ссылка на источник, страница, цитата и объяснение числа совпадений. Это число совпадений, а не вероятность достоверности.
5. Имя и фамилия выбираются парой из одного документа. Компоненты адреса берутся из одного адресного блока. Личный адрес выбирается только среди доказательств с совпадающим именем и ролью владельца.
6. Заведомо другая компания и значения, не подтверждённые цитатой, в голосовании не участвуют. Отсутствующие факты, налоговые освобождения и согласия не выдумываются.

Ручные значения сохранённой анкеты и вручную подтверждённые факты имеют приоритет. Их можно заменить вариантом под полем. Новые документы отменяют актуальность подтверждения анкеты по существующим правилам.

Подпись Business description также распознаётся в текстовых документах. Отрасль, описание деятельности и назначение счёта остаются отдельными полями: одно не подставляется вместо другого без соответствующего найденного значения.

После установки нажмите Ctrl+F5 в кабинете: доступные значения появятся без отдельных нажатий «Использовать это значение». Сохранённые тексты документов уже содержат кандидатов; повторно загружать читаемые документы не нужно. Изменения относятся к основной анкете компании, а не к автоматической отправке банковских заявок.

Проверено 74 автоматическими тестами и браузерными сценариями: выбор большинства, одиночный вариант на ручной проверке, защита от повторных голосов, равенство, согласованность адреса и имени, сохранение ручной версии, автозаполнение и замена альтернативой в интерфейсе. Использованы только синтетические документы.
