# 0.3.2: ИИ автоматически объясняет каждое поле

Раньше панель показывала правила сопоставления, а объяснение OpenAI требовало отдельной кнопки и оставалось в боковой панели. Теперь после выбора компании при подключённом OpenAI автоматически включается «ИИ читает и объясняет каждое поле». Одна пакетная проверка передаёт подписи и структуру доступных полей и запрашивает отдельное русское пояснение к каждому — включая поля без данных и юридические галочки. Введённые значения, номера из документов, цитаты и оригиналы документов этим запросом не отправляются. Для объяснения причин незаполнения передаются только типы доступных реквизитов и наличие общего подтверждения оператором.

Нажмите значок возле поля или переведите в поле курсор. Пояснение ИИ появляется в оверлее и в панели. Если ответ ещё готовится, отображается состояние загрузки; открытая подсказка сохраняется после получения ответа. Кнопка «Объяснить по-русски» также обновляет обе подсказки. Галочки объясняются, но не выбираются помощником.

Новые поля и изменившаяся структура формы запускают новый разбор. Неизменившаяся форма использует результат текущего сеанса панели. Повторный разбор можно запросить кнопкой «Агент: разобрать анкету». Автоматический режим отключается одноимённой галочкой. Статус ИИ и ошибки подключения показаны отдельно от статуса сверки данных. Лимит API остаётся общим: 100 запросов в день по умолчанию.

Исправлены подписи с приклеенным пояснением, например «LEI code (optional) This is required to make use of Investment Services». Наличие пояснения не мешает распознать LEI. Условие «обязателен для инвестиционных услуг» не следует считать противоречием с необязательностью в обычной заявке.

Вставка по-прежнему использует только итоговые сведения компании и требует общего подтверждения оператором. Если данных нет, ИИ должен объяснить, что требуется, а не придумать реквизит. В счётчике отдельно указаны распознанные назначения полей и поля с готовыми данными. Поля внутри iframe и закрытого Shadow DOM текущая версия не читает; это ограничение не устранено этим обновлением.

После обновления через код: сохраните черновик банковской анкеты, откройте chrome://extensions в Dolphin, перезагрузите помощник круглой стрелкой, обновите вкладку анкеты и откройте панель. Выберите компанию. Дождитесь статуса «ИИ разобрал … полей». Нажимать отдельную кнопку объяснения для каждого поля больше не требуется.

Проверено: 45 автоматических тестов; браузерные сценарии автозаполнения и автоматических ИИ-пояснений по каждому полю, повторного использования результата, появления новых полей и синхронизации оверлея. API OpenAI и runtime расширения в тестах имитируются; реальную генерацию с ключом пользователя проверяют после установки.
