# Windows: как подключить Dolphin 307.36437

Эта инструкция предназначена для версии, указанной пользователем: **307.36437**. У меня нет доступа к её установленной копии. Названия кнопок Dolphin могут отличаться; загрузка расширения и работа в настоящем профиле требуют отдельной проверки. Антидетект-функции и отпечатки браузера помощник не меняет.

## 1. Получите адрес сервиса и папку расширения

Администратор должен передать вам HTTPS-адрес помощника, логин / пароль и папку `extension` из проекта. Например, распакуйте её в `C:\RegistrationAssistant\extension`.

После установки не перемещайте эту папку: распакованное расширение загружается из неё при работе браузера.

## 2. Откройте нужный профиль Dolphin

1. Запустите Dolphin и откройте профиль, в котором будете регистрировать компанию.
2. Внутри открывшегося Chromium-окна в адресной строке введите `chrome://extensions`.
3. Если страница открылась, включите переключатель **Developer mode / Режим разработчика**.
4. Нажмите **Load unpacked / Загрузить распакованное расширение**.
5. Выберите папку `extension`. Внутри неё должен лежать `manifest.json`; не выбирайте всю папку проекта.
6. Должна появиться карточка **«Помощник регистраций компаний»** без ошибки. При необходимости закрепите значок через меню расширений (значок пазла).

Если Dolphin запрещает `chrome://extensions` или загрузку распакованного расширения, не меняйте скрытые настройки и защиту наугад. Проверьте штатный раздел управления расширениями для профилей Dolphin и возможность установки такого расширения. Совместимость в этом случае ещё не установлена; потребуется адаптация способа установки. Покупать сервер до этой короткой проверки не обязательно.

## 3. Войдите в помощника и подготовьте компанию

1. Откройте адрес сервиса в отдельной вкладке. Введите логин и пароль.
2. Создайте компанию и загрузите документы. Подтвердите необходимые значения по оригиналам.
3. Слева нажмите **«Создать токен на 24 часа»**, затем **«Скопировать»**.

Токен — временный ключ доступа к вашим карточкам. Его не нужно отправлять в чат. Новый токен заменяет старый: одновременно поддерживается одно подключение расширения на пользователя.

## 4. Подключите расширение

1. В карточке расширения откройте **Details / Сведения → Extension options / Параметры расширения**. Альтернативно нажмите значок помощника на обычной странице, затем «Подключение».
2. Введите адрес сервиса: например, `https://assistant.example.com`. Адрес без `/api` и дополнительных путей.
3. Вставьте токен и нажмите **«Подключить и проверить»**.
4. Если браузер спросит разрешение обращаться к указанному серверу — подтвердите именно этот адрес.
5. Дождитесь сообщения **«Подключено»** с вашим логином.

Для локальной проверки на том же компьютере допускается адрес `http://127.0.0.1:3100`. Адрес удалённого сервера должен использовать HTTPS с действительным сертификатом.

## 5. Используйте панель на анкете

1. Откройте анкету. Не запускайте первую проверку на отправке реальной заявки: начните с полей названия, номера компании и адреса.
2. Нажмите значок помощника. Справа появится панель внутри страницы.
3. **Выберите компанию.** Не выбирается автоматически даже единственная компания.
4. Для понятного поля помощник покажет значение и цитату. Прочитайте их и нажмите **«Вставить в это поле»**.
5. Для незнакомого поля раскройте **«Выбрать поле и данные вручную»**. Выберите вопрос и подтверждённые сведения, сверьте источник, подтвердите соответствие и вставьте.
6. Кнопка **«Объяснить по-русски»** работает, если администратор подключил API. Она объясняет вопрос, но не принимает юридическое решение за вас.
7. При ошибке выберите поле внизу панели и напишите исправление. При следующей сверке это исправление остановит обычную подсказку для этой компании / домена / названия поля.
8. После перехода на другую страницу снова откройте панель. Внутри динамической страницы изменения полей отслеживаются автоматически; доступна кнопка «Обновить поля».

## Если что-то не работает

| Сообщение / проблема | Что сделать |
|---|---|
| Требуется подключение | Создайте токен в веб-интерфейсе и введите его в настройках расширения |
| После закрытия браузера подключение исчезло | Это ожидаемо: токен хранится только на время сеанса браузера. Введите ещё действующий токен или создайте новый |
| Токен истёк | Через 24 часа создайте новый |
| Поле не найдено | Убедитесь, что открыта анкета, раскройте нужный раздел и нажмите «Обновить поля». iframe / canvas не поддерживаются |
| Нет подтверждённого значения | Добавьте и подтвердите его в карточке компании |
| Нет точного варианта списка | Выберите вариант вручную на сайте |
| ИИ не подключён | Сверка документов работает; подключение пояснений делает администратор |
| Панель перекрывает форму | Скройте её кнопкой ×; откройте снова значком расширения |

## macOS

При серверном варианте установка Node.js на Mac не нужна. Получите папку `extension`, сохраните её в постоянном месте и выполните те же действия внутри профиля Dolphin. Интерфейс и действия расширения общие; проверка на настоящем Mac ещё не выполнена.
